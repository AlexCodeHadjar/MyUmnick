# Риг персонажа — нарезка на слои

Персонаж разбирается на части. Из частей в Godot 4 собирается «марионетка» с костями и деформируемыми сетками,
и анимации делаются движением частей, а не перерисовкой кадров: размер и рисунок одинаковые во всех позах,
движения плавные. Нарезку делаете вы, риг и анимации — Claude.

```text
rig/
├── README.md          это задание
├── parts-map.jpg      карта частей главного кадра: номер слоя → где он на персонаже
├── reference/
│   ├── main/stand_1.png        ГЛАВНЫЙ КАДР — из него режется весь персонаж
│   └── variants/*.png          кадры, из которых вырезаются сменные части (глаза, рот, руки, предметы)
├── layers/
│   ├── main/          ← сюда PNG-слои главного кадра
│   └── variants/      ← сюда PNG сменных частей
└── work/              ← сюда рабочий файл Krita/Photoshop (.kra/.psd) — в git не попадает
```

Если какая-то часть сложная — можно делить мельче (например, плащ на 3–4 куска, хвосты банта отдельно): просто
добавьте слой с понятным именем и номером между соседними (`13b_cloak_left_lower.png`).

**Дорисовка обязательна.** Когда кость поворачивает часть, открывается то, что было под ней. Под каждой частью
должно быть продолжение рисунка шириной 20–40 px (как будто перекрывающей части нет), иначе при движении появятся
дыры.

## 2. Сменные части — `reference/variants/`

Это части, которые не повернуть костью — у них другая форма. Каждую вырезать **одну** (без остального персонажа)
из указанного кадра. Имя файла = имя референса до `__` (например, из `eyes_happy__purr_1.png` → `eyes_happy.png`).

| Группа | Файлы-референсы | Что вырезать |
|---|---|---|
| Глаза | `eyes_half`, `eyes_happy`, `eyes_squeeze`, `eyes_angry`, `eyes_spiral`, `eyes_sleep`, `eyes_squint` | оба глаза вместе, без маски |
| Рот | `mouth_smile`, `mouth_yawn`, `mouth_talk_1`, `mouth_talk_2`, `mouth_talk_3` | только рот |
| Руки | `arm_relaxed`, `arm_reach` | рука целиком: плечо + предплечье + кисть, **тремя отдельными PNG** (`arm_relaxed_upper.png`, `arm_relaxed_fore.png`, `arm_relaxed_hand.png`) |
| Кисти | `hand_open`, `hand_fist`, `hand_point`, `hand_hold` | только кисть в перчатке |
| Предметы | `prop_box`, `prop_stamp`, `prop_paper`, `prop_book`, `prop_pencil_sheet`, `prop_popcorn`, `prop_note`, `prop_mallet`, `prop_block`, `prop_jukebox`, `prop_headphones_mic` | только предмет; закрытое руками — дорисовать |

Сменные части режутся **на холсте своего кадра-референса** (тот же размер и положение, что в референсе) —
совмещу их с главным кадром сам.

## 3. Как сохранять

### Основной путь — один PSD (выбран пользователем 2026-11-19)

- Файл: `rig/work/character.psd` (в git не попадает). Холст **1024×1536**, как у `stand_1.png`.
- **Каждая часть — отдельный слой**, имя слоя — как имя файла в таблицах, но без `.png`: `01_horn_far`,
  `02_horn_near`, … `22_bow`.
- Сменные части — в **группе** (папке слоёв) `variants`: слои `eyes_happy`, `mouth_talk_1`, `hand_fist`, `prop_box`…
  Их можно класть прямо поверх главного кадра на месте глаз/рта/кисти — так даже лучше: я сразу вижу, где они стоят.
- Режимы наложения — «Обычный», непрозрачность 100 %, без масок слоя, стилей и смарт-объектов (если есть —
  растрировать: «Слой → Растрировать»). Эффекты (тени, обводки) не использовать.
- Слои референсов (сам `stand_1.png`, кадры-образцы) — в группу `ref` или удалить: группу `ref` я пропущу.
- Экспортировать PNG **не нужно**: слои из PSD Claude вытащит сам (Python, `psd-tools`), каждую часть — на её место.

### Если удобнее отдельными PNG

1. **Рабочий файл** — Krita (`.kra`) или Photoshop/Photopea (`.psd`) в `rig/work/`. Холст **не менять**:
   1024×1536 px, как у референса. Слои не сдвигать и не масштабировать.
2. **Экспорт** — каждый слой отдельным PNG:
   - **полный холст 1024×1536**, часть на своём месте, всё остальное прозрачно (не обрезать по содержимому — по
     положению части я узнаю, где она стоит);
   - PNG, RGBA, прозрачный фон, без фона-подложки и без тени;
   - имена — латиницей, как в таблицах (`01_horn_far.png` …).
   - Главный кадр → `rig/layers/main/`, сменные части → `rig/layers/variants/`.
3. **Krita:** «Инструменты → Сценарии → Экспорт слоёв» (Export Layers), формат PNG, **снять** галочку «Подогнать
   размер под содержимое слоя» (Adjust export size to layer content).
   **Photopea / Photoshop:** «Файл → Экспорт слоёв» или для каждого слоя «Экспорт как» PNG с полным холстом
   (не «обрезать»).
4. **Проверка перед сдачей:** если включить все слои главного кадра, картинка должна совпасть с `stand_1.png`
   один в один (без щелей и двойных контуров).

### Необязательно, но поможет: точки вращения

Отдельный слой `pivots.png`: маленькие красные точки (8–10 px) там, где части поворачиваются — шея, плечи,
локти, запястья, бёдра (верх ног), колени, лодыжки, основания рожков, верх пол плаща. Без него точки поставлю сам.
