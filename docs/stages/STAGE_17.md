# Этап 17 — Надёжность и приватность

## Цель
Приложение само поднимается после сбоев, а пользователь управляет тем, что запоминается. Веха M12.

## Зависимости
Этапы 10, 13 (запуск llama-server из ядра, ADR-0019). S-17.2 учитывает память в Obsidian (S-16.4),
если та уже готова. Сборка релиза от этого этапа не зависит.

## Критерии приёмки этапа
- [ ] Падение llama-server или голоса не роняет приложение: компонент поднимается сам, пользователь
  видит понятное сообщение.
- [ ] Разговор в приватном режиме не оставляет следов на диске.

## Подводные камни
- Перезапуск в цикле: нужны пауза с нарастанием и предел попыток, затем — понятная ошибка.
- Приватный режим обещает отсутствие следов: проверять все места записи (память, Obsidian, журналы,
  трассировки, фоновые задачи), а не только базу фактов.
- Ключ шифрования нельзя хранить рядом с данными; потеря ключа — потеря памяти: предупреждать заранее.

## Сессии

### S-17.1 — Самовосстановление
- **Цель:** наблюдатель за llama-server, голосом и STT: падение и зависание обнаруживаются, компонент
  перезапускается с нарастающей паузой и пределом попыток; ход завершается понятной ошибкой, чат
  остаётся рабочим; статус виден в UI. Закрывает: жёстко убитое ядро оставляет llama-server
  работать (ADR-0019, STATE). Проверки — вне горячего пути.
- **Scope:** `src/vtuber/bootstrap/`, `application/`, `ui/src/features/`, `docs/adr/`
- **Готово, когда:**
  - [x] Тесты на фейках: падение, зависание, предел попыток, успешный возврат.
  - [x] Сценарий (автотест на заглушке вместо llama-server): убить сервер во время ответа — приложение
    восстанавливается; убить ядро — сервер не остаётся. С настоящим llama-server — при аренде.
  - [ ] Наблюдатель не ухудшает TTFT сверх погрешности (цена проверки замерена, TTFT — при аренде).
- **Статус:** код готов (ADR-0021)

### S-17.2 — Приватный режим
- **Цель:** переключатель «не запоминать этот разговор»: нет записи фактов, резюме, чатов и текста
  реплик в журналах; заметный индикатор в UI. Быстрая очистка всей памяти с подтверждением.
  Опционально — шифрование хранилища (выбор и ключ — через ADR).
- **Scope:** `application/memory/`, `application/conversation/`, `src/vtuber/bootstrap/`, `gateway/`,
  `ui/src/features/`, `docs/adr/`
- **Готово, когда:**
  - [x] Тест: после приватного разговора в данных и журналах нет его текста.
  - [x] Память до режима работает как прежде; очистка удаляет всё и не выполняется без подтверждения.
- **Статус:** готова. Шифрование (опция) не сделано: нужен отдельный ADR о выборе и хранении ключа
