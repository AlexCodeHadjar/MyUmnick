# Этап 3 — Диалоговый сервис: персона, промпт, краткосрочная память, отмена

## Цель
Сценарий «ход диалога» целиком, пока без голоса и UI. Веха M1: диалог с персоной в терминале
с выводом TTFT после каждого ответа (`uv run python -m vtuber.gateway.cli`).

## Зависимости
Этап 2.

## Критерии приёмки этапа
- [ ] Префикс промпта (всё до истории) байт-в-байт одинаков на всех ходах; история между
      усечениями только растёт.
- [ ] Ctrl+C / новая реплика прерывает ответ ≤ 100 мс.
- [ ] Теги эмоций не попадают в выводимый текст.
- [x] Персона меняется правкой TOML без изменения кода (FR-11).

## Подводные камни
- Время/дата в системном промпте ломает кэш (T-03). Динамика — только в последнем блоке.
