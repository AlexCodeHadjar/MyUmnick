# Этап 6 — Аватар: Live2D

## Цель
Живая модель справа. Веха M2: окно с чатом слева и живой Live2D-моделью справа.

## Зависимости
Этап 5.

## Критерии приёмки этапа
- [ ] 60 FPS при потоковой генерации текста (performance-профиль).
- [ ] Смена модели — заменой файлов и `mapping.json`, без кода.
- [ ] Реакция на отправку сообщения ≤ 1 кадра.

## Подводные камни
- **Лицензия.** Приложение, загружающее произвольные Live2D-модели, по терминам Live2D —
  «Expandable Application»: перед публикацией нужна проверка и отдельное соглашение, даже для
  частных лиц (`docs/licenses.md`). Для личного использования и разработки это не мешает, но
  решение (Live2D / VRM / одна фиксированная модель) фиксируется ADR в S-6.1.
- Модели сильно различаются набором параметров и выражений — всё модель-зависимое только
  в `mapping.json`.

## Сессии

### S-6.1 — Версии, лицензия, ADR, интерфейс AvatarRenderer
- **Цель:** связка версий PixiJS + pixi-live2d-display (или поддерживаемого форка) + Cubism Core;
  решение по лицензии Live2D; интерфейс `AvatarRenderer` (`load`, `setEmotion`, `setMouth`,
  `lookAt`, `react`, `update`, `dispose`).
- **Scope:** `ui/src/features/avatar/AvatarRenderer.ts`, `docs/adr/`, `docs/licenses.md`
- **Читать:** `docs/licenses.md`, `docs/architecture.md` (Фронтенд)
- **Готово, когда:**
  - [ ] ADR: выбранные версии и решение по Expandable Application.
- **Статус:** не начата

### S-6.2 — Live2D: загрузка, idle, моргание, дыхание, взгляд

- **Scope:** `ui/src/features/avatar/live2d/`
- **Готово, когда:**
  - [ ] Профиль: 60 FPS при стриминге текста.
- **Статус:** не начата
