# Этап 14 — Естественный слух

## Цель
Витюбер отвечает, когда обращаются к нему, не перебивает на паузе, различает собеседников и замечает
звуки вокруг. Веха M9.

## Зависимости
Этап 11. Этап 13 от этого этапа не зависит. S-12.7 (менеджер ресурсов) — для моделей на GPU.

## Критерии приёмки этапа
- [ ] Посторонний разговор в комнате не запускает ход; обращение по имени запускает.
- [ ] Пауза посреди фразы не приводит к преждевременному ответу; «конец речи → первый звук» остаётся
  ≤ 1.5 с p50 (Этап 11).
- [ ] При двух собеседниках реплики в истории подписаны разными говорящими.
- [ ] Выключенная функция этапа не влияет на задержки диалога.

## Подводные камни
- **Новые зависимости и модели — только через ADR** со сверкой лицензий и замером задержки.
- openWakeWord: код Apache-2.0, но готовые модели CC BY-NC-SA. Своё русское слово придётся обучать;
  качество на русском не проверено. Porcupine — коммерческий сервис с ключом доступа: проверить
  условия, работу без сети и поддержку русского.
- pyannote: библиотека MIT, но веса на Hugging Face закрыты соглашением: скачивать их должен
  пользователь со своим токеном.
- SenseVoice: код MIT, у весов своя лицензия (`model-license`), сверить условия.
- Всё это слушает микрофон постоянно: звук не сохранять и не отправлять наружу.

## Сессии

### S-14.1 — Обращение по имени (Wake Word)
- **Цель:** режим «по имени»: ход начинается после «Эй, …», а не на любую речь в комнате. Порт
  детектора; сравнить openWakeWord и Porcupine (RealtimeSTT — как образец подключения); своя
  фраза задаётся в конфиге; режимы push-to-talk и «всегда слушать» остаются.
- **Scope:** `src/vtuber/ports/`, `src/vtuber/adapters/`, `application/conversation/`, `docs/adr/`
- **Готово, когда:** [ ] на записях с посторонней речью и с обращением измерены пропуски и ложные
  срабатывания; [ ] детектор укладывается в кадр реального времени на CPU.
- **Статус:** не начата

### S-14.2 — Умное определение конца реплики
- **Цель:** отличать паузу «я хотел…» от законченного вопроса: модель завершённости (Pipecat Smart
  Turn) поверх порога тишины VAD; при сбое модели — откат к тишине.
- **Scope:** `src/vtuber/adapters/stt/`, `application/conversation/`, `docs/adr/`
- **Читать:** ADR-0016
- **Готово, когда:** [ ] на русских записях преждевременных ответов меньше, чем только по тишине
  (замер до/после; поддержку русского проверить на записях, а не по описанию); [ ] задержка в норме.
- **Статус:** не начата

### S-14.3 — Разделение собеседников по голосу
- **Цель:** диаризация (pyannote.audio): кто когда говорил; метка говорящего в реплике и истории,
  чтобы не смешивать людей. Работает вне горячего пути и не задерживает ответ.
- **Scope:** `src/vtuber/ports/`, `src/vtuber/adapters/`, `application/prompting/`, `docs/adr/`
- **Готово, когда:** [ ] запись с двумя людьми размечена верно (доля ошибок замерена); [ ] TTFT без
  ухудшения сверх бюджета; [ ] без весов приложение работает в режиме одного собеседника.
- **Статус:** не начата

### S-14.4 — Распознавание звуковых событий
- **Цель:** смех, аплодисменты, кашель, музыка (метки SenseVoice) становятся событиями шины;
  персонаж может уместно отреагировать, с ограничением частоты, чтобы не комментировать каждый звук.
- **Scope:** `src/vtuber/adapters/`, `src/vtuber/domain/events.py`, `application/`, `docs/adr/`
- **Готово, когда:** [ ] точность меток замерена на наборе записей; [ ] реакция не прерывает речь
  пользователя и не влияет на задержки при выключенной функции.
- **Статус:** не начата
