# Этап 16 — Диалоги, память и интернет

## Цель
Пользователь управляет историей и памятью, а персонаж при разрешении знает свежие новости. Веха M11.

## Зависимости
Этап 10. S-16.3 — S-12.4 (инструменты). Этап 13 от этого этапа не зависит.

## Критерии приёмки этапа
- [ ] Возврат к реплике создаёт ветку, исходная беседа не теряется.
- [ ] Факт, удалённый в редакторе, больше не попадает в ответы.
- [ ] С выключенным поиском приложение полностью работает офлайн (NFR-06).
- [ ] Чаты и факты лежат в хранилище Obsidian; правка заметки меняет поведение памяти, а индекс
  пересобирается из файлов.

## Подводные камни
- **Поиск в интернете расходится с NFR-06 («полностью офлайн»):** нужен ADR; функция выключена по
  умолчанию, а запрос наружу уходит только с явного разрешения пользователя.
- SillyTavern и SearXNG — AGPL-3.0: SillyTavern берём только как образец идеи, код не копируем;
  SearXNG запускается отдельным процессом, не внутри приложения.
- Текст страниц из интернета — данные, а не инструкции: нельзя выполнять команды, найденные на них.
- Память в Obsidian хранится открытым текстом: при Obsidian Sync или облачной папке она уходит с
  компьютера — предупреждать при настройке. Obsidian для работы не обязателен: это только папка с
  Markdown, плагин с REST API не используем (память не должна зависеть от открытого приложения).
- Ветвление меняет префикс промпта: учесть KV-кэш (T-03) и `test_prefix_is_stable`.

## Сессии
Порядок: S-16.4 и S-16.5 — раньше S-16.1 и S-16.2: они определяют, где лежат чаты и факты.

### S-16.1 — Ветвление диалогов и контрольные точки
- **Цель:** вернуться к реплике, попробовать другое продолжение, сохранить контрольную точку;
  исходная ветка остаётся. Хранение — дерево, а не список; переключение веток в UI.
- **Scope:** `src/vtuber/domain/`, `application/conversation/`, `gateway/`, `ui/src/features/chat/`
- **Готово, когда:** [ ] тесты: ветка не меняет исходную, память и промпт берут только активную;
  [ ] TTFT после переключения замерен; [ ] ручной сценарий.
- **Статус:** не начата

### S-16.2 — Редактор памяти
- **Цель:** просмотр фактов и их источников, исправление, удаление; отдельная память для разных
  пользователей. Правка сразу действует на поиск фактов. После S-16.5 основное редактирование идёт в
  Obsidian: здесь остаётся быстрый доступ из UI и разделение пользователей.
- **Scope:** `src/vtuber/ports/`, `src/vtuber/adapters/memory/`, `application/memory/`, `gateway/`,
  `ui/src/features/`
- **Читать:** ADR-0015; связь с говорящим из S-14.3 — если тот этап уже готов
- **Готово, когда:** [ ] удалённый факт не находится; [ ] память пользователей не смешивается
  (контрактный тест); [ ] данные старой версии мигрированы.
- **Статус:** не начата

### S-16.3 — Поиск актуальной информации
- **Цель:** ответы о свежих событиях с показом источников, через инструмент S-12.4: локальный
  SearXNG (как образец — связка Open WebUI), результат идёт в динамический блок, источники видны в чате.
- **Scope:** `plugins/web_search/`, `application/tools/`, `ui/src/features/chat/`, `docs/adr/`
- **Готово, когда:** [ ] ADR о сетевом доступе; [ ] офлайн-режим без запросов наружу подтверждён
  тестом; [ ] тайм-аут поиска не ломает ответ; [ ] на вопросах о свежих событиях показаны источники.
- **Статус:** не начата

### S-16.4 — Память в Obsidian: запись чатов и фактов
- **Цель:** хранилище Obsidian — источник истины: разговоры сохраняются между запусками (`Чаты/`), факты,
  люди и дневник — заметки со ссылками `[[...]]` и свойствами (id, источник, дата). SQLite-vec — индекс,
  который можно пересобрать из файлов. Запись — через порт, в фоне и атомарно; горячий путь файлы не
  читает. Импорт уже накопленных фактов. Пересмотр ADR-0015, новый ADR.
- **Scope:** `src/vtuber/ports/memory.py`, `src/vtuber/adapters/memory/`, `application/memory/`,
  `config/default.toml`, `docs/adr/`
- **Читать:** ADR-0015, `application/memory/README.md`
- **Готово, когда:**
  - [x] Контрактный тест: после перезапуска разговор и факты на месте; удаление индекса — пересборка из файлов.
  - [ ] TTFT p95 с памятью не вырос сверх +40 мс (замер на аренде).
  - [ ] Папка открывается в Obsidian: граф и ссылки работают (ручной сценарий, за пользователем).
- **Статус:** код готов (ADR-0020); в самом Obsidian и на настоящей модели не проверялось

### S-16.5 — Память в Obsidian: правки пользователя
- **Цель:** изменённая, удалённая или новая заметка попадает в индекс без перезапуска; конфликт с записью
  витюбера не теряет правки пользователя (его правка главнее, битая заметка — предупреждение, а не сбой).
- **Scope:** `src/vtuber/adapters/memory/`, `application/memory/`
- **Готово, когда:**
  - [x] Тесты: правка меняет выдачу поиска; удалённый факт больше не находится; одновременная запись
    не теряет данные.
  - [ ] Слежение за файлами не влияет на TTFT (замер на аренде; стоимость опроса замерена, см. журнал).
- **Статус:** код готов; в самом Obsidian не проверялось
