# Этап 16 — Диалоги, память и интернет

## Цель
Пользователь управляет историей и памятью, а персонаж при разрешении знает свежие новости. Веха M11.

## Зависимости
Этап 10. S-16.3 — S-12.4 (инструменты). Этап 13 от этого этапа не зависит.

## Критерии приёмки этапа
- [ ] Возврат к реплике создаёт ветку, исходная беседа не теряется.
- [ ] Факт, удалённый в редакторе, больше не попадает в ответы.
- [ ] С выключенным поиском приложение полностью работает офлайн (NFR-06).

## Подводные камни
- **Поиск в интернете расходится с NFR-06 («полностью офлайн»):** нужен ADR; функция выключена по
  умолчанию, а запрос наружу уходит только с явного разрешения пользователя.
- SillyTavern и SearXNG — AGPL-3.0: SillyTavern берём только как образец идеи, код не копируем;
  SearXNG запускается отдельным процессом, не внутри приложения.
- Текст страниц из интернета — данные, а не инструкции: нельзя выполнять команды, найденные на них.
- Ветвление меняет префикс промпта: учесть KV-кэш (T-03) и `test_prefix_is_stable`.

## Сессии

### S-16.1 — Ветвление диалогов и контрольные точки
- **Цель:** вернуться к реплике, попробовать другое продолжение, сохранить контрольную точку;
  исходная ветка остаётся. Хранение — дерево, а не список; переключение веток в UI.
- **Scope:** `src/vtuber/domain/`, `application/conversation/`, `gateway/`, `ui/src/features/chat/`
- **Готово, когда:** [ ] тесты: ветка не меняет исходную, память и промпт берут только активную;
  [ ] TTFT после переключения замерен; [ ] ручной сценарий.
- **Статус:** не начата

### S-16.2 — Редактор памяти
- **Цель:** просмотр фактов и их источников, исправление, удаление; отдельная память для разных
  пользователей. Правка сразу действует на поиск фактов.
- **Scope:** `src/vtuber/ports/`, `src/vtuber/adapters/memory/`, `application/memory/`, `gateway/`,
  `ui/src/features/`
- **Читать:** ADR-0015; связь с говорящим из S-14.3 — если тот этап уже готов
- **Готово, когда:** [ ] удалённый факт не находится; [ ] память пользователей не смешивается
  (контрактный тест); [ ] данные старой версии мигрированы.
- **Статус:** не начата

### S-16.3 — Поиск актуальной информации
- **Цель:** ответы о свежих событиях с показом источников, через инструмент S-12.4: локальный
  SearXNG (как образец — связка Open WebUI), результат идёт в динамический блок, источники видны в чате.
- **Scope:** `plugins/web_search/`, `application/tools/`, `ui/src/features/chat/`, `docs/adr/`
- **Готово, когда:** [ ] ADR о сетевом доступе; [ ] офлайн-режим без запросов наружу подтверждён
  тестом; [ ] тайм-аут поиска не ломает ответ; [ ] на вопросах о свежих событиях показаны источники.
- **Статус:** не начата
