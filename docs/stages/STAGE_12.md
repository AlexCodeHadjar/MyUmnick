# Этап 12 — Расширения и плагины

## Цель
Новые возможности подключаются плагинами без правки ядра. Веха M7.

## Зависимости
Этап 8 (минимум), желательно 10.

## Критерии приёмки этапа
- [ ] Плагин-пример ставится `uv pip install -e plugins/example` и работает без изменения ядра.
- [ ] Отключённый плагин не влияет на задержки.

## Сессии

### S-12.1 — Plugin API и загрузчик
- **Цель:** `Plugin` (`name`, `setup(ctx)`, `shutdown()`), `PluginContext` (подписка на шину,
  регистрация источника реплик, своя секция конфига, логгер) — без доступа к внутренностям ядра;
  загрузка через entry points + включение/выключение в конфиге; `docs/plugins.md` и плагин-пример.
- **Scope:** `kernel/plugin.py`, `bootstrap/plugins.py`, `plugins/example/`, `docs/plugins.md`
- **Готово, когда:** [ ] плагин-пример реагирует на событие без правки ядра.
- **Статус:** не начата

### S-12.2 — MessageSource и чат стрима
- **Цель:** `MessageSource` — UI-чат становится одним из источников; чат Twitch/YouTube
  (очередь, фильтры, лимит частоты, выбор, на что отвечать).
- **Scope:** `src/vtuber/ports/`, `plugins/stream_chat/`
- **Готово, когда:** [ ] тест с фейковым источником; лимит частоты соблюдается.
- **Статус:** не начата

### S-12.3 — OBS-плагин
- **Цель:** OBS WebSocket: субтитры текущей фразы, смена сцены по эмоции.
- **Scope:** `plugins/obs/`
- **Готово, когда:** [ ] ручной сценарий с OBS.
- **Статус:** не начата

### S-12.4 — Маршрутизатор намерений и инструменты
- **Цель:** время, таймер, заметки — без раунда function calling в горячем пути: маршрутизатор
  намерений вызывает инструмент до LLM и кладёт результат в динамический блок (одна генерация
  вместо двух ⏱).
- **Scope:** `application/tools/`, `plugins/tools/`
- **Готово, когда:** [ ] TTFT с инструментом ≈ TTFT без него (замер).
- **Статус:** не начата
