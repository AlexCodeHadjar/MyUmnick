# Этап 21 — Чаты: своя память и контекст у каждого

## Цель
Слева в окне, как в Claude, — список чатов и категорий, которые создаёт пользователь. У каждого чата своя память
(факты, заметки, резюме) и свой контекст разговора. Стрелка справа от списка прячет его сдвигом к краю. Переключение
— без перезапуска ядра (ADR-0037). Веха M16.

## Критерии приёмки
- [x] Новый чат открывается с пустым разговором; возврат к прежнему показывает его историю.
- [x] Факты и заметки чатов не смешиваются; основной чат — прежние данные пользователя.
- [x] Категории: создать, удалить (чаты остаются); чат — переименовать, перенести, удалить вместе с памятью.
- [x] Стрелка сворачивает и разворачивает список с анимацией; состояние запоминается.
- [ ] Проверено в окне Tauri и с настоящей LLM (проверено в браузере с заглушкой LLM).
- [ ] Время переключения замерено.
