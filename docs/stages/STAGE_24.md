# Этап 24 — Карманный Умник: спутник на телефоне и блокнот с синхронизацией

> План по запросу пользователя от 2026-11-17. Решения — ADR-0050. Веха **M18**.

## 0. Коротко
Отдельное Android-приложение `mobile/android/` (Kotlin, без LLM). Это «болванчик» того же персонажа, что ходит по
рабочему столу ПК:
1. **Запускается сам при включении телефона** (`BOOT_COMPLETED` → служба переднего плана).
2. **Живёт поверх экрана** (оверлей `SYSTEM_ALERT_WINDOW`): ходит по низу экрана, садится, ложится, засыпает,
   те же кадры поз и эмоций (`ui/public/characters/default/`).
3. **Взаимодействие**: тык (poke), поглаживание сериями (фразы `pet.ru` — первое/ещё/много/перегруз/максимум),
   перетаскивание (held), бросок (float → падение), встряхивание телефона (dizzy), реплики по времени суток.
4. **Единственная «умная» функция — голос**: слышит «Умник» (офлайн), отвечает репликой и записывает в блокнот
   продиктованное. «Умник, запиши купить молоко» — сразу; «Умник!» → «Слушаю» → следующая фраза — заметка.
   Также «Умник, прочитай заметки» (озвучка системным TTS).
5. **Синхронизация с ПК по USB без отладки**: телефон пишет блокнот в папку `Documents/UmNick/` (её видно по MTP).
   Ядро на ПК само замечает подключение телефона (WPD), забирает новые заметки в `data/notes.txt` и кладёт
   на телефон заметки с ПК. Повторов нет: у каждой заметки свой `id`.

Приоритеты проекта не задеты: телефонный модуль — внешний, синхронизация на ПК — фоновая задача с опросом раз в
5 с в отдельном потоке, горячий путь (LLM → TTS) её не видит.

## 3. Формат обмена (кратко, подробно — `docs/phone-sync.md`)
- Телефон пишет `notes.jsonl`: `{"id": "uuid", "text": "...", "created": "ISO-8601", "origin": "phone"}`.
- ПК пишет `from_pc.jsonl` тем же форматом (`origin: "pc"`) — заметки из `data/notes.txt`.
- ПК ведёт `data/phone_sync.json` — какие `id` уже забраны. Телефон удаляет у себя ничего не нужно.

## 4. Что нужно от пользователя
- Установить JDK 17 и Android SDK (или Android Studio) — без них APK не собрать. Можно поставить через `winget`.
- На телефоне один раз: разрешить «Поверх других окон», микрофон, уведомления, выбрать папку `Documents/UmNick`,
  отключить оптимизацию батареи для UmNick (иначе TECNO HiOS убьёт службу).
- Модель Vosk `vosk-model-small-ru-0.22` (~45 МБ) кладётся в `mobile/android/app/src/main/assets/` (README).

## 4а. Перебежка между ПК и телефоном (дополнение пользователя, 2026-11-17)
Аватар один на два устройства. Утащили мышью за **левый край экрана ПК** — он исчезает там (анимация портала)
и «выпрыгивает» из правого края экрана телефона. Утащили пальцем за правый край телефона — возвращается на ПК
из левого края.
- MTP для этого не годится (нет живого канала, телефон не знает, что подключён). Нужен **живой канал**:
  телефон и ПК в одной сети Wi-Fi (или USB-модем). ПК раз в 2 с шлёт UDP-маяк `umnick-hello` на порт 8766,
  телефон отвечает и открывает WebSocket к шлюзу ядра (`ws://<ПК>:8765/companion`, пара по коду из 4 цифр
  при первом подключении).
- Сообщения: `companion.handoff {to: "phone"|"pc", y: 0..1, mood, pose}` и `companion.ack`. Пока канала нет,
  левый край ПК — обычная стена, перебежки нет.
- По тому же каналу ходят и заметки (сразу, без кабеля); MTP остаётся запасным путём при подключении по USB.
- Сессии: **S-24.9** шлюз ядра — маяк, пара, `companion.handoff`; **S-24.10** UI спутника — край экрана как
  портал на телефон; **S-24.11** телефон — клиент канала, вход и выход через правый край.

## 5. Риски
- HiOS агрессивно убивает фоновые службы — служба переднего плана + исключение из оптимизации батареи.
- Постоянное прослушивание микрофона тратит батарею: Vosk с ограниченной грамматикой до слова «Умник», полная
  диктовка — только после имени. Выключатель «Слушать» в уведомлении.
- MTP на Windows кэширует список файлов: ПК перечитывает папку при каждом подключении заново.
