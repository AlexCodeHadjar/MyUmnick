# Этап 15 — Живое присутствие

## Цель
Персонаж сам проявляет инициативу и живёт поверх рабочего стола. Веха M10.

## Зависимости
Этапы 6, 8. Этап 13 от этого этапа не зависит.

## Критерии приёмки этапа
- [ ] Инициативные реплики появляются только в простое и не мешают пользователю.
- [ ] Прозрачное окно не опускает рендер ниже 60 FPS (NFR-05).

## Подводные камни
- Open-LLM-VTuber — только источник идей: его лицензия не определена автоматически, код не копировать
  без проверки.
- Прозрачность и пропуск кликов зависят от платформы (Tauri, WebView2): проверять на Windows вживую.
- Прогрев и фоновые задачи уже делят простой (S-10.3): инициативная реплика не должна им мешать.

## Сессии

### S-15.1 — Инициативные реплики
- **Цель:** после заданного времени простоя персонаж сам задаёт вопрос или продолжает тему. Через
  планировщик простоя; настройки: включение, интервал, лимит подряд без ответа пользователя; любой
  ввод немедленно отменяет реплику. Не срабатывает во время речи, набора и на свёрнутом экране по
  настройке.
- **Scope:** `application/conversation/`, `application/scheduler/`, `config/default.toml`,
  `personas/`
- **Готово, когда:** [ ] тесты на фейковых часах: срабатывание, отмена вводом, лимит; [ ] ручной сценарий.
- **Статус:** не начата

### S-15.2 — Персонаж поверх рабочего стола
- **Цель:** небольшое прозрачное окно с моделью: перемещение, закрепление поверх окон, пропуск кликов
  сквозь пустые области, быстрый возврат к обычному виду.
- **Scope:** `ui/src-tauri/`, `ui/src/features/avatar/`, `ui/src/features/` (режим окна)
- **Готово, когда:** [ ] ручной сценарий на Windows; [ ] 60 FPS при стриминге (профиль); [ ] режим
  запоминается между запусками.
- **Статус:** не начата
