# Этап 13 — Упаковка и релиз

## Цель
Устанавливаемое приложение для Windows. Веха M8.

## Зависимости
Этапы 0–9 обязательно, остальные — по готовности.

## Критерии приёмки этапа
- [ ] Чистая Windows-машина: установка → мастер → диалог голосом, без ручных шагов в консоли.
- [ ] Холодный старт ≤ 20 с (NFR-07).

## Подводные камни
- Публичная раздача: лицензии всех поставляемых компонентов (Live2D, голос, модель) должны это
  разрешать — сверить `docs/licenses.md` перед релизом.

## Сессии

### S-13.1 — Сборка sidecar, ADR
- **Цель:** ядро в исполняемый sidecar (PyInstaller или Nuitka — по размеру и скорости старта);
  поставка llama-server (сборка CUDA 12.8+) рядом с приложением.
- **Scope:** `packaging/`, `docs/adr/`
- **Готово, когда:** [ ] ADR с замерами размера и времени старта.
- **Статус:** не начата

### S-13.2 — Мастер первого запуска
- **Цель:** определение GPU/VRAM → рекомендация модели и голоса → загрузка с проверкой
  контрольных сумм (с явного согласия пользователя) → выбор аватара.
- **Scope:** `ui/src/features/onboarding/`, `application/setup/`
- **Готово, когда:** [ ] сценарий на чистой машине.
- **Статус:** не начата

### S-13.3 — Установщик, руководство, релиз
- **Цель:** установщик Tauri (MSI/NSIS), иконки, опционально автообновление;
  `docs/user-guide.md`; «скопировать отчёт» об ошибке; SemVer, `CHANGELOG.md`, тег v1.0.0.
- **Scope:** `ui/src-tauri/`, `docs/`, `CHANGELOG.md`
- **Готово, когда:** [ ] критерии этапа выполнены.
- **Статус:** не начата
