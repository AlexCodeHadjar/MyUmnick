# Этап 11 — Голосовой ввод и перебивание

## Цель
Разговор голосом в обе стороны. Веха M6.

## Зависимости
Этап 9.

## Критерии приёмки этапа
- [ ] От конца фразы пользователя до первого звука ответа ≤ 1.5 с p50.
- [ ] Ложных перебиваний от собственного голоса витюбера — 0 на тестовом сценарии с колонками.

## Сессии

### S-11.1 — Захват микрофона в UI, протокол кадров
- **Цель:** `getUserMedia` с `echoCancellation` и `noiseSuppression` (эхоподавление браузерного
  движка не даёт витюберу «слышать себя»); кадры 16 кГц PCM → бинарные `mic.frame`.
- **Scope:** `ui/src/features/mic/`, `gateway/`
- **Готово, когда:** [x] кадры доходят до ядра; e2e-тест протокола
  (`test_mic_frames_reach_the_sink_in_order`, кадр `<BBHI` + PCM: `encodeMicFrame`, `decode_mic_frame`).
- **Статус:** готово

### S-11.2 — Порт STT, адаптер, VAD
- **Цель:** `STTPort` (промежуточные и финальные гипотезы); faster-whisper + Silero VAD; конец
  фразы по тишине (настраиваемо, старт 500–700 мс).
- **Scope:** `src/vtuber/ports/stt.py`, `src/vtuber/adapters/stt/`
- **Готово, когда:** [x] контрактный тест STT и VAD (`test_stt_contract.py`, настоящие модели на
  записи `tests/data/speech_ru_16k.wav`); [ ] `@gpu` на записи — при следующей аренде (на CPU
  большая turbo распознаёт в несколько раз медленнее речи, это ожидаемо).
- **Статус:** готово, кроме прогона на GPU

### S-11.3 — Голосовой ход, prefill по гипотезам, barge-in
- **Цель:** голосовой ход; промежуточные гипотезы → speculative prefill (T-05); barge-in: речь
  ≥ 300 мс во время SPEAKING → отмена хода; режимы push-to-talk и «всегда слушать»; метрика
  «конец речи → первый звук».
- **Scope:** `application/conversation/`
- **Готово, когда:** [ ] метрика ≤ 1.5 с p50; 0 ложных перебиваний.
- **Статус:** не начата
