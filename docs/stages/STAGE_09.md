# Этап 9 — Оптимизация скорости

## Цель
Гарантированно выполнить NFR-01…NFR-05 и закрепить их автоматической проверкой. Веха M4.

## Зависимости
Этап 8.

## Критерии приёмки этапа
- [ ] NFR-01…NFR-05 выполнены на RTX 5070 Ti; отчёт `docs/perf/report-<дата>.md`.
- [x] TTFT с prefill-при-наборе ниже, чем без него, минимум на 30 % для реплик длиннее 15 слов (−34…−43 %).

## Подводные камни
- Оптимизация без замера запрещена (R-39). Часть «очевидных» оптимизаций на конкретном железе
  ничего не даёт — это нормально; решение фиксируется в ADR с цифрами.

## Сессии

### S-9.1 — Полный бенчмарк, baseline, профилирование
- **Цель:** бенчмарк по всем строкам бюджета, `bench/baseline.json`; py-spy под нагрузкой,
  asyncio debug-режим для поиска медленных колбэков.
- **Scope:** `tools/`, `bench/`
- **Читать:** `docs/performance.md`
- **Готово, когда:** [x] baseline сохранён (`bench/baseline.json`); блокировок event loop нет, запись в STATE.md.
- **Статус:** готово (`docs/perf/report-2026-11-03.md`)

### S-9.2 — Speculative prefill (ядро + UI)
- **Цель:** `input.typing` → `LLMPort.prefill()` (T-05): промпт по шаблону чата, запрос без
  генерации с `cache_prompt` в слот диалога; дебаунс, отмена устаревших префиллов.
- **Scope:** `adapters/llm/llamacpp.py`, `application/conversation/`, `ui/src/features/chat/`
- **Готово, когда:** [x] замер: −30 % TTFT для реплик > 15 слов: p50 96–112 → 64 мс (−34…−43 %),
  p95 129–147 → 75–76 мс (`tools.bench_latency --speculative`, 30 замеров × 2 раунда, RTX 5070 Ti).
- **Статус:** готово

### S-9.3 — Speculative decoding, параметры сервера
- **Цель:** черновая модель того же семейства (T-09) — включить при приросте ≥ 15 %; подбор
  `-c`, числа слотов, квантизации.
- **Scope:** `scripts/`, `config/`, `docs/adr/`
- **Готово, когда:** [x] ADR с цифрами «до/после» (ADR-0030: черновик +56 % TPS, но выключен).
- **Статус:** готово

### S-9.4 — Тюнинг TTS, гейт регрессий
- **Цель:** потоки CPU, прогрев, при необходимости синтез следующей фразы заранее; проверка, что
  фон не трогает слот диалога; гейт «регрессия p95 > 15 % = провал».
- **Scope:** `adapters/tts/`, `.github/`, `tools/`
- **Готово, когда:** [x] гейт роняет прогон при искусственной регрессии (`tools.perf_gate`, тест).
- **Статус:** гейт и проверка слота готовы; потоки TTS и заранее синтез — после замера на целевой машине
