# Этап 0 — Фундамент репозитория и процесса

## Цель
Репозиторий, инструменты контроля качества и система документации готовы так, что с первой
строки кода все правила проверяются автоматически, а ИИ работает сессионно.

## Зависимости
Нет.

## Критерии приёмки этапа
- [x] `pre-commit run --all-files` зелёный на пустом каркасе (CI повторяет те же шаги).
- [x] Нарушение слоя (тестовый импорт adapters из domain) роняет `lint-imports`.
- [x] Функция на 30 инструкций роняет ruff (`PLR0915`).
- [ ] Новая ИИ-сессия по промту из `docs/ai/WORKFLOW.md` называет текущую сессию и её scope,
      прочитав ≤ 6 файлов.

## Подводные камни
- Не начинать код ядра, «пока инструменты не готовы» — потом правила вводятся через боль.
