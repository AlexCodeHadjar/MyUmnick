# Этап 18 — Зрение и выразительность

## Цель
Персонаж видит показанное ему, точнее двигает ртом, жестикулирует по смыслу и умеет петь. Веха M13.

## Зависимости
Этапы 6, 7, 8. S-18.1, S-18.2 и S-18.5 — S-12.7 (менеджер ресурсов): модели на GPU делят VRAM с LLM.
Этап 13 от этого этапа не зависит.

## Критерии приёмки этапа
- [ ] Показанная картинка или снимок экрана учитывается в ответе; экран не снимается без явного действия.
- [ ] Рот совпадает со звуками речи и закрыт в паузах (ручной сценарий).
- [ ] Жест не задерживает речь и уместен на наборе реплик.
- [ ] Выключенные функции этапа не влияют на TTFT и TTFA.

## Подводные камни
- Зрение: у выбранной модели есть `mmproj` (0,18 ГБ), но `--mmproj` и картинка в запросе меняют TTFT
  и VRAM: замер обязателен. Качество без цензуры на картинках не проверено.
- Снимок экрана может содержать пароли и личные данные: только по явному действию, не сохранять на диск,
  в приватном режиме (S-17.2) и на стриме — отдельное предупреждение.
- Живая модель не генерирует фонемы сама: нужен выровненный текст или разбор звука; не сломать бюджет
  первой фразы.
- Жесты зависят от модели: всё модель-зависимое — только в `mapping.json` (ADR-0011).
- Пение: новая модель и лицензии (весов, обучающих данных) — через ADR. Чужие песни на стриме — вопрос
  авторских прав; клонирование голоса реального певца без разрешения не поддерживаем.

## Сессии

### S-18.1 — Зрение: картинка от пользователя
- **Цель:** прикрепить изображение к реплике; модель отвечает с учётом картинки. Поддержка в LLM-порте,
  адаптере и протоколе; запуск llama-server с `--mmproj`; модель без поддержки — понятный отказ.
- **Scope:** `src/vtuber/ports/llm.py`, `src/vtuber/adapters/llm/`, `gateway/`, `ui/src/features/chat/`,
  `scripts/`, `docs/adr/`
- **Готово, когда:**
  - [ ] Контрактный тест на заглушке; замер на RTX 5070 Ti: VRAM и TTFT с картинкой и без неё.
  - [ ] TTFT обычной реплики без картинки в бюджете.
- **Статус:** не начата

### S-18.2 — Зрение: экран
- **Цель:** снимок экрана или окна по явной команде («посмотри на экран»), с индикатором; без постоянного
  захвата и без записи на диск. Опирается на S-18.1.
- **Scope:** `ui/src-tauri/`, `ui/src/features/`, `application/tools/`, `docs/adr/`
- **Готово, когда:** [ ] без команды снимков нет (тест); [ ] ручной сценарий с выбором окна;
  [ ] снимок не остаётся на диске.
- **Статус:** не начата

### S-18.3 — Точный липсинк по фонемам
- **Цель:** форма рта по звукам речи (висемы), а не только по громкости (ADR-0003 — пересмотр): метки
  времени от движка или разбор звука, маппинг на параметры модели, откат к громкости при отсутствии данных.
- **Scope:** `ui/src/features/audio/`, `ui/src/features/avatar/`, `src/vtuber/adapters/tts/`,
  `ui/public/avatars/*/mapping.json`, `docs/adr/`
- **Готово, когда:** [ ] рассинхрон замерен на русских фразах; [x] TTFA не вырос сверх бюджета (ядро не менялось);
  [ ] 60 FPS (NFR-05); [x] модель без форм рта работает по громкости.
- **Статус:** код готов (ADR-0023); на настоящем голосе не проверено

### S-18.4 — Жесты по смыслу
- **Цель:** кивок, наклон головы, удивление и другие жесты по содержанию фразы: тег жеста от LLM по образцу
  тегов эмоций (`StreamParser`), набор жестов — из `mapping.json`, частота ограничена.
- **Scope:** `src/vtuber/domain/`, `application/pipeline/`, `application/prompting/`, `gateway/`,
  `ui/src/features/avatar/`
- **Готово, когда:** [x] теги жестов не попадают в текст и речь (тест); [ ] уместность замерена на
  наборе реплик по образцу S-8.1 (`tools.eval_gesture`, нужна настоящая модель); [x] неизвестный жест не ломает ответ.
- **Статус:** код готов; замер ждёт настоящей модели

### S-18.5 — Пение
- **Цель:** персонаж исполняет выбранную песню голосом персонажа: выбор движка (ADR), запуск вне горячего
  пути, воспроизведение с отменой; рот и эмоции работают при пении. Материал — с правами пользователя.
- **Scope:** `plugins/singing/`, `docs/adr/`, `docs/licenses.md`
- **Готово, когда:** [ ] ADR с лицензиями и замером VRAM; [ ] ручной сценарий на русском;
  [ ] обычный диалог не страдает, пока движок не используется.
- **Статус:** не начата
