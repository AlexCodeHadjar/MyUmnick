# Этап 19 — Голос персонажа по образцу

## Цель
Персонаж говорит голосом, склонированным по образцам с разрешения автора голоса, не теряя в скорости
ответа. Закрывает открытый выбор голоса (ADR-0014). Веха M14.

## Зависимости
Этапы 7 и 8. S-12.7 (менеджер ресурсов): модель на GPU делит VRAM с LLM. Движок пения в S-18.5 ждёт
выбора голоса на этом этапе. Этап 13 от этого этапа не зависит.

## Критерии приёмки этапа
- [ ] Голос выбран пользователем на слух и записан в ADR.
- [ ] TTFA p50 ≤ 800 мс и p95 ≤ 1200 мс на RTX 5070 Ti с настоящей LLM; пауз между фразами ≤ 80 мс сверх
  естественных (Этап 7).
- [ ] LLM и голос вместе помещаются в 16 ГБ VRAM.
- [ ] Без файлов движка или образцов приложение работает на Silero с понятным статусом.

## Подводные камни
- **Голос реального человека — только с его разрешения.** Разрешение подтвердил пользователь, 2026-11-03:
  голос можно использовать дома и на стримах; публикация записей и другое использование в него не входят.
  Для любого другого голоса нужно отдельное разрешение.
- Веса OmniVoice — CC BY-NC: монетизированный стрим с этим голосом потребует другого движка или другой лицензии.
- Образцы и готовые записи — вне git: `data/voice_refs/`, `bench/results/tts_samples/clone/`.
- Образцы получены из MP3/AAC, шум и музыка не убраны: потери и фон могут перейти в клон. Записи
  `video_speech_*` не использовать: голос в них не подтверждён, это личное сообщение.
- **FlashInfer — только Linux** (документация, 2026-11-03), а целевая машина на Windows. Цифры с ним (32 шага: короткая
  фраза 0,2 с против 1,7 с) сняты на Linux; на Windows без него укладывается только 8 шагов, а их качество пользователю
  не подошло. Варианты для ADR: голос в WSL2 (не проверено) или другой способ ускорения. Первый запуск на новой длине
  с CUDA Graph занимает 0,6–1,4 с: нужен прогрев (T-06).
- Манера речи копируется хуже тембра: сценка с эмоциями может звучать беднее исходной записи.
- Движки: OmniVoice — веса CC BY-NC; лицензию весов Qwen3-TTS Base проверить; Chatterbox требует
  torch 2.7.1 cu128 (sm_120). Цифры скорости сняты без клонирования (`docs/perf/gpu-run-2026-11-02.md`).
- Первая фраза у Qwen в прошлом прогоне ≈ 3 с: без потокового режима бюджет TTFA не выполняется.
- ИИ-ассистент не слушает звук: качество оценивает только пользователь.

- **Цель:** озвучить набор фраз на Qwen3-TTS Base 0.6B и 1.7B, OmniVoice и Chatterbox с каждым образцом;
  замерить задержку короткой фразы, RTF и VRAM; пользователь выбирает голос и лучший образец на слух.
- **Scope:** `scripts/remote/clone_voice.*`, `scripts/remote/README.md`, `docs/adr/`, `docs/licenses.md`
- **Читать:** ADR-0014, `docs/perf/gpu-run-2026-11-02.md`
- **Готово, когда:** [x] образцы подготовлены, текст распознан (проверка текста — за пользователем);
  [x] прогон на аренде и страница для прослушивания; [x] ADR: движок, лицензия, границы разрешения (ADR-0031).
- **Статус:** пользователь выбрал на слух OmniVoice (2026-11-03; веса CC BY-NC), образец `maomao_04`; скорость
  без других задач на GPU замерена (`clone_voice.py tune`). 8 шагов пользователю не подошли; 32 шага с FlashInfer
  звучат как 32 без него (на слух, 2026-11-03): короткая фраза 0,21 с, 5,6 ГБ, только Linux. Основной образец —
  `maomao_04` (решение пользователя, 2026-11-03). С LLM на одной карте: пик 14,5 ГБ из 16, голос при ответе
  LLM 0,26–0,54 с, TTFT p50 91 мс (голос шёл только часть замера; настоящий конвейер — S-19.3)
