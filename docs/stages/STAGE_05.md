# Этап 5 — UI-оболочка: окно, чат, сцена-заглушка

## Цель
Окно приложения: чат слева со стримингом, справа — место под модель.

## Зависимости
Этап 4. Нужны Node.js и pnpm (на машине разработки пока не установлены).

## Критерии приёмки этапа
- [ ] Ввод → первый символ ответа на экране укладывается в TTFT + ≤ 20 мс.
- [ ] 1000 сообщений в истории — прокрутка без лагов.
- [ ] Потеря ядра → UI показывает статус и переподключается без перезапуска окна.

## Сессии

### S-5.1 — Каркас Tauri + Svelte, инструменты, sidecar
- **Цель:** Tauri 2 + Svelte 5 + TS + Vite; eslint/prettier/svelte-check; строгий tsconfig
  (R-61); запуск ядра как sidecar (в разработке — отдельно); хуки и CI для `ui/`.
- **Scope:** `ui/` (каркас), `ui/src-tauri/`, `.pre-commit-config.yaml`, CI
- **Читать:** `docs/architecture.md` (Фронтенд), `docs/rules/code-rules.md` (J)
- **Готово, когда:**
  - [ ] `pnpm tauri dev` открывает окно; eslint/svelte-check/prettier зелёные.
- **Статус:** не начата

### S-5.2 — Transport и store
- **Цель:** `core/transport.ts` (переподключение с экспоненциальной паузой, разбор JSON и
  бинарных кадров, типы из protocol.gen.ts); `core/store.ts`.
- **Scope:** `ui/src/core/`
- **Готово, когда:**
  - [ ] vitest: разбор кадров, переподключение.
- **Статус:** не начата

### S-5.3 — Чат: список, ввод, стоп, батчинг
- **Цель:** виртуализированный список, ввод (Enter / Shift+Enter), «Стоп», батчинг токенов по
  кадрам (T-16), индикатор «печатает».
- **Scope:** `ui/src/features/chat/`
- **Готово, когда:**
  - [ ] Тест 1000 сообщений; DOM обновляется не чаще раза в кадр.
- **Статус:** не начата

### S-5.4 — Раскладка, статус-бар, панель метрик, карта UI
- **Цель:** две панели с перетаскиваемым разделителем (FR-01, ширина запоминается); статус
  LLM/TTS; панель метрик по горячей клавише (FR-15); раздел `ui/src` в карте проекта.
- **Scope:** `ui/src/app/`, `ui/src/features/metrics/`, `tools/`
- **Готово, когда:**
  - [ ] Ручной сценарий: перетаскивание, перезапуск — ширина сохранилась; метрики видны.
