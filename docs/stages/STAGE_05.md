# Этап 5 — UI-оболочка: окно, чат, сцена-заглушка

## Цель
Окно приложения: чат слева со стримингом, справа — место под модель.

## Зависимости
Этап 4. Node.js 24, pnpm 12, Rust (MSVC) и Visual C++ Build Tools (ADR-0009).

## Критерии приёмки этапа
- [x] Ввод → первый символ ответа на экране укладывается в TTFT + ≤ 20 мс (окно Tauri,
  фейковое ядро: 2–14 мс).
- [x] 1000 сообщений в истории — прокрутка без лагов (медиана кадра 6,9 мс, p95 9 мс).
- [x] Потеря ядра → UI показывает статус и переподключается без перезапуска окна.
