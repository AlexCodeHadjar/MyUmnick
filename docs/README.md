## Принципы

- **Docs-as-code:** документация живёт в репозитории и проходит ревью вместе с кодом.
- **Автогенерируемое не правится руками** и проверяется в CI на актуальность.
- **Один факт — одно место.** Список эмоций — в `domain/emotion.py`; протокол —
  в `gateway/protocol.py`; настройки инструментов — в `pyproject.toml` и `.importlinter`.
  Документы ссылаются, а не копируют.
- **Карточка модуля — контракт.** Код расходится с карточкой — это баг; исправляется одно из двух
  в том же PR.
