# Обмен блокнотом ПК ↔ карманный Умник (Этап 24, ADR-0050)

## Папка на телефоне
`Внутренняя память/Documents/UmNick/` — её выбирают один раз в приложении (шаг 4). ПК видит её по MTP, когда
телефон подключён кабелем в режиме **«Передача файлов»** и разблокирован. Отладка по USB не нужна.

| Файл | Кто пишет | Что |
|---|---|---|
| `notes.jsonl` | телефон | весь блокнот телефона, перезаписывается при каждой новой заметке |
| `from_pc.jsonl` | ПК | заметки из `data/notes.txt`, кроме пришедших с телефона |

Строка — JSON: `{"id": "…", "text": "…", "created": "ISO-8601", "origin": "phone"|"pc"}`.
`id` телефона — UUID; `id` ПК — `pc-` + 16 знаков SHA-1 текста строки (стабилен, повторов нет).

## ПК — плагин `phone_sync`
Включение: `uv pip install -e plugins/phone_sync` и `[plugins] enabled = ["phone_sync"]` в `config/user.toml`.
Проводник прячет расширения (`notes.jsonl` виден как «notes») — `mtp.ps1` сравнивает `System.FileName`.
- Раз в `poll_s` (5 с) `mtp.ps1 find` ищет портативное устройство с `Documents/UmNick`.
- При подключении и далее раз в ~2 мин: забрать `notes.jsonl` → новые `id` дописать в `data/notes.txt` →
  запомнить в `data/phone_sync.json` → положить `from_pc.jsonl`.
- Удаление не синхронизируется (ADR-0050).

## Телефон
- При запуске службы: прочитать `from_pc.jsonl` (новые `id` — в блокнот), записать `notes.jsonl`.
- Живой канал по Wi-Fi и перебежка персонажа — `docs/stages/STAGE_24.md`, раздел 4а (S-24.9…S-24.11).
