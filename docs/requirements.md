# Требования

Источник: мастер-план v1, разделы 1, 2.6, 13. Изменения — через ADR.

Приоритеты проекта (строго по порядку): **P1 — скорость ответа, P2 — правильность ответа,
P3 — расширяемость, P4 — внешний вид.**

## Цель

Настольное приложение (Windows в первую очередь, с возможностью переноса на Linux):

- справа — анимированная модель витюбера (Live2D, в перспективе VRM);
- слева — чат с этой моделью;
- «мозг» — локальная LLM, работающая без интернета;
- витюбер отвечает текстом и голосом, двигает ртом синхронно с речью и меняет эмоции по смыслу
  ответа;
- главная характеристика — скорость реакции: живой диалог, а не «запрос → ожидание → ответ».

## Ограничения

- Только локальные модели. Облачные API — лишь необязательный адаптер для сравнения качества.
- Потребительское железо: одна видеокарта 8–16 ГБ VRAM.
- Основной язык общения — русский (влияет на выбор LLM, TTS и STT).

## Не входит в MVP

- Дообучение (fine-tune) собственной модели.
- Собственный движок рендера аватара.
- Трекинг лица через веб-камеру.
- Сборки под Linux/macOS — после релиза 1.0.

## Определение успеха

1. На эталонном железе выполняются NFR-01…NFR-05.
2. На эталонном наборе вопросов (`docs/testing.md`, оценка качества) доля правильных ответов не
   ниже порога из ADR выбора модели (ориентир — 80 %).
3. Новый TTS-движок подключается за одну сессию ИИ без изменения кода вне своего адаптера.
4. ИИ-ассистент начинает продуктивную работу в новой сессии, прочитав не более ~6 документов.

## Аппаратные требования

**Целевая машина проекта (эталон для NFR и бенчмарков): RTX 5070 Ti 16 ГБ VRAM, 32 ГБ RAM.**
Это Blackwell (sm_120): llama.cpp нужна сборка с CUDA 12.8+.

| Уровень | GPU | RAM | CPU | Что получится |
|---|---|---|---|---|
| Минимум | 8 ГБ VRAM (RTX 3060 8GB / 4060) | 16 ГБ | 6 ядер | 7–8B Q4, TTS и STT small на CPU; NFR выполнимы с короткими ответами |
| **Эталон** | 12–16 ГБ VRAM (RTX 4070 / 4060 Ti 16GB / **5070 Ti**) | 32 ГБ | 8 ядер | 8–14B Q4/Q5, черновая модель для speculative decoding, STT на GPU |
| Комфорт | 24 ГБ VRAM | 64 ГБ | 8–16 ядер | 14–32B, качественный TTS на GPU, запас под плагины |
| Без GPU | — | 32 ГБ | 8+ ядер | 3–4B модели, медленно; только разработка и тесты |

Диск — NVMe SSD: загрузка модели 5–10 ГБ с HDD съест бюджет холодного старта.

Ориентиры скорости (проверяются на Этапе 2): 8B Q4 на картах среднего класса — 40–80 ток/с,
на топовых — больше 100. Для непрерывной речи этого хватает с запасом; узкое место — TTFT и TTS
первой фразы (`docs/performance.md`).
