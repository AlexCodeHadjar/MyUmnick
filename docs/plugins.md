# Плагины

Плагин добавляет возможность без правки ядра (FR-14): отдельный Python-пакет, который ядро находит
по entry point. Рабочий образец — `plugins/example/`.

## Как написать

1. Пакет с `pyproject.toml` и записью:

   ```toml
   [project.entry-points."vtuber.plugins"]
   example = "vtuber_example:ExamplePlugin"
   ```

2. Класс без аргументов конструктора. Он реализует `vtuber.kernel.Plugin`:

   | Член | Что делает |
   |---|---|
   | `name` | Имя; совпадает с именем entry point |
   | `async setup(ctx)` | Подписаться на события, запустить своё |
   | `async shutdown()` | Остановить запущенное в `setup` |

3. Плагин импортирует только `vtuber.kernel` и `vtuber.domain`. Остальные слои — внутренности
   ядра, они меняются без предупреждения.

## Что даёт `PluginContext`

| Член | Что делает |
|---|---|
| `subscribe(EventType, handler)` | Подписка на событие из `vtuber.domain` |
| `settings(Model)` | Секция `[plugins.settings.<имя>]`, проверенная наследником `ConfigSection` |
| `log` | Логгер; события попадают в общий JSON-лог с полем `module = plugin.<имя>` |

События: `TurnStarted`, `TurnFinished`, `TurnCancelled`, `TurnRemembered`, `EmotionChanged`,
`MetricRecorded`, `BackendStatusChanged`.

## Как подключить

```bash
uv pip install -e plugins/example
```

```toml
# config/user.toml
[plugins]
enabled = ["example"]

[plugins.settings.example]
label = "мой стрим"
```

`uv sync` без флага `--inexact` удаляет пакеты, которых нет в `uv.lock`, в том числе плагин: после
него плагин ставится заново.

Список `enabled` задаётся только в файле: переменная окружения передаёт строку, а не список.

## Гарантии ядра

- **Невключённый плагин не стоит ничего.** Он не импортируется; если список пуст, ядро не ищет даже
  entry points.
- **Плагин не задерживает ход.** Шина ждёт своих подписчиков, поэтому обработчики плагина идут из
  его собственной очереди, а не внутри `publish`. Они выполняются по одному, в порядке событий.
- **Плагин не роняет приложение.** Сбой при импорте, в `setup` (тайм-аут `setup_timeout_s`), в
  обработчике или в `shutdown` (тайм-аут `shutdown_timeout_s`) пишется в лог, остальное работает.
  Снятый пакет из `enabled` — только предупреждение `plugin.not_installed`.

## Ограничения

- Очередь плагина — 256 событий. Переполнилась — новые события теряются с записью
  `plugin.event_dropped`: не делайте в обработчике долгую работу, если важно не терять события.
- Плагин работает в одном процессе и цикле событий с ядром. Защиты от блокирующего кода нет:
  блокирующий вызов в корутине остановит всё приложение, поэтому его выносят в `asyncio.to_thread`
  (R-34). Изоляции и прав тоже нет: ставьте только плагины, которым доверяете.
