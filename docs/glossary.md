# Глоссарий

| Термин | Значение |
|---|---|
| ADR | Architecture Decision Record — короткий документ об одном архитектурном решении |
| Barge-in | Перебивание: пользователь начинает говорить, витюбер замолкает |
| GGUF | Формат файлов моделей для llama.cpp, поддерживает квантизацию |
| KV-кэш | Сохранённые вычисления внимания для обработанных токенов; позволяет не пересчитывать префикс |
| Prefill | Обработка входного промпта моделью до генерации первого токена |
| Speculative prefill | Обработка черновика промпта заранее, пока пользователь печатает/говорит |
| Speculative decoding | Ускорение генерации: маленькая модель предлагает токены, большая проверяет пачкой |
| Квантизация (Q4_K_M и т.п.) | Сжатие весов до 4–5 бит: меньше VRAM, быстрее, немного хуже качество |
| Липсинк | Синхронизация движения рта со звуком |
| Порт / адаптер | Интерфейс, которым ядро описывает потребность / его реализация для конкретной технологии |
| Корень композиции | Единственное место, где создаются и связываются все объекты приложения |
| RAG | Retrieval-Augmented Generation — поиск релевантных данных и добавление их в промпт |
| RTF | Real-Time Factor — время синтеза, делённое на длительность синтезированного звука |
| Sidecar | Вспомогательный процесс, запускаемый и управляемый основным приложением (Tauri) |
| Слот (llama.cpp) | Независимый поток обработки запросов со своим KV-кэшем |
| SSE | Server-Sent Events — потоковая передача ответа по HTTP |
| TTFT / TTFS / TTFA | Время до первого токена / первой фразы / первого звука |
| VAD | Voice Activity Detection — определение, говорит ли человек |
| Визема | Визуальная форма рта, соответствующая звуку речи |
| Горячий путь | LLM → парсер → нарезка → TTS → sink: всё, что лежит между Enter и первым звуком |
| Expandable Application | Термин лицензии Live2D: приложение, загружающее произвольные модели (аватар-системы) |
