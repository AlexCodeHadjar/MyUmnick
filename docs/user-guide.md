# Руководство пользователя

## Издания: русское и английское

Программа запускается в одном из двух изданий (ADR-0032):

| | Русское (`RU`) | Английское (`EN 18+`) |
|---|---|---|
| Язык интерфейса, ответов, голоса, слуха | русский | английский |
| Персона | Мика | Mika (тот же характер) |
| Содержание | обычное | без цензуры (ADR-0033): мат, чёрный юмор, взрослые темы |
| Голос | как в настройках (Silero или голос по образцу) | Kokoro `af_heart`, запасной — Piper ljspeech |
| Память | `data/memory.sqlite`, `data/vault` | `data/en/` — своя, отдельная |

### Как выбрать
- При запуске открывается экран с двумя плитками. Мышь: клик по плитке. Клавиатура: `←`/`→`, `Enter`, `1`/`2`.
- Английское издание при первом выборе просит подтвердить, что вам есть 18 лет — один раз.
- «Запоминать выбор» — дальше программа сразу запускается в последнем издании.
- Сменить издание: значок `RU` / `EN 18+` в строке статуса → «Перезапустить». Текущий ход прерывается, ядро
  закрывается и открывается экран выбора.

### Жёсткий минимум
Даже без цензуры персона не участвует в сексуальном содержании с несовершеннолетними, не пишет сексуальных сцен с
реальными людьми и не выдаёт выдумки о реальных людях за правду. Это не отключается.

### Настройки изданий
- Отличия издания — `config/editions/<издание>.toml` (не правьте без нужды).
- Свои настройки для обоих изданий — `config/user.toml`, но персона, голос, язык слуха и пути памяти из него
  действуют только в русском издании. Для английского — `config/user.en.toml`.
- Разработчику: `uv run python -m vtuber serve --edition en` (или `VTUBER_EDITION__ID=en`).

### Плагины
В английском издании запускаются только плагины, которые знают английский (`obs`, `code_assistant`). Остальные
пропускаются с записью `plugin.language_unsupported` в логе.

### Помощник-программист
Одна модель для кода на оба издания, работает на английском. В русском издании просьбу сначала переводит
основная модель, в английском — передаёт как есть.
