# S-13.2 — Мастер первого запуска · 2026-11-03

## Сделано
- `application/setup`: каталог, рекомендация по VRAM, установка с докачкой и суммами, сценарий мастера.
- `adapters/setup/HttpFetcher`, порт `FileFetcher`; `config/catalog.toml` (10 файлов, ревизии закреплены).
- `config/setup.toml` как отдельный слой конфига (default < setup < user < env); `SetupFailed`.
- Протокол: `setup.install`, `setup.cancel`, `setup.state`, `setup.progress`, `setup.finished`; разделён на
  `protocol_base.py`, `protocol.py`, `protocol_extras.py` (лимит длины файла).
- UI: `features/onboarding`, выбор голоса и аватара; `restart_app` в Tauri.
- Заодно: замена клиента больше не пишется как `connection handler failed`.

## Решения
- Без модели окно открывается: `LlamaServerProcess` не запускает сервер, если файла модели нет.
- Мастер включается только в поставке (`[setup].enabled`): при разработке модели лежат отдельно.
- Выбор пишется в отдельный файл: мастер не должен затирать правки пользователя в `user.toml`.
- Модели подхватываются при старте, поэтому после установки приложение перезапускается.
- Суммы: Hugging Face (LFS) и прямое хеширование файла; модель LLM — из `scripts/remote/models.tsv`.
- Отступление от scope: kernel/config, адаптер LLM, шлюз, bootstrap, `lib.rs`.

## Проверки
- Настоящий `serve` с локальной раздачей: без согласия на диске пусто; прерывание оставляет `.part` и не пишет
  конфиг; повтор ставит файлы нужного размера и пишет выбранный голос.
- В браузере: мастер показал память и предупреждение, кнопка неактивна без согласия, прогресс, экран завершения.
- Настоящая сеть: файл каталога с Hugging Face, сумма и докачка совпали.
- Не проверено: загрузка настоящих моделей целиком, окно Tauri и перезапуск, чистая машина, собранное ядро.
  Панель браузера не крутит rAF, когда скрыта: часть сценария пройдена напрямую по WebSocket.
