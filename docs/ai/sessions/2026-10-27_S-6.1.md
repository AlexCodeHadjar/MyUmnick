# S-6.1 — Версии, лицензия, ADR, интерфейс AvatarRenderer · 2026-10-27

## Цель
Связка версий PixiJS + движок Live2D + Cubism Core; решение по лицензии Live2D; интерфейс
`AvatarRenderer` (`load`, `setEmotion`, `setMouth`, `lookAt`, `react`, `update`, `dispose`).

## Сделано
- Сравнение движков по npm (2026-10-27): `untitled-pixi-live2d-engine` 1.4.0 (MIT, PixiJS 8,
  Cubism 2–5, выпуски 2026-01…2026-09); `@naari3/pixi-live2d-display` 1.2.5 (последний выпуск
  2025-11); исходный `pixi-live2d-display` 0.4.0 (PixiJS 6, 2023); официальный Cubism Web
  Framework (без Pixi, своя обвязка).
- ADR-0011: PixiJS 8 + untitled-pixi-live2d-engine ^1.4 + Cubism Core 5 от пользователя;
  лицензия — личное использование без распространения; файлы Core и модели — вне git.
- `ui/src/features/avatar/AvatarRenderer.ts` + `index.ts`: контракт с `resize()` (масштаб под
  панель, S-6.2) и `AvatarReaction` (`idle`/`listening`/`thinking`, T-17); `core` экспортирует
  `Emotion`.
- `.gitignore`: `ui/public/live2d/`, `ui/public/avatars/**` кроме `mapping.json` (проверено
  пробными файлами).
- `docs/licenses.md`, `docs/stack.md`, STAGE_06 (S-6.1 готово; путь `mapping.json` для S-6.3),
  `ui/README.md`, STATE.

## Решения
- Движок выбран по живости проекта и Cubism 5; риск «маленькой команды» закрыт контрактом
  `AvatarRenderer` — замена движка не трогает остальное UI.
- Пакеты не ставятся в S-6.1: зависимости приходят вместе с кодом, который их использует
  (S-6.2); версии зафиксированы в ADR.
- `setMouth`/`lookAt` только запоминают цель, применяет `update()`: звук и курсор могут звать их
  чаще кадра без лишней работы (R-65/R-66).
- Модели в `ui/public/avatars/` (Vite отдаёт `public/` как есть), а не в корневом `avatar/`, как
  было в плане S-6.3, — иначе понадобился бы свой сервер файлов или копирование при сборке.
- Тесты не добавлены: в S-6.1 нет логики — только типы (проверены `svelte-check`).
