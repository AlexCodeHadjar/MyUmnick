# S-16.3 — Поиск актуальной информации · 2026-11-03

## Сделано
- `plugins/web_search`: явная просьба, запрос к локальному SearXNG, справка как чужой текст, источники.
- `ContextTool`: у долгого инструмента свой срок; реплики без просьбы завершаются сразу. `report_sources`, `chat.sources`.
- ADR-0022: исключение из NFR-06.

## Решения
- Плагин выключен по умолчанию и не импортируется: офлайн-режим остаётся как был.
- Адрес только localhost: прямой запрос к чужому сервису конфигом не разрешить.
- Модель сама поиск не запускает: только правило на реплику ведущего.

## Проверки
- Фейковый SearXNG: запрос только по просьбе, тайм-аут и сбой дают честный ответ, страница с атакой отброшена, разметка вычищена.
- Не проверено: настоящий SearXNG (его нужно ставить отдельно) и как модель пользуется справкой.
