# S-6.2 — Live2D: загрузка, idle, моргание, дыхание, взгляд · 2026-10-27

## Цель
Загрузка `.model3.json`, idle-моушены, авто-моргание, дыхание, слежение за курсором, масштаб под
панель; цикл рендера вне Svelte, пауза при сворачивании (R-66).

## Сделано
- Модель Haru (образцовая, Live2D Inc., Free Material License) из архива пользователя:
  `runtime/` и `ReadMe.txt` → `ui/public/avatars/haru/` (вне git). Редакторские `.cmo3`/`.can3`
  не нужны приложению — не скопированы.
- Пакеты `pixi.js` 8.22.0 и `untitled-pixi-live2d-engine` 1.4.0 (ADR-0011).
- `live2d/core-loader.ts`: Cubism Core подключается `<script>` до импорта движка (движок
  проверяет `window.Live2DCubismCore` при импорте); нет файла — понятная ошибка, повтор возможен.
- `live2d/Live2DRenderer.ts`: Pixi `Application` без автозапуска, `Live2DModel.from` с
  `autoUpdate/autoFocus/autoHitTest: false`, вписывание в сцену (`fit.ts`), idle-группа `Idle`;
  рот — индексы параметров группы `LipSync` (иначе `ParamMouthOpenY`), запись в
  `beforeModelUpdate`; взгляд — `focusController.focus(x, y)`; `pixi.js/unsafe-eval` под CSP.
- `loop.ts`: `AvatarLoop` — rAF вне Svelte, пауза по `visibilitychange`, шаг ≤ 100 мс, первый
  шаг после паузы — 0.
- `session.ts` + `AvatarStage.svelte`: жизнь модели (создание, загрузка, кадры, ResizeObserver,
  курсор), статус «загрузка/ошибка» на сцене. `App.svelte` монтирует сцену; модель —
  `VITE_AVATAR=haru` в `ui/.env`.
- Тесты: `loop`, `core-loader`, `fit`, `session` — 22 новых, всего 103.

## Решения
- Pixi и движок — динамический импорт: основной бандл 63 КБ, Pixi (600 КБ) и движок (220 КБ)
  грузятся после окна; чат не ждёт аватара.
- Моргание, дыхание, физика, покой — силами движка (Cubism Framework): своя реализация дала бы
  то же, но больше кода.
- Индексы параметров рта — один раз при загрузке: в кадре только запись по индексу.
- API движка изучено по исходникам на GitHub и проверкам компилятора (пробные файлы, удалены) —
  `node_modules` не читались (AGENTS.md).
- `setEmotion`/`react` — заглушки до `mapping.json` (S-6.3).

## Проверки
- `pnpm test` — 103 passed; `pnpm lint`, `pnpm check`, `pnpm build` — зелёные.
- Сборка: основной чанк не импортирует Pixi статически (нет modulepreload).
- Браузер без Core: сцена — «Модель «haru» не загрузилась: Нет Cubism Core: положите
  live2dcubismcore.min.js …», чат и статус работают.
- Живая проверка (после того как пользователь принял лицензию Live2D):
  - Core 6.0.1 из SDK 5-r.5: модель грузится, но движок падает в каждом кадре
    (`doDrawModel`: `Cannot read properties of undefined (reading '0')`). Отладчик CDP (пауза на
    исключении): `renderOrder` — undefined. В Core 6 нет `drawables.renderOrders` (теперь
    `model.getRenderOrders()`); у движка — открытый issue #11, совет — Core из SDK 5-r.4.
  - Добавлена проверка версии Core в загрузчике: Core ≥ 6 → понятная ошибка на сцене.
  - Core 5.1 из `CubismSdkForWeb-5-r.4.zip` (официальный сервер Live2D, 18.9 МБ, скачан по
    разрешению пользователя): Haru рисуется, ошибок нет — CSP окна пропускает Pixi и Core.
  - Кадры (экран 146 Гц): покой 139 к/с, стриминг (фейковое ядро) 140 к/с, медиана 6.9 мс,
    p99 7.2 мс; 2 кадра из 843 дольше 20 мс (максимум 90 мс — вероятно, сборка мусора).
  - Взгляд за курсором и перевписывание при ширине сцены 369 px — работают.
  - Фигура Haru выходит за свой холст (ноги обрезаны снизу) — кадр модели настроим в
    mapping.json (S-6.3).
