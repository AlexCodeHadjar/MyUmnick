# S-7.7 — Бенчмарк TTFA, ADR голоса · 2026-10-29

## Цель
TTFA, RTF и паузы между фразами в бенчмарке; ADR выбора голоса по таблице «качество × RTF ×
TTFA × лицензия».

## Сделано
- `tools/bench_voice.py` — бенчмарк голоса на настоящем `ReplyPipeline`:
  - `TimedTTS` — обёртка `TTSPort`, меряет синтез каждой фразы (`PhraseTiming.rtf`);
  - `VoiceProbe` — `ReplySink`: первый видимый текст (TTFT), приход и длительность фрагментов;
  - `playback_stalls` — паузы, в которые плеер остался бы без звука;
  - `ScriptedLLM` — LLM-заглушка (TTFT, темп, ответы 1–3 предложения с тегом эмоции) для
    машины без сервера;
  - итог: TTFT, TTFA, «TTFA − TTFT», худшая пауза ответа, RTF фраз; `--out` — JSON.
- `tools/bench_latency.py`: дробные значения в таблице — с тремя знаками (RTF 0.05 был «0.0»).
- ADR-0014: голос по умолчанию — Silero v5_6_ru `xenia` 48 кГц; Piper `denis` — запасной и путь
  к публикации; `audio.played` — вместе с состоянием «говорит».
- `docs/licenses.md` — ссылки на ADR-0014; `docs/performance.md` — как мерить голос.
- Тесты `tests/tools/test_bench_voice.py` (7 + медленный с Silero).

## Решения
- Голосовой бенчмарк — отдельный модуль, а не флаг `bench_latency`: файл LLM-бенчмарка
  превысил бы 250 строк (R-10); общее (`percentile`, `Stats`, `render`) импортируется оттуда.
- TTFA без целевой машины — с LLM-заглушкой на бюджете NFR-01 (TTFT 250 мс), плюс «TTFA −
  TTFT» — вклад голоса, переносимый на любую LLM. Критерий Этапа 7 «TTFA p50 ≤ 800 на RTX 5070
  Ti» остаётся открытым до прогона с настоящей LLM.
- Паузы меряются по фрагментам ядра: плеер начинает с первым фрагментом и играет подряд;
  тишина, синтезированная внутри фразы, — естественная и не считается.
- Выбор голоса решила персона: русские CC0-голоса Piper — мужские, Мика — женский образ.
- Качество 1–5 — предварительно, не на слух (ассистент звук не слушает): оценку ставит
  пользователь, таблица в ADR-0014.
- **Отступление от scope** (`tools/bench_latency.py`, `docs/adr/`, `docs/licenses.md`): новый
  `tools/bench_voice.py` с тестом, строка в `docs/performance.md` («Как измеряем»).

## Проверки
- `pytest` (с `-m slow` для нового модуля) — зелёный; ruff, mypy --strict, import-linter,
  длина файлов — зелёные.
- Бенчмарк (машина разработки, 40 реплик, 88 фраз, TTFT заглушки 250 мс):
  - Silero, 40 ток/с: TTFA p50 516–545 / p95 595–615 мс; «TTFA − TTFT» p50 245–257 мс;
    RTF фраз p50 0.039–0.047 / p95 0.054–0.080; пауз сверх звука нет.
  - Piper, 40 ток/с: TTFA p50 550 / p95 614 мс; RTF p50 0.041 / p95 0.056.
  - 80 ток/с: TTFA p50 438 (Silero) / 428 (Piper); «TTFA − TTFT» 157 мс.
- Не проверено: TTFA с настоящей LLM (целевая машина); качество голосов на слух.
