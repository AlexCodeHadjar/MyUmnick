# S-12.3 — OBS-плагин · 2026-11-03

## Сделано
- `plugins/obs`: OBS WebSocket 5 на `websockets` (вход с паролем, переподключение), субтитры, сцены.
- Событие `PhraseVoiced(text, starts_in_s, duration_s)` из `Speaker`; `Voice.on_phrase`.
- `EmotionChanged` теперь публикуется: событие было описано в домене, но его никто не отправлял.

## Решения
- Субтитры привязаны к звуку, а не к тексту: синтез в 40 раз быстрее речи, по тексту последняя фраза
  появилась бы, пока звучит первая. Время считается по длительности отданных кадров.
- Отдельная библиотека OBS не нужна: протокол простой, `websockets` уже есть (новой зависимости нет).
- Отступление от scope: домен, `Speaker`, сервис хода, `container.py`, `pyproject.toml`.

## Метрики
- Горячий путь: одна публикация на фразу и одна на эмоцию; без подписчиков `publish` выходит сразу.
  Отдельный замер до/после не делался.

## Проверки
- Тесты на фейковом сервере OBS.
- Настоящий OBS 33.0.1 (портативный, Windows), состояние читалось через его API:
  - вход с паролем; неверный пароль — клиент не падает и пробует снова;
  - приложение целиком: `serve`, настоящий Silero, заглушка LLM. Ход занял 0.5–0.7 с, звука 11.9 с; фразы
    сменились на +0.5, +4.1, +8.3 с, текст исчез на +12.0 с;
  - сцена по `happy` сменилась, по эмоции не из карты — нет; «Стоп» стирает субтитр сразу;
  - опечатка в сцене — `obs.request_failed` в логе, соединение живо;
  - закрытие и новый запуск OBS: клиент переподключается сам, диалог без OBS идёт.
- Не разобрано: проверочный скрипт дважды завис при опросе OBS, перезапущенного посреди работы `serve`, хотя
  диалог без OBS работал, а отдельная проверка переподключения прошла. Причина неизвестна.
- Не проверено: субтитры глазами в эфире и совпадение со звуком на слух (время — по длительности кадров).
