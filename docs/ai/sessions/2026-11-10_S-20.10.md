# S-20.10 — Перенос фактов между изданиями · 2026-11-10

## Сделано
- `application/memory/transfer.py`: `FactTransfer` (выгрузка во входящие другого издания, приём своих входящих,
  перевод), `TransferRequests` (выгрузка по просьбе UI и приём при старте — в простое, `IdleScheduler`).
- Переводит только русское ядро — и при выгрузке ru → en, и при приёме en → ru: английская модель знает только
  английский. Повторы при приёме отсекаются по тексту, затем сверка индекса с заметками (ADR-0020); принятые
  входящие переименовываются в `facts.jsonl.done`; неудачный перевод оставляет их на следующий запуск.
- `[memory].inbox`, `[memory].transfer_to` (у `en` — зеркально; языковые ключи издания).
- Протокол: `memory.transfer` (UI → ядро), `memory.transferred` (итог); `MemoryBridge`, `MemoryControls.transfer`.
- UI: кнопка в панели памяти, итог и статус «в простое» на языке издания.
