# S-9.2 — Speculative prefill (ядро + UI) · 2026-10-29

## Цель
`input.typing` → `LLMPort.prefill()` (T-05): промпт по шаблону чата, запрос без генерации с
`cache_prompt` в слот диалога; дебаунс, отмена устаревших префиллов.

## Сделано
- Протокол: `InputTyping` (`input.typing`, `{ text }`) во входящих; `protocol.gen.ts` и
  `docs/protocol.md` перегенерированы.
- Шлюз: `input.typing` → `ConversationService.typing(text)` без ответа клиенту.
- `ConversationService.typing(draft)`: только между ходами (IDLE); промпт — `PromptBuilder.build`
  (история + черновик), как у будущего хода; пустой и повторный черновик пропускаются; новый
  черновик и `handle()` отменяют устаревший прогрев; ошибка прогрева — лог `prefill.skipped`.
- `ReplyPipeline.prefill(messages)` — прогрев через LLM конвейера, замер `llm.prefill`.
- Адаптер llama.cpp не менялся: `prefill` (`/apply-template` → `/completion`, `n_predict: 0`,
  `cache_prompt`, `id_slot`) уже был с Этапа 2 (T-06).
- UI: `CoreClient.typing(text)`; транспорт не копит `input.typing` при разрыве;
  `chat/typing.ts` — `TypingDebouncer` (300 мс), `Composer` → `ontyping`, отправка снимает
  ожидающий черновик.
- `tools/bench_latency.py --speculative` — перед каждым замером прогрев черновиком (реплика без
  последнего слова), вне замера: сравнение с обычным прогоном даёт эффект T-05.
- Тесты: `test_typing_prefill.py` (6), шлюз (`input.typing` по сокету), протокол, бенчмарк
  (`run_speculative_bench`, CLI с заглушкой), UI (`typing.test.ts`, транспорт, клиент).

## Решения
- Прогрев только между ходами: во время ответа слот llama-server занят генерацией, а история ещё
  без ответа — прогрев промпта без него не совпал бы с будущим запросом.
- Черновик — вся история + текст поля: llama-server переиспользует общий префикс, поэтому даже
  недописанная реплика экономит prefill всего, что до неё.
- Отмена прогрева при отправке — на стороне ядра (клиент httpx); сервер может дорабатывать уже
  начатый прогрев — настоящий запрос тогда ждёт его в слоте. Проверить на целевой машине.
- Замер критерия −30 % TTFT невозможен без настоящей LLM: подготовлен `--speculative` в бенчмарке.
- **Отступление от scope** (`adapters/llm/llamacpp.py`, `application/conversation/`,
  `ui/src/features/chat/`): `gateway/{protocol,server,__init__}.py`,
  `application/pipeline/reply_pipeline.py`, `ui/src/core/{client,transport}.ts`,
  `tools/bench_latency.py`, сгенерированные `protocol.gen.ts` и `docs/protocol.md`; тесты
  `test_gen_protocol.py` и `test_bench_voice.py` (порог таймера Windows).
