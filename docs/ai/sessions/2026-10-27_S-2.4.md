# S-2.4 — Бенчмарк задержки и eval-заготовка · 2026-10-27

## Цель
`tools/bench_latency.py` (TTFT, TPS, p50/p95), `bench/prompts_ru.jsonl` (30–50 реплик),
`eval/qa_ru.jsonl` (первые 50 вопросов), базовый `tools/eval_quality.py`.

## Сделано
- `tools/jsonl.py` — чтение JSONL с проверкой pydantic и `файл:строка` в ошибке.
- `tools/llm_client.py` — адаптер по имени из конфига приложения (`BACKENDS`), сбор ответа,
  временный системный промпт Мики (общий для бенчмарка и eval).
- `tools/bench_latency.py` — прогрев (prefill системного промпта + неучитываемый ответ), реплики
  по кругу, TTFT / ответ целиком / TPS, p50/p95/max методом ближайшего ранга, таблица, `--out`
  JSON; коды возврата 0 / 1 (сбой) / 2 (сервер недоступен).
- `tools/eval_checks.py` — проверки `any_of`, `none_of` (с начала слова, регистр и «ё» не
  важны, числа не совпадают с более длинными), `refusal`, `max_sentences`, `no_markdown`
  (+ эмодзи), `min_cyrillic_ratio`; теги эмоций убираются.
- `tools/eval_quality.py` — диалог по репликам кейса с историей, таблица по категориям, список
  непройденных с ответами, `--out` JSON.
- `bench/prompts_ru.jsonl` — 40 реплик (10 коротких, 15 средних, 10 длинных, 5 о памяти).
- `eval/qa_ru.jsonl` — 50 кейсов: knowledge 15, honesty 10, persona 10, memory 8 (внутри
  разговора), russian 7.
- Тесты `tests/tools/`: `test_jsonl.py` (4), `test_bench_latency.py` (7), `test_eval_quality.py`
  (19); CLI обоих скриптов — против заглушки на настоящем HTTP; валидность файлов репозитория.
- Документы: `docs/performance.md` (методика бенчмарка), `docs/testing.md` (формат кейсов,
  проверки, предупреждение про honesty), STAGE_02.

## Решения
- Реплики по кругу: повтор одной реплики подряд целиком попадает в KV-кэш и занижает TTFT.
- TPS — по дельтам после первой: у llama-server одна дельта ≈ один токен; точные `timings`
  сервера адаптер не отдаёт (если понадобятся — Этап 9).
- Межсессионная память (`<new_session>`) не включена: до Этапа 10 такие кейсы заведомо
  провалились бы и исказили сравнение моделей в S-2.5.
- `main` синхронная: чтение/запись файлов вне event loop (ruff ASYNC), LLM — через `asyncio.run`.
- `BACKENDS` в tools — словарь имя → класс; полноценный выбор через `Registry` — в bootstrap
  (S-3.5).
- ruff: `src = ["src", "."]` — `tools` и `tests` считаются своими при сортировке импортов;
  в тестах разрешён `FBT001` (bool-параметры в parametrize).
