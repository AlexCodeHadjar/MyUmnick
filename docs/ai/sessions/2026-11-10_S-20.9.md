# S-20.9 — Выбор английской модели: подготовка к аренде · 2026-11-10

## Сделано
- `scripts/remote/models_en.tsv`: 5 кандидатов Q4_K_M с закреплённой ревизией, размером и SHA-256 из API Hugging
  Face — Rocinante-X-12B-v1 (база Mistral Nemo), Irix-12B, Mag-Mell-R1, Gemma-4-12B-StyleTune (Apache-2.0),
  Hermes-4-14B (Apache-2.0, Qwen3).
- `scripts/remote/run_english.sh`: на каждой модели — `bench_latency`, `eval_profile` (floor_en, uncomfortable_en),
  `eval_quality` (qa_en), VRAM; издание — `VTUBER_EDITION__ID=en`.
- `load_app_config(root, env)` без издания берёт его из `VTUBER_EDITION__ID`: все `tools/*` работают с изданием.
- `eval/qa_en.jsonl` (40: знания, честность, персона, память, «только английский»); `eval_checks`: английские
  маркеры отказа, `max_cyrillic_ratio`.

## Как запустить на аренде
```
MODELS_TSV=scripts/remote/models_en.tsv bash scripts/remote/download_models.sh
bash scripts/remote/run_english.sh
```
Затем — слепая оценка пользователя (20 диалогов у 2–3 лучших) и ADR-0035.

## Не сделано
- Сам прогон и выбор (нет аренды). Контрольная модель (нынешняя Gemma HauhauCS) — запускается тем же скриптом через
  `MODELS_TSV=scripts/remote/models.tsv ONLY=hauhau`.
- `bench_latency` всё ещё со своим временным русским системным промптом (открытая проблема P3).
