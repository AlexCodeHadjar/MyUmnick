# S-20.1 — Издание в ядре: конфиг, аргумент, данные · 2026-11-09

## Цель
`--edition` / `[edition]`, слои `editions/<id>.toml`, `setup.<id>.toml`, `user.<id>.toml`, раздельные пути данных
`en`; `ru` без изменений.

## Сделано
- План Этапа 20 (`docs/stages/STAGE_20.md`): издания, экран выбора, профиль без цензуры, короткий список английских
  моделей, голос, ответы пользователя (общая английская модель для кода — 4.10).
- Домен: `EditionId`, `ContentProfile`.
- `kernel.ConfigFiles`: `edition`, `edition_user`, `user_ignored`; порядок
  default < edition < generated < user (без `user_ignored`) < edition_user < env.
- `bootstrap/edition.py`: `EditionConfig`, `resolve_edition`, `edition_files`, `check_edition`,
  `ignored_user_keys`, `LANGUAGE_BOUND_KEYS`; `load_app_config(root, env, edition=ru)`.
- `python -m vtuber [chat|serve] --edition en`; предупреждение `config.user_keys_ignored` в логе.
- `config/editions/ru.toml`, `en.toml` (память `data/en/`, Whisper `en`, имена, `setup.en.toml`); `[edition]` в
  `default.toml`.

## Решения
- ADR-0032: издание — слой конфига и свои данные, выбирается до старта ядра.
- Языковые ключи общего `user.toml` вне `ru` отбрасываются, а не только предупреждаются: в `user.toml` пользователя
  русская персона и голос по образцу — без этого они попали бы в английское издание.
- `[edition].id` после загрузки сверяется с выбранным: переменная или файл не подменят издание молча.
