## Решения
- Точка входа — `python -m vtuber`: gateway не может импортировать bootstrap (контракт слоёв),
  поэтому `python -m vtuber.gateway.cli` из плана невозможен.
- Реестр адаптеров собирается функцией в bootstrap, а не модульной переменной (R-04).
- В истории — реплика без справки (`context`): закрыт вопрос P2 из S-3.1.
- Ctrl+C завершает чат; прерывание ответа — новой строкой или `/stop` (обработка SIGINT поверх
  `asyncio.run` усложнила бы код без пользы для M1).
- Неизвестный `[llm].backend` выясняется уже внутри `asyncio.run` — `ConfigError` ловится и там
  (найдено тестом).
- `__main__.py` исключён из покрытия (запуск процесса); `run()` покрыт тестом.
