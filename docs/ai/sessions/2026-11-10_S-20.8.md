# S-20.8 — Плагины, мастер, руководство · 2026-11-10

## Сделано
- `PluginContext.language`; плагин объявляет `languages`, без атрибута — только `ru`; в `en` такие не запускаются
  (`plugin.language_unsupported`). Оба языка: `obs`, `code_assistant`. `docs/plugins.md`.
- `code_assistant`: английские просьбы и «cancel code», тексты для персоны на языке издания; в `en` запрос уходит
  модели для кода без перевода, в `ru` — переводит модель общения (решение пользователя).
- Мастер: `SetupCatalog.voice_setting` (куда писать голос); `config/catalog.en.toml` — Kokoro (размер и SHA-256
  сверены с релизом), запасной Piper ljspeech medium; `[setup].catalog_file` в `editions/en.toml`.
- `docs/user-guide.md` — издания, жёсткий минимум, настройки, плагины.

## Проверки
- pytest: плагины, мастер, каталоги обоих изданий.

## Осталось / проблемы
- Поставка (S-13.3, по команде): `build_sidecar.py` пишет только `setup.toml` — английскому изданию нужен ещё
  `setup.en.toml` с `[setup] enabled = true`, иначе мастер в `en` не откроется.
- `stream_chat`, `stream_director`, `tools`, `web_search`, `singing` — только русский.
- Замер `en` на аренде (TTFT, TTFA, eval) — вместе с S-20.9.
