# S-7.3 — Адаптер Silero · 2026-10-28

## Цель
`SileroTTS`: модель грузится один раз (R-40), синтез в `asyncio.to_thread`, ограничение потоков
CPU, PCM s16le. Контрактный тест проходит; RTF замерен.

## Сделано
- ADR-0012: Silero v5_6_ru (CC BY-NC 4.0 — личное использование, выбор пользователя), torch
  CPU-сборки и NumPy — необязательная группа `silero` (`[project.optional-dependencies]`, индекс
  `download.pytorch.org/whl/cpu`); установлены torch 2.14.1+cpu, numpy 2.5.4.
- Модель скачана с официального сервера: `models/tts/silero/v5_6_ru.pt` (147 664 410 байт, вне
  git). Проба API: `apply_tts(text, speaker, sample_rate, put_accent, put_yo, …)`, голоса aidar,
  baya, kseniya, eugene, xenia; 8/24/48 кГц.
- `adapters/tts/silero.py`: `SileroConfig` (`[tts.silero]`), `SileroTTS` — загрузка в
  `async with` (модели нет — `TTSUnavailable` при синтезе с подсказкой, откуда скачать), синтез в
  потоке под `threading.Lock`, перевод в s16le (`to_pcm`, обрезка за шкалой), фрагменты по
  `chunk_ms`, уступка цикла между фрагментами, фраза без букв — тишина, ошибка движка —
  `GenerationFailed`. Карточка `adapters/tts/README.md`.
- Контракт: `TTSCase` «silero» (`tts_params()` с метками `slow` и `skipif` без модели); torch
  импортируется лениво — быстрый прогон его не ждёт. Юнит-тесты с фейковой моделью (8).
- CI: `uv sync --locked --all-extras`; AGENTS.md и README — установка с группой и загрузка модели.

## Решения
- Контракт поймал отличие от фейка: Silero отдавала готовые фрагменты без уступки цикла —
  потребитель доедал фразу раньше, чем срабатывала отмена. Добавлен `await asyncio.sleep(0)`
  между фрагментами.
- Модель v5_6_ru, а не лёгкая v4_ru: RTF и так в 6–10 раз лучше цели, v4 выигрыша не даёт.
- 48 кГц быстрее 24 кГц (RTF 0.035 против 0.052, первый фрагмент 86 против 137 мс) — частота
  для конфига (S-7.5) — 48 кГц.
- Загрузка модели не роняет старт: статус TTS придёт в UI через прогрев (S-7.5), как у LLM.
- Предупреждения `SyntaxWarning` при загрузке — из кода внутри пакета модели Silero, не наши.
