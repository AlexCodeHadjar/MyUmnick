# S-6.3 — Маппинг эмоций, реакции на события · 2026-10-27

## Цель
`mapping.json` модели (эмоция → выражение/моушен); реакция на отправку и `turn.started` в том
же кадре (T-17); замена модели без правки кода.

## Сделано
- `features/avatar/mapping.ts`: схема `mapping.json` v1 — `expressions` (имя → `.exp3.json`),
  `emotions` (эмоция протокола → выражение), `reactions` (`idle`/`listening`/`thinking`:
  выражение и моушен), `frame` (масштаб и сдвиг центра); проверка на входе с именем поля в
  ошибке; списки эмоций и реакций сверяются с типами через `satisfies`. `expressionFor` —
  реакция важнее эмоции.
- `features/avatar/reactions.ts`: `reactionOf` — «думаю» с момента отправки (реплика
  пользователя последняя, ход ещё не начат) и на фазе `thinking`; без связи или при ошибке ядра
  — покой.
- `live2d/settings.ts`: `mapping.json` рядом с моделью (нет — модель как есть), model3.json с
  дописанными выражениями маппинга и `url` для путей; не-JSON ответ = нет файла.
- `live2d/engine.ts` — загрузка движка и индексы рта вынесены из рендера.
- `Live2DRenderer`: эмоции и реакции через маппинг (движок дёргается только при смене нужного
  выражения), моушен реакции с `MotionPriority.NORMAL` без сброса выражения, кадр из маппинга
  (`applyFrame`).
- `AvatarStage`: получает store; эффекты на реакцию и эмоцию (срабатывают в кадре изменения
  store). `App.svelte` передаёт store.
- `ui/public/avatars/haru/mapping.json` (в git): 8 выражений, 7 эмоций (thinking → f02
  «Pensive», embarrassed → Blushing), реакция `thinking` → Pensive, кадр «по пояс» (zoom 1.55,
  offsetY 0.3).
- Тесты: mapping (14), reactions (4), settings (7), applyFrame — всего 128.

## Решения
- Выражения — через маппинг, а не правкой model3.json модели: файлы модели не наши и не в git;
  маппинг — единственный наш файл в каталоге модели.
- «Думаю» считается из store, а не из `turn.started`: реплика пользователя попадает в store
  синхронно в `say()` — реакция в том же кадре, без ожидания ядра (T-17, NFR-03).
- Сила эмоции (`intensity`) пока не используется — выражение целиком; затухание — Этап 8.
- Haru без моушена на «думаю»: его жесты `haru_m_*` — размашистые, на каждую реплику
  отвлекают; поле `motion` в схеме есть для других моделей.
