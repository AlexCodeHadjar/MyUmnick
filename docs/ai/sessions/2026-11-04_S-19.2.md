# S-19.1, S-19.2 — голос по образцу

## Сделано
- Сравнение движков на аренде, выбор на слух: OmniVoice 32 шага + FlashInfer, образец `maomao_04` (ADR-0031).
- `scripts/voice_server.py`, `VoiceServerTTS`, `FallbackTTS`, `[tts.voice_server]`, движок `voice_server` в реестре.
- Чат показывает причину сбоя хода вместо одного «прервано».

## Замеры
На аренде, без других задач: короткая фраза 0,21 с, RTF обычной 0,06, 5,6 ГБ. С LLM: пик 14,5 ГБ, синтез 0,26–0,54 с.
Через SSH-туннель фраза ≈ 1 с: это сеть, а не движок.

## Проблемы
- Картинки «прерывались»: LLM запущена без `--mmproj`, а UI не показывал причину. На сервере перезапущено с проектором.
- FlashInfer только для Linux: на целевой машине нужен WSL2, не проверено.
- Туннель `gpu.nz` рвётся: проверка сервера при старте повторяется, иначе ядро сразу уходило на Silero.
- `pnpm` виден только внутри приложения Claude, в терминале пользователя его нет: окно запускалось через обход в scratchpad.

## Дальше
