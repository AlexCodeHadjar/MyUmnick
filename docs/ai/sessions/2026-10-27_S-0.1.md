# S-0.1 — Каркас репозитория, pyproject, инструменты, CI · 2026-10-27

## Цель
Репозиторий, где ruff / mypy --strict / pytest с покрытием и pre-commit зелёные на пустом
каркасе, а CI повторяет те же шаги.

## Сделано
- `git init` (ветка `main`), `uv init --package` → src-layout, пакет `vtuber`.
- `pyproject.toml`: настройки ruff/mypy/pytest/coverage по разделу 7.15; dev-группа зависимостей
  (ruff, mypy, pytest, pytest-asyncio, pytest-cov, hypothesis, import-linter, pre-commit);
  `uv.lock`.
- `.pre-commit-config.yaml`: базовые проверки + ruff check/format + mypy через `uv run --frozen`.
- `.github/workflows/ci.yml`: windows-latest, `uv sync --locked`, ruff, format --check, mypy,
  pytest --cov.
- `.gitignore`, `.gitattributes` (LF; CRLF для .ps1), `.claude/settings.json` (deny-правила 9.6),
  `README.md`.
- Мастер-план сохранён в `docs/archive/MASTER_PLAN_v1.md` с восстановленной markdown-разметкой.
- Смоук-тест `tests/unit/test_package.py`.

## Решения
- Runtime-зависимостей нет (YAGNI): pydantic/structlog/orjson появятся на Этапе 1 вместе с кодом.
- Хуки вызывают инструменты через `uv run --frozen` — одна версия из `uv.lock` для хуков, CI
  и редактора; отдельные `rev:` для ruff/mypy в pre-commit не нужны.
- `requires-python = ">=3.12,<3.13"` — стек зафиксирован на 3.12 (раздел 4.2).
- Сверх 7.15: `CPY001` в ignore (в ruff 0.17 `ALL` требует заголовок копирайта);
  `extend-exclude = ["docs/archive"]` (ruff 0.17 форматирует код в markdown);
  `--strict-config`, `branch = true` в coverage.
- Deny на `docs/archive/**` отложен до конца S-0.3 — нарезке нужен доступ к архиву.
