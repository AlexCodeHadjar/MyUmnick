# S-5.4 — Раскладка, статус-бар, панель метрик, карта UI · 2026-10-27

## Цель
Две панели с перетаскиваемым разделителем (FR-01, ширина запоминается); статус LLM/TTS; панель
метрик по горячей клавише (FR-15); раздел `ui/src` в карте проекта.

## Сделано
- `app/split.ts` + `SplitLayout.svelte`: доля чата, ограниченная минимумами панелей (320 px),
  перетаскивание с захватом указателя, стрелки на разделителе (WAI-ARIA window splitter),
  хранение в localStorage с защитой от битых значений и недоступного хранилища.
- `app/status.ts` + `StatusBar.svelte`: ядро («подключение…» при первом запуске, «нет связи —
  переподключаюсь» после потери), LLM, TTS; без связи состояние бэкендов — «—».
- `features/metrics/`: `stats.ts` (последний, p50/p95 по ближайшему рангу, нормы: TTFT ≤ 250 —
  NFR-01, `ui.first_char` ≤ 270), `hotkey.ts` (Ctrl+Shift+M по `code`), `MetricsPanel.svelte`
  поверх сцены.
- `core`: store хранит последние 100 замеров каждой стадии (`recordSpan`); `probe.ts` —
  замер UI «реплика → первый символ в DOM», снимается в кадре применения дельты.
- `tools/ui_map.py`: экспорты TS с первой строкой JSDoc, компоненты Svelte с ведущим
  комментарием; `gen_map` добавляет раздел `ui/src`; хук `gen-map` следит и за `ui/src/`.
- Тесты: vitest — 81 (split, status, stats/hotkey, probe, client); pytest — `test_ui_map.py` (6).
- `App.svelte`: `color-scheme: dark` (тёмные полосы прокрутки); пробел перед «— прервано».

## Решения
- **Выход за scope** (`app/`, `features/metrics/`, `tools/`):
  - `core/store.svelte.ts`, `core/probe.ts`, `core/client.ts`, `core/index.ts` — панели нужна
    история замеров (p50/p95), а не последнее значение, и замер UI, который снимается только
    между транспортом и store.
  - **Найденная ошибка:** `uv run python tools/<скрипт>.py` падал на `from tools.…` у
    `bench_latency`, `eval_quality` (и падал бы у `gen_map`) — пакет `tools` не на `sys.path`
    при запуске файлом. Все вызовы переведены на `python -m tools.<имя>`: AGENTS.md, хук и CI
    `gen-map`, `docs/performance.md`, `docs/testing.md`, `docs/ai/WORKFLOW.md`, docstring-и.
- Карта UI — регулярные выражения, а не парсер TS: prettier гарантирует экспорт с начала строки;
  без новой зависимости и без Node в хуке Python.
- Ширина — доля окна, а не пиксели: при смене размера окна раскладка сохраняет пропорцию.
