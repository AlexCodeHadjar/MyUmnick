# S-5.1 — Каркас Tauri + Svelte, инструменты · 2026-10-27

## Цель
Tauri 2 + Svelte 5 + TS + Vite; eslint/prettier/svelte-check; строгий tsconfig (R-61); хуки и
CI для `ui/`; решение о sidecar.

## Сделано
- Установлены Node.js 24, pnpm 12, Visual C++ Build Tools 2022 (MSVC 14.44), Rust 1.99 (MSVC).
- `ui/`: Vite 8 + Svelte 5 + TS 6.0, строгий `tsconfig.json`, `eslint.config.js`
  (`strictTypeChecked`, запрет `any` и `as`), prettier, `src/app/main.ts` + `App.svelte`
  (заглушка двух панелей).
- `ui/src-tauri/`: `Cargo.toml`, `build.rs`, `src/main.rs` + `src/lib.rs`, `tauri.conf.json`
  (окно 1280×760, CSP только на `ws://127.0.0.1:*`), `capabilities/default.json`
  (`core:default`), иконки из сгенерированного PNG (`pnpm tauri icon`).
- Хуки `ui-eslint`, `ui-prettier`, `ui-svelte-check`, `ui-cargo-fmt`; CI-job `ui`.
- ADR-0009 (стек UI, pnpm, TS 6.0, sidecar — S-13.1), карточка `ui/README.md`, `docs/stack.md`.
- `protocol.gen.ts` компилируется `tsc --noEmit` и svelte-check — критерий Этапа 4 закрыт.

## Решения
- Sidecar откладывается до S-13.1: собирать ядро в exe пока не из чего; в разработке ядро
  запускается отдельно (`python -m vtuber serve`).
- svelte-check 4.7 не выдаёт типы компонента без `<script>` (TS7016 в `main.ts`) — найдено
  пробой: компонент со скриптом проходит, без скрипта — нет. В `App.svelte` добавлен блок.
- `*.md` исключён из prettier: markdown репозитория един для ядра и UI.

## Проверки
- `pnpm lint`, `pnpm check`, `pnpm format:check`, `pnpm build` — зелёные.
- `cargo build`, `cargo fmt --check`, `cargo clippy -D warnings` — зелёные.
- Фронтенд на dev-сервере Vite во встроенном браузере: обе панели, консоль без ошибок.
- **Не проверено:** `pnpm tauri dev` — окно падает с «Could not find the webview runtime».
  На машине разработки Edge вырезан (`C:\Program Files (x86)\Microsoft` нет), а в реестре
  осталась запись WebView2 144 — установщик winget видит её и ничего не ставит. Чинится
  удалением устаревшего ключа `EdgeUpdate\Clients\{F3017226-…}` и переустановкой — это правка
  системы, решение пользователя. На целевой машине WebView2 есть по умолчанию.
