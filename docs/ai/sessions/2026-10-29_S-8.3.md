# S-8.3 — Междометия-заглушки (опция) · 2026-10-29

## Цель
Заранее синтезированные «Хм…», «Ммм…», если первый звук не готов через X мс (T-17); опционально —
визем-липсинк, если TTS отдаёт фонемы.

## Сделано
- `application/pipeline/filler.py`:
  - `FillerConfig` — секция `[pipeline.filler]`: `enabled`, `after_ms` (1000), `phrases`
    («Хм…», «Так…», «Сейчас…»);
  - `FillerBank` — синтез междометий один раз (`prepare(tts)`), выдача по кругу;
  - `AudioOut` — единственный писатель звука хода: междометие пишется целиком под замком и
    только если ответ ещё не звучит; ответ ждёт конца начатого междометия.
- `Speaker(tts, telemetry, fillers)`: задача-таймер междометия на ход, отменяется в конце хода;
  ответ идёт через `AudioOut.answer`. `Voice(..., fillers)`.
- `application/pipeline/config.py` — `PipelineConfig` (`chunker`, `filler`) вынесен из `chunker.py`.
- Bootstrap: `Backends.fillers`; `_Voice(tts, fillers)` — в `serve` банк наполняется в прогреве
  голоса после пробного синтеза.
- Тесты `tests/unit/application/pipeline/test_filler.py` (7).

## Решения
- Место — `Speaker` (`application/pipeline`), а не `application/conversation` из плана: звук хода
  пишет только TTS-ветка, и гарантия «не накладывается» держится там, где один писатель.
- Синтез при загрузке, а не в ходе: в ходе CPU занят настоящей фразой; синтез междометия —
  23–36 мс, звук — 0.5–0.9 с (Silero и Piper).
- Ответ не обрывает начатое междометие, а встаёт за ним: обрыв на полуслове звучит хуже, чем
  пауза до ~0.8 с. Поэтому срок 1000 мс — выше бюджета TTFA (800): обычный ответ без «Хм».
- `tts.first_audio` (ядро) меряет звук ответа — междометие не в счёт; `ui.first_audio` в UI —
  слышимый звук, междометие в счёт (воспринимаемая скорость).
- Визем-липсинк не делался: ни Silero, ни Piper (через `piper-tts`) не отдают фонемы со временем.
- В UI ничего не менялось: междометие — кадры того же хода, плеер играет их по порядку.
- **Отступление от scope** (`application/conversation/`, `ui/src/features/audio/`): правки в
  `application/pipeline/`, `bootstrap/{container,main}.py`, `config/default.toml`, карточки
  `pipeline`, `bootstrap`, `docs/performance.md` (T-17).

## Проверки
- `pytest --cov` (442, 98 %), ruff, mypy --strict, import-linter — зелёные; сквозной `serve` со
  звуком (`-m slow`, Silero, с синтезом междометий в прогреве) — зелёный.
- Синтез междометий: Silero «Хм…» 0.53 с / «Так…» 0.60 с / «Сейчас…» 0.84 с; Piper 0.65 / 0.37 /
  0.66 с; синтез 22–39 мс.
- Окно Tauri (CDP), ядро `serve` с Silero, заглушка LLM 400 мс на 4 символа: звук хода начался на
  1027 мс (междометие), длился до 1533 мс, ответ — с 1740 мс; «думаю» на 804 мс, снято с
  междометием. Без заглушки первый звук был бы на ~1740 мс.
- Не проверено: звучание междометий на слух.
