# S-3.1 — Персона и PromptBuilder · 2026-10-27

## Цель
`personas/default.toml` и загрузка в `Persona`; `PromptBuilder` строит промпт «от неизменного
к изменчивому», список эмоций — из `Emotion`.

## Сделано
- `application/prompting/prompt_builder.py`: `PromptBuilder(persona)` — префикс (система +
  примеры) собирается один раз в конструкторе; `build(history, user_text, context=())` →
  `Prompt(messages, prefix_length)`; `render_system_prompt(persona)` — `{emotions}` → теги
  всех эмоций; справка (`context`) — только в последнюю реплику пользователя.
- `bootstrap/persona.py`: `PersonaConfig` (секция `[persona]`), `load_persona(path)` — TOML →
  `Persona`, примеры `[[examples]]` → пары сообщений; ошибки — `ConfigError` с путём.
- `personas/default.toml` (Мика) с пояснениями; секция `[persona]` в `config/default.toml`;
  поле `persona` в `AppConfig`; шаблон `docs/templates/persona.toml` → `[[examples]]`.
- Тесты: `tests/unit/application/prompting/test_prompt_builder.py` (5, в т.ч.
  `test_prefix_is_stable` — байтовое сравнение префикса между ходами и «история только
  дописывается»), `tests/unit/bootstrap/test_persona.py` (7), проверка `[persona]` в
  `test_config.py`.
- Карточки `application/prompting/README.md`, bootstrap; STAGE_03; STATE (S-2.5 отложена).

## Решения
- Загрузка персоны — в bootstrap: чтение файла и проверка — граница; application тестируется
  без файлов (R-56). Выход за scope STAGE оговорён в STAGE_03.
- Справка в тексте реплики, а не отдельным системным сообщением: шаблоны чата ряда моделей
  (Gemma, Mistral) не допускают system посреди диалога. Цена — открытая проблема P2 в STATE.
- Примеры — массив пар `[[examples]]`, а не одна пара: можно показать модели несколько образцов.
- `language` — свободный текст («русский»), а не код «ru»: попадает в промпт как есть.
