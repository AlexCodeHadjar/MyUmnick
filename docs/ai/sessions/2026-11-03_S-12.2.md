# S-12.2 — MessageSource и чат стрима · 2026-11-03

## Сделано
- `IncomingMessage`, порт `MessageSource`, `PluginContext.add_source`; `running_plugins` отдаёт источники.
- `gateway/external_turns.py`: реплика источника → ход, по одной, только в тишине, без UI — теряется.
- `ConversationService.wait_silent`: конец хода плюс длительность отданного звука.
- `plugins/stream_chat`: Twitch (анонимное чтение IRC), фильтры, очередь с выбором, лимит частоты.

## Решения
- Чат UI не стал источником в общей очереди: это лишний шаг в горячем пути (приоритет 1), а реплика
  ведущего должна перебивать. Отступление от формулировки цели этапа.
- Ход кончается раньше звука (RTF 0.02), а новый ход вытесняет звук в UI: без `wait_silent` зритель
  обрывал бы речь. Считается по длительности кадров: сообщения `audio.played` в протоколе нет.
- Ядро запрашивает реплику, когда готово отвечать: источник выбирает лучшую на этот момент.
- Анонимный вход Twitch: без учётных данных; писать в чат плагин не может.
- Зависимостей нет: websockets уже в ядре. Отступление от scope: сервис хода, шлюз, bootstrap, kernel,
  pyproject (пути плагина для тестов и mypy).

- Не проверено: настоящий канал Twitch, ожидание звука на слух, YouTube не сделан.
