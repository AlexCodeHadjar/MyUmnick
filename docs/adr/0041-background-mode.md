# ADR-0041: Фоновый режим — старт с Windows, трей, окно открывается по имени
- Статус: принято
- Дата: 2026-11-11

## Контекст
Пользователь попросил: программа запускается вместе с компьютером, в фоне слушает и открывается, когда её зовут
(«Умник», ADR-0040). Раньше окно было единственным способом жить приложению: закрыли — ядро остановилось; повторный
клик по ярлыку давал ошибку «уже запущен».

## Решение
- **Трей.** Флаг `tray-icon` у уже стоящей `tauri` (крейт `tray-icon` тянется ею же — новой зависимости нет).
  Меню значка: «Открыть», «Запускать вместе с Windows» (галочка), «Выход»; клик по значку — открыть окно.
  Крестик окна прячет его в трей: витюбер продолжает слушать; выход — из меню значка.
- **Скрытый старт.** Окно в `tauri.conf.json` создаётся `visible: false`; оболочка показывает его сразу, если не
  попросили фон (`--background` у собранного exe или `VTUBER_BACKGROUND=1` от лаунчера).
- **В фоне UI:** экран выбора пропускается (прошлое издание из `launcher.json`), микрофон стартует в «всегда
  слушать» (сохранённый выбор не перезаписывается), ядру сразу уходит `window.visibility = false` — персонаж сам
  не заговаривает (S-15.1).
- **Зов.** `input.barge_in` в режиме «по имени» приходит, когда услышано имя (уже в промежуточной гипотезе).
  `CoreClient.onCalled` срабатывает мимо пачки кадров — у скрытого окна `requestAnimationFrame` стоит — и зовёт
  команду `window_reveal`: скрытое или свёрнутое окно показывается и получает фокус. Открытое окно не
  выдёргивается поверх чужих окон.
- **Автозапуск** — значение `AI VTuber` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` через `reg.exe`
  (плагин автозапуска был бы новой зависимостью ради двух команд). Строку даёт окружение: в разработке —
  `launch.ps1 -Background` (лаунчер передаёт её в `VTUBER_AUTOSTART_COMMAND`), у собранного exe — он сам с
  `--background`. Окно без лаунчера в разработке строки не знает — пункт меню выключен.
- **Лаунчер.** `launch.ps1 -Background`; второй запуск при живом витюбере показывает его окно (Win32
  `FindWindow`/`ShowWindow`), а второй автозапуск просто выходит.

## Последствия
- LLM и модели голоса держатся в памяти всё время работы Windows — это цена мгновенного ответа на зов.
- В режиме `addressing.mode = "always"` окно из трея открывает любая речь: фоновый режим рассчитан на «по имени».
- Порт 8765 занят ядром, пока витюбер в трее.
- Не проверено: микрофон в скрытом окне WebView2 на живом голосе; поведение фокуса, когда Windows запрещает
  фоновому процессу выходить на передний план (окно может появиться за активным).
