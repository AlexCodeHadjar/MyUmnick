# ADR-0050: Карманный Умник — Android-приложение и обмен блокнотом по MTP
- Статус: принято
- Дата: 2026-11-17

## Контекст
Пользователь хочет спутника «Умник» на телефоне (TECNO POVA 6 Pro 5G, Android): те же позы, эмоции, реплики и
взаимодействие, без LLM; автозапуск при включении; отклик на «Умник» и блокнот под диктовку; при подключении к ПК
основная программа сама находит телефон и обменивается заметками.

## Решение
- **Нативное Kotlin-приложение** (`mobile/android/`), не Tauri mobile: нужны служба переднего плана, оверлей
  поверх всех окон и `BOOT_COMPLETED` — это проще и надёжнее в нативном коде.
- **Распознавание — Vosk** (`com.alphacephei:vosk-android`, Apache-2.0) с моделью `small-ru` (Apache-2.0):
  работает офлайн, умеет ограниченную грамматику (дёшево слушать только имя). Системный `SpeechRecognizer`
  отвергнут: пищит при каждом запуске и не годится для постоянного слушания.
- **Озвучка ответов — системный `TextToSpeech`** (без зависимостей).
- **Обмен — файлы по MTP, без отладки по USB**: приложение пишет в `Documents/UmNick/` (доступ через SAF),
  ПК видит её как портативное устройство. На ПК — плагин `phone_sync`: раз в 5 с ищет устройство WPD с папкой
  `UmNick` через `Shell.Application` (PowerShell, отдельный поток, без новых Python-зависимостей).
  ADB отвергнут: требует режима разработчика и отладки по USB.
- Кадры и фразы не дублируются руками: `tools/export_mobile_pack.py` копирует их из `ui/`.

## Последствия
- Новые зависимости только в `mobile/android` (Gradle): AndroidX core, Vosk. Python-зависимостей нет.
- Для сборки нужны JDK 17 и Android SDK — их нет в окружении разработки.
- Заметки сливаются только в одну сторону без удаления: удалённая на одной стороне заметка не удаляется на другой.
