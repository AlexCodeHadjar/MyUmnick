# ADR-0027: Звуковые события через SenseVoice
- Статус: принято 2026-11-03: пользователь согласился на скачивание; функция выключена, пока точность не замерена
- Дата: 2026-11-03

## Контекст
S-14.4 просит замечать смех, аплодисменты, кашель и музыку. SenseVoiceSmall размечает `BGM`, `Applause`, `Laughter`, `Cry`, `Sneeze`,
`Breath`, `Cough`. Whisper таких меток не даёт, а Silero VAD пропускает только речь.

## Найдено
- **Русского у выложенной модели нет:** распознаёт китайский, кантонский, английский, японский и корейский. Текст от неё не берём,
  только метку. Работают ли метки на русской речи и комнатном шуме, неизвестно: это главный риск, его покажет только замер.
- **Лицензия весов:** FunASR Model Open Source License v1.1. Можно использовать, менять и распространять с указанием источника
  и названия модели. Раздел 3 называет модель предоставленной «for reference and learning purposes only». Отдельное разъяснение
  разрешает коммерческое использование официальных весов, но сторонних сборок не касается. Раздел 6: условия могут меняться
  автоматически. Код — MIT.
- **Сборка для onnxruntime:** `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17` от k2-fsa, сторонняя конвертация; `model.int8.onnx`
  228 МБ, рядом файл `LICENSE`. Есть сборка 2025-09-09 (архив около 166 МБ по зеркалу), в её списке файлов лицензии нет.
- **Библиотека:** `sherpa-onnx` 2.0.1 (Apache), группа `sounds`, в окружении 28 МБ. Поле `event` в Python подтверждено запуском.
- **Скачано:** сборка 2024-07-17, архив 163 МБ, SHA-256 `7d1efa2138a65b0b488df37f8b89e3d91a60676e416f515b952358d83dfd347e`.

## Решение
- Отдельное окно микрофона мимо детектора речи, с порогом громкости; на тишину модель не тратится.
- Модель на CPU, грузится только при `[stt.sounds].enabled = true`; по умолчанию выключено.
- Реакция редкая, только на выбранные звуки и только в тишине. Звук не сохраняется.

## Последствия
- Выключенная функция ничего не стоит: объекта нет.
- Включённая занимает память и CPU: разбор окна 3 с — около 0,2 с на двух потоках (ПК разработки); память не измерена.
- Проба: русская речь Silero и английский пример, 16 окон, лишних меток нет. Аккорды дают `BGM`; хлопки из шума — `Speech`,
  синтетический смех — `Event_UNK`. Настоящих записей смеха, кашля и аплодисментов не было: точность неизвестна.
- Для публичного распространения условия весов надо перечитать заново.
