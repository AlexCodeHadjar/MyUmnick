# ADR-0014: голос по умолчанию — Silero v5_6_ru `xenia` 48 кГц; Piper `denis` — запасной
- Статус: принято
- Дата: 2026-10-29

## Контекст
Этап 7 требует: TTFA p50 ≤ 800 мс, RTF выбранного TTS ≤ 0.3, паузы между фразами ≤ 80 мс сверх
естественных (`docs/stages/STAGE_07.md`). Движков два, за одним `TTSPort`: Silero (ADR-0012) и
Piper (ADR-0013). Персона — Мика, женский образ (`personas/default.toml`). Приложение — для
личного использования (ADR-0011): некоммерческие лицензии допустимы, пока нет публикации.

Целевая машина (RTX 5070 Ti) ещё недоступна, настоящего TTFT нет (S-2.5). Поэтому TTFA
замерен на настоящем конвейере ответа (`ReplyPipeline` → нарезка → TTS → кадры) с
LLM-заглушкой: TTFT = 250 мс (бюджет NFR-01), далее 40 или 80 токенов/с, ответы 1–3
предложения с тегом эмоции (T-07). Голосовая часть — настоящая; отдельно выводится
«TTFA − TTFT» — вклад голоса, который переносится на любую LLM.

## Замеры
`uv run python -m tools.bench_voice --tts <движок> --simulate-llm [--sim-tps N]`, 40 реплик
`bench/prompts_ru.jsonl`, 88 фраз, машина разработки (CPU, 4 потока torch). TTFA — до первого
звука, отданного ядром; сеть и плеер UI добавляют ≈ 20 мс (S-7.6: в окне `ui.first_audio` p50
160 мс при TTFT ≈ 30 мс). TTFT заглушки выше заданных 250 мс: первый видимый текст идёт после
тега эмоции, и таймер Windows (~15.6 мс) растягивает паузы между токенами.

| Движок, темп LLM | TTFT p50 | TTFA p50 / p95 / max | TTFA − TTFT p50 / p95 | RTF фразы p50 / p95 | Пауза сверх звука, max |
|---|---|---|---|---|---|
| Silero, 40 ток/с | 307–316 | 516–545 / 595–615 / 623 | 245–257 / 305–307 | 0.039–0.047 / 0.054–0.080 | 0 |
| Piper, 40 ток/с | 321 | 550 / 614 / 633 | 251 / 312 | 0.041 / 0.056 | 0 |
| Silero, 80 ток/с | 282 | 438 / 472 / 497 | 157 / 205 | 0.048 / 0.076 | 0 |
| Piper, 80 ток/с | 284 | 428 / 454 / 456 | 157 / 181 | 0.044 / 0.052 | 0 |

Вывод: вклад голоса в TTFA — это в основном ожидание первой фразы от LLM (≥ 4 слов, T-02), а
не синтез: синтез фразы p50 67 мс (Silero) и 80 мс (Piper). При TTFT 250 мс и 40 ток/с TTFA
p95 ≤ 615 мс — **TTFA p50 ≤ 800 мс выполняется с запасом ~250 мс** на любом из движков; запас
съест TTFT хуже 500 мс. Буфер не пустеет ни разу: синтез в 12–25 раз быстрее речи.

На целых промптах (S-7.4, без нарезки) RTF Piper — p50 0.184 / p95 0.322, Silero — 0.041 /
0.151: в конвейере фразы короткие, и Piper укладывается в цель; длинная фраза без знаков
(`max_words = 25`) — его слабое место.

## Рассмотренные варианты

| Голос | Качество 1–5 (предв.) | RTF p95 | TTFA p50 (40 ток/с) | Лицензия | Пол |
|---|---|---|---|---|---|
| **Silero v5_6_ru `xenia`, 48 кГц** | 4 | 0.054–0.080 | 516–545 | CC BY-NC 4.0 | женский |
| Silero v5_6_ru `baya` / `kseniya` | 4 | как `xenia` | как `xenia` | CC BY-NC 4.0 | женский |
| Piper `ru_RU-denis-medium`, 22 кГц | 3 | 0.056 (фразы), 0.322 (целые промпты) | 550 | CC0 | мужской |
| Piper `ru_RU-dmitri-medium` | 3 | ≈ `denis` | ≈ `denis` | CC0 | мужской |
| Piper `irina`, `ruslan` | — | — | — | неизвестна / CC BY-NC-SA | — |

Качество — **предварительная оценка, не на слух**: ИИ-ассистент не слушает звук. Основа: 48 кГц
против 22 кГц, встроенные ударения и «ё» у Silero v5, вероятностная модель medium у Piper. Оценку
на слух ставит пользователь; поменять её — правка этой таблицы, без кода
(`[tts].backend`, `[tts.silero].speaker`).

## Решение
- Голос по умолчанию — **Silero v5_6_ru, `xenia`, 48 кГц** (уже в `config/default.toml`):
  женский голос под персону, лучшее качество, RTF и TTFA в пределах цели с запасом.
- Piper `denis` (CC0) — запасной движок и путь к публикации: переключается одной строкой
  `[tts].backend = "piper"`. Мужской голос не подходит Мике — перед публикацией нужен
  CC0/коммерческий женский голос (свой голос Piper, договор с Silero) — тогда пересмотр.
- TTFA p50 ≤ 800 мс зафиксирован: 516–545 мс на машине разработки при TTFT 250 мс. На целевой
  машине перепроверить с настоящей LLM: `uv run python -m tools.bench_voice` (без
  `--simulate-llm`) — критерий Этапа 7 закрывается этим прогоном.
- `audio.played` (UI → ядро) не добавлять сейчас: TTFA с плеером меряет сам UI
  (`ui.first_audio`, S-7.6). Сообщение понадобится для состояния «говорит» (конец
  воспроизведения) — добавить вместе с ним, когда оно появится в плане.

## Последствия
- Лицензия Silero (CC BY-NC) — та же граница, что у Live2D (ADR-0011): любое распространение или
  монетизация начинаются с пересмотра этого ADR.
- Регрессия голоса видна в бенчмарке: «TTFA − TTFT» и «Пауза max» не зависят от LLM.
- Нарезка (`first_min_words = 4`) — главный рычаг TTFA после TTFT: уменьшение до 3 слов
  сократит ожидание первой фразы, но первая фраза из 1–2 слов звучит неестественно (STAGE_07).
