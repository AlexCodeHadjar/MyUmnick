# ADR-0029: Собеседники — отпечаток голоса на каждую фразу
- Статус: принято; функция выключена, пока доля ошибок на людях не замерена
- Дата: 2026-11-03

## Контекст
S-14.3 предлагает диаризацию pyannote.audio. Её веса закрыты соглашением и требуют токена, а полная диаризация размечает запись
целиком, уже после разговора. Метка нужна сразу, для этой реплики.

## Решение
- **Отпечаток голоса ERes2Net через `sherpa-onnx`** (группа `sounds`, уже есть, ADR-0027). Токена не нужно.
- **На фразу один отпечаток:** фразы уже режет детектор речи. Сегментация pyannote не понадобилась и не установлена. Две реплики без
  паузы внутри одной фразы получат одну метку.
- **Считается рядом с Whisper:** ответ ждёт отпечаток не дольше `wait_s`, затем идёт без метки.
- **Метка в тексте реплики** («Собеседник 2: …»), поэтому она и у модели, и в истории. Пока слышен один голос, метки нет и промпт не
  меняется. Короче `min_phrase_s` — без метки.
- **Отпечатки только в памяти:** не пишутся на диск, при перезапуске номера начинаются заново. Имён нет, только номера.

## Лицензии
- ERes2Net base: Apache 2.0 (карточка ModelScope). Сборка ONNX k2-fsa, сторонняя конвертация, файл лицензии с ней не идёт.
- Сегментация pyannote 3.0 скачана для проверки: MIT, в приложении не используется.

## Замеры
- ПК разработки, CPU, 2 потока: загрузка 0,28 с, отпечаток 83 мс в среднем, 148 мс максимум.
- Голоса Silero (5 голосов, по 8 фраз): один голос — сходство не ниже 0,54, в среднем 0,80; разные — в среднем 0,11–0,41,
  самая похожая пара до 0,60. Отсюда порог 0,55, но пересечение есть.
- Разговор по очереди по этим отпечаткам: 10 пар голосов, по 16 фраз, ошибок нет, насчитано по два голоса. Это синтетика: чистый звук
  и разные голоса. На людях, в шуме и с одним микрофоном может быть хуже.

## Последствия
- Выключено по умолчанию: без него промпт и задержки те же.
- Доля ошибок на записи двух людей не замерена, для этого `tools.eval_speakers`. Модель обучена на китайской речи.
