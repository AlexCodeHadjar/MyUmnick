# ADR-0024: Зрение через проектор llama-server
- Статус: принято
- Дата: 2026-11-03

## Контекст
FR просит показывать персонажу картинку. У выбранной модели есть `mmproj` (0,18 ГБ, ADR-0004). Проектор занимает
видеопамять, а картинка не должна задерживать обычные реплики (приоритет 1).

## Решение
- **Проектор включается настройкой** `[llama_server].mmproj` и `-MmProj` в `scripts/start_llm.ps1`. По умолчанию выключен.
- **Картинка — часть одного сообщения.** В порт идёт `Message.images`; запрос без картинки байт в байт прежний, строкой.
- **Картинка живёт один ход.** В истории и в заметках только пометка в тексте: иначе каждый следующий ход заново гонял бы её
  через проектор и она попала бы на диск.
- **Уменьшается в UI до 1024 пикселей**, JPEG. Предел кадра сокета поднят до 8 МиБ. Своё сообщение `chat.send_image`:
  обычный `chat.send` не меняется.
- **Отказ понятен.** Ошибка сервера на запросе с картинкой становится `VisionUnavailable` с подсказкой про `--mmproj`.
  Заранее сервер не спрашиваем: лишний запрос в горячем пути ради редкого случая.

## Последствия
- Новых зависимостей нет.
- **Не замерено:** VRAM и TTFT с проектором и картинкой. Нужны файл `mmproj` и аренда 5070 Ti, этап S-18.1 не закрыт, пока их нет.
- Качество ответов по картинкам и работа без цензуры на них не проверены.
