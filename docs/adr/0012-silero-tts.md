# ADR-0012: первый движок TTS — Silero v5.6 на torch (CPU), необязательная зависимость
- Статус: принято
- Дата: 2026-10-28

## Контекст
Этап 7: голос с TTFA p50 ≤ 800 мс и RTF ≤ 0.3 (`docs/stages/STAGE_07.md`). План — сначала
Silero (S-7.3), затем Piper (S-7.4); выбор голоса учитывает лицензии (`docs/licenses.md`).
Пользователь выбрал Silero: лицензия моделей CC BY-NC 4.0 подходит для личного использования
(как и Live2D, ADR-0011). Видеокарта отдана LLM — TTS работает на CPU (T-11).

## Рассмотренные варианты
Модель (`models.yml` Silero, 2026-10-28): **v5_6_ru** (148 МБ, 5 голосов: aidar, baya,
kseniya, eugene, xenia; 8/24/48 кГц; ударения и «ё» — встроенные) против v4_ru (40 МБ).
Замер v5_6_ru на машине разработки, 4 потока CPU: RTF 0.017–0.035 — в 10 раз лучше цели;
меньшая модель выигрыша по скорости не даёт.

Зависимость: **torch (CPU-сборка) как необязательная группа `silero`** против обязательной
зависимости и против CUDA-сборки torch (≈ 2.5 ГБ, конкурирует с LLM за видеопамять).

## Решение
- `torch>=2.6` (CPU-сборка с индекса `download.pytorch.org/whl/cpu`) и `numpy` — в
  `[project.optional-dependencies] silero`. Ядро без группы ставится и работает (TTS — фейк или
  другой движок); полная установка — `uv sync --all-extras`, так же в CI.
- Модель — `models/tts/silero/v5_6_ru.pt` (вне git), загрузка вручную:
  `https://models.silero.ai/models/tts/ru/v5_6_ru.pt`. Загружается `torch.package` один раз
  (R-40); синтез — в потоке (`asyncio.to_thread`), модель защищена блокировкой потоков: отменённый
  синтез дорабатывает в фоне и не должен столкнуться со следующим.
- Числа потоков torch — из конфига (`torch.set_num_threads`, процесс-глобально: torch в ядре
  только у TTS).
- NumPy — только для перевода тензора в PCM s16le без поэлементного цикла.

## Последствия
- `docs/licenses.md`: Silero v5_6_ru — CC BY-NC 4.0; torch, numpy — BSD. Публикация или
  монетизация — пересмотреть (Piper `denis`/`dmitri`, CC0 — S-7.4).
- Контракт TTSPort для Silero — медленный тест (`-m slow`): грузит модель 2–3 с; без файла
  модели — пропуск с причиной.
- CI ставит группу `silero` (CPU torch ≈ 200 МБ, кэшируется uv).
- Silero не стримит внутри фразы: фраза синтезируется целиком (~50–90 мс на 2–4 с звука на
  машине разработки) и отдаётся фрагментами `chunk_ms` для ровной отдачи в UI.
