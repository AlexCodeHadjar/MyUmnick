# ADR-0025: Снимок экрана только по явному действию
- Статус: принято
- Дата: 2026-11-03

## Контекст
S-18.2 просит показать персонажу экран. На снимке могут быть пароли и личные данные, а на стриме их увидят зрители.

## Рассмотренные варианты
1. **Захват в оболочке (Rust, плагин или свой код).** Можно снимать без диалога, но это новая зависимость и как раз та
   возможность, которой быть не должно.
2. **`getDisplayMedia` в WebView.** Окно выбирает пользователь в системном диалоге, система сама показывает индикатор,
   зависимостей нет.

## Решение
Вариант 2. Снимок начинается только с кнопки или с реплики вроде «посмотри на экран», и реплика лишь открывает диалог.
После диалога снимок виден рядом с полем с предупреждением и не уходит, пока пользователь не нажмёт «Отправить» ещё раз.
Захват останавливается сразу после одного кадра. Снимок живёт в памяти и идёт как обычная картинка (ADR-0024): на диск и в
историю не попадает.

## Последствия
- Постоянного захвата нет и в коде для него ничего не предусмотрено.
- Двойное подтверждение стоит лишнего нажатия: так решено ради личных данных.
- Работа диалога в WebView2 на Windows не проверена вживую.
