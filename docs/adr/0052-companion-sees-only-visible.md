# ADR-0052: Спутник видит только видимое; фильм — по сеансам мультимедиа Windows; «Спокойнее»

- Статус: принято
- Дата: 2026-11-17

## Контекст
Живая проверка пользователя: пока смотрели фильм, спутник тыкал куда-то и называл ярлыки. Причин две:
1. **Цели для тычков не проверялись на видимость.** Цели — элементы активного окна или значки рабочего
   стола из UI Automation. Если фокус на миг уходил на рабочий стол, спутник «видел» значки сквозь окно с
   фильмом.
2. **Фильм узнавался по узким признакам:** плеер, браузер на весь экран, известный видеосайт во вкладке.
   На незнакомом сайте режим «смотрим вместе» не включался.

Пользователь попросил:
- чтобы спутник понимал, где находится, и делал то, что доступно именно там;
- большой набор универсальных фраз для просмотра;
- режим, в котором он не «бушует», а просто смотрит.

## Решение
- **Только видимое.** `desktop::covering` отдаёт рамки окон выше целевого по z-порядку; для рабочего стола —
  все окна. `uia::targets` отбрасывает цели, чей центр закрыт любым из них. Тычки и прыжки по значкам
  теперь только по тому, что реально видно в этом месте.
- **Что играет в системе** (`media.rs`, команда `companion_media`):
  - **откуда:** сеансы мультимедиа Windows (System Media Transport Controls, WinRT
    `Windows.Media.Control`). Браузеры и плееры сами сообщают «играет / пауза» и приложение-источник;
  - **зависимости:** новых нет, только функции `Foundation` и `Media_Control` у уже стоящего `windows`
    0.62 (ADR-0048);
  - **приватность:** название трека не запрашивается и не хранится, берётся только источник;
  - **запасной путь:** не все программы сообщают о себе. Яндекс Браузер, проверено вживую: 0 сеансов при
    идущем видео. Поэтому команда отдаёт и **аудиосеансы** Windows (Core Audio, функции
    `Win32_Media_Audio`, `Win32_System_Com_StructuredStorage`, `Win32_System_Variant`): активный —
    «играет», молчащий — «пауза». Из всех источников слой выбирает видео (`pickMedia`). Встроенный
    веб-движок (`msedgewebview2`, окна приложений и само окно витюбера) браузером не считается;
  - **опрос:** раз в 2 с из слоя спутника;
  - **видео:** браузер или видеоплеер, но не музыкальная программа и не музыкальная вкладка
    (`watch.ts: mediaVideo`).
- **Когда смотрим** (`keepWatching`):
  - **начать** — видео в фокусе или на весь экран;
  - **продолжать** — пока фильм идёт, куда бы ни ушёл фокус. Щелчок по рабочему столу не прерывает фильм;
  - **пауза** — часть просмотра, до 90 с. На паузе и продолжении — своя реплика.
- **Во время просмотра:**
  - звучат только ответы на ваши действия (погладили) и фразы самого просмотра;
  - реакции на мышь, окна и прочее молчат;
  - тихие реплики: первая через 4–7 мин, дальше раз в 8–14 мин;
  - большой универсальный набор фраз — `phrases/watch.ru.ts` и `watch.en.ts`, около 100 на издание.
- **«Спокойнее»** — пункт меню спутника, а при просмотре включается сам:
  - потребности растут втрое медленнее;
  - жетоны фраз «сам по себе» копятся втрое дольше, реакции звучат вдвое реже;
  - тычков и прыжков по значкам нет.

## Последствия
- Сеансы мультимедиа есть с Windows 10 1809. На старых системах `companion_media` отвечает «ничего не
  играет», и остаются прежние признаки.
- Окно, которое не регистрирует сеанс мультимедиа (редкие плееры), узнаётся по прежним признакам.
