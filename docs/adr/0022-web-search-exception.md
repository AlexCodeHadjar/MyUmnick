# ADR-0022: Поиск в интернете как исключение из «полностью офлайн»
- Статус: принято
- Дата: 2026-11-03

## Контекст
NFR-06 требует работы полностью офлайн, а FR-25 просит ответы о свежих событиях. Запрос наружу раскрывает, о чём
спрашивает пользователь, а текст страниц может содержать команды для модели.

## Решение
- **Выключено по умолчанию и не входит в ядро:** отдельный плагин. Пока его не включили, он даже не импортируется,
  поэтому NFR-06 выполняется как раньше.
- **Запрос только по явной просьбе в реплике ведущего.** Модель сама поиск не запускает; зрителям и приватному режиму
  инструменты недоступны (S-12.11, S-17.2).
- **Только локальный SearXNG:** плагин ходит лишь на localhost. SearXNG под AGPL-3.0, поэтому это отдельный процесс, который
  запускает пользователь, а не часть приложения.
- **Страницы — данные:** справка подписана как чужой текст, разметка вычищена, страницы с явными атаками отброшены.
- **Источники видны:** плагин сообщает их через `report_sources`, UI показывает ссылки.
- **Свой срок у инструмента:** поиск длится секунды, а обычный срок инструмента 30 мс. Срок задаётся при регистрации;
  реплики без просьбы завершаются сразу и ничего не ждут.

## Последствия
- При включённом плагине запросы уходят наружу через SearXNG: это надо понимать, включая его.
- Ответ с поиском задерживается на его время, TTFT такого хода не укладывается в обычный бюджет. Это осознанно.
- На настоящем SearXNG и настоящей модели не проверялось.
