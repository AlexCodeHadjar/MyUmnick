# ADR-0038: Аватар — сфера из точек «как у Джарвиса» вместо модели Live2D
- Статус: принято
- Дата: 2026-11-10

## Контекст
Пользователь попросил убрать модель и сделать «как Джарвис»: сферу из точек и связей, которая вибрирует при
разговоре и переливается. Похожие решения на GitHub — Three.js и частицы (`nilanjanajui/jarvis` ArcReactor3D,
`ethanplusai/jarvis` orb.ts, `jeromepl/3D-audio-sphere`, `nehasriva/phonon` — точки Фибоначчи, звук сдвигает их
наружу). Three.js — новая зависимость (~600 КБ); приоритет — скорость.

## Решение
- `ui/src/features/avatar/orb/`: 420 точек по сфере Фибоначчи, рёбра к 3 ближайшим соседям (считаются один раз),
  поворот и перспектива в кадре, Canvas 2D без новых зависимостей; рёбра рисуются четырьмя пачками по глубине.
- Сфера реализует контракт `AvatarRenderer` (ADR-0011): `setMouth` (громкость голоса) раскачивает точки волнами
  по поверхности и раздувает свечение, `setEmotion` тянет оттенок (нейтральный — голубой), `react("thinking")`
  ускоряет вращение, `nod`/`gesture` — пульс, `lookAt` наклоняет сферу к курсору. Остальное UI не менялось.
- Выбор — `VITE_AVATAR=orb` в `ui/.env` (теперь по умолчанию); сфера грузится своим чанком без Pixi и Live2D.
  Модель Live2D осталась: любое другое имя в `VITE_AVATAR`. При `orb` выбор модели в мастере её не перекрывает.

## Последствия
- Кадр ≈ 1,5–1,6 мс на машине разработки (60 кадров подряд, в покое и «в речи»), без Pixi и WebGL-контекста модели.
- Липсинк по форме рта (ADR-0023) и жесты модели у сферы не видны — только громкость и пульс.
- `ui/index.html` по-прежнему подключает Cubism Core статически (нужен Live2D); при сфере его можно не грузить —
  отдельная правка, если понадобится.
