# ADR-0046: Оформление окна по образцу Capri, палитра «ночь Умника»
- Статус: принято
- Дата: 2026-11-16

## Контекст
Пользователь попросил интерфейс «как у Capri, только с другой цветовой палитрой». Интерфейс Capri
(capri-desktop, `app/Neon.cs`, `app/Mainframe.cs`): почти чёрный фон с винным свечением сверху, разделы на тёмных
полосах под бирюзовой чертой, названия настроек розовым, значения голубым, рамки и кнопки со срезанными углами и
красными штрихами на больших срезах, узкий шрифт Bahnschrift SemiCondensed. Код и картинки Capri не берём
(PolyForm Noncommercial) — только приёмы оформления.

## Решение
- Все цвета, шрифты и срезы — переменные в `ui/src/app/theme.css`; компоненты берут переменные, а не свои значения.
- Палитра своя: фон `#0a0b14`, свечение индиго `#1d1652`, черта раздела фиолетовая `#6d5cff`, названия
  `#a7b8ff`, значения и «включено» мятные `#5ef0b4`, штрихи на углах и предупреждения янтарные `#ffb547`.
- Приёмы: `.u-frame` — панель со срезом 12 px слева сверху и справа снизу и штрихами вдоль срезов; `.u-section` —
  заголовок раздела заглавными с « >» и чертой; кнопки — срез правого нижнего угла, наведение — кайма акцентом.
- Шрифт — Bahnschrift SemiCondensed (есть в Windows 10/11), запасной — Segoe UI. Новых зависимостей нет.
- Экран выбора издания остаётся «как у Steam» (Этап 20, просьба пользователя).

## Последствия
- Смена палитры — правка одного файла. Окно «Сопровождения» использует те же переменные.
