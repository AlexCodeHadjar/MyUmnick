# ADR-0043: Навыки помощника — реестр, гейты, запуск плагина на ходу
- Статус: принято
- Дата: 2026-11-16

## Контекст
Пользователь попросил панель «Навыки»: все инструменты помощника с описанием и включателем, который действует в
реальном времени. До этого инструменты включались только списком `[plugins].enabled` в конфиге и перезапуском
ядра, а у плагина не было описания для человека.

## Решение
- **Навык** (`domain/skill.py`, `SkillInfo`) — одна возможность: `id` `<плагин>` или `<плагин>.<навык>`,
  встроенные — `core.memory`, `core.initiative`. Флаги `network` (ходит в интернет) и `gpu`.
- **API плагинов, совместимо со старыми:** `ctx.declare_skill(SkillInfo)` возвращает полный id; `add_context`,
  `add_command`, `add_source` принимают `skill=`. Без него всё зарегистрированное — навык «весь плагин».
  `tools` объявляет `time`, `timer`, `notes`, `web_search` — `search` (`network=True`).
- **Реестр** (`application/skills/SkillRegistry`): выбор пользователя поверх конфига; `enabled()` — поиск в
  словаре, его зовут в горячем пути. Счётчики за сессию: срабатывания, средняя задержка, выходы за срок.
- **Гейты:** `ToolContext` не опрашивает выключенный инструмент; `EnabledCommands` прячет выключенные команды
  (реплика идёт к модели обычной); `gated_stream` читает источник, но не пускает реплики; `gated_hints` — для
  памяти; инициатива проверяет `core.initiative`.
- **Запуск на ходу:** `PluginServices` — живые списки справки, команд и источников. Включение навыка
  незапущенного плагина вызывает `PluginServices.load(name)` (тот же `setup` с тайм-аутом); новый источник
  ядро начинает читать сразу. Выключение плагин не выгружает — только закрывает гейты. Плагин, включённый в
  панели целиком, запускается и при следующем старте.
- **Хранение:** `[skills].file` — `data/skills.json`, у английского издания `data/en/skills.json`
  (`JsonSkillChoices`, запись через временный файл). `user.toml` приложение не переписывает.
- **Протокол:** `skills.action {action: list|set, id, enabled}` и `skills.state`. Установленные пакеты ищутся
  только по `list`, то есть когда открыта панель: обычный запуск без плагинов по-прежнему их не ищет.
- **Системный промпт не меняется:** список навыков в нём ломал бы кэш при каждом переключении (T-03).

## Последствия
- Переключение действует со следующей реплики; идущий ход не рвётся.
- Сервис хода подключает справку, только когда появился первый инструмент: без плагинов — ни одного вызова.
- Плагин, запущенный из панели, работает до выхода, даже если навык выключить.
