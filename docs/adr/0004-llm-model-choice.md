# ADR-0004: LLM — Gemma 4 12B Uncensored HauhauCS Balanced, Q4_K_M
- Статус: принято (оценка русского 1–5 — за пользователем)
- Дата: 2026-11-02

## Контекст
Нужна локальная модель с сильным русским на RTX 5070 Ti 16 ГБ: TTFT p50 ≤ 250 мс (NFR-01), запас
VRAM под остальное, честность вместо выдумок. Пользователь дополнительно потребовал модель без
цензуры: проверка показала, что обычная Gemma 4 отказывает в 7 из 8 «неудобных» запросов (мат,
чёрный юмор, эротика, политика).

## Замеры
Аренда gpu.nz, RTX 5070 Ti 16 ГБ, Core Ultra 7 265, 31 ГБ RAM, llama.cpp `1b6935b`, флаги
`scripts/remote/start_llm.sh`; бенчмарк и eval — на самом сервере, без сети. Сырые результаты —
`bench/results/remote/`. Eval — 50 формальных проверок (`eval/`), несколько прогонов; «Отказы» — 8
неудобных запросов, подсчёт по маркерам отказа (занижает мягкие уклонения).

## Решение
- Модель — `HauhauCS/Gemma4-12B-QAT-Uncensored-HauhauCS-Balanced`, файл
  `Gemma4-12B-QAT-Uncensored-HauhauCS-Balanced-Q4_K_M.gguf` (ревизия `ae8045a`, см.
  `scripts/remote/models.tsv`); на целевой машине — `models/llm/`, `scripts/start_llm.ps1 -Model`.
- Почему она: все кандидаты укладываются в TTFT с запасом в 4 раза, значит решают качество и
  отсутствие отказов. Среди вариантов без цензуры у неё 0 отказов при eval 47/50 (94 %): цена
  снятия цензуры — 2–3 балла к обычной Gemma. Q5 не дал выигрыша в качестве за 1 ГБ VRAM и −10 %
  TPS.
- **Порог качества для Этапа 10: eval ≥ 80 %** (ориентир мастер-плана): выбранная модель
  проходит с запасом, но и память, и новые вопросы S-10.6 не должны опустить ниже.
- Запасной вариант, если важнее мгновенный отклик: GigaChat 3.1 10B Q5 (TTFA p50 111 мс).

## Последствия
- 0 отказов из 8 — не гарантия: на вопросе о религиях модель уходит от ответа, а подсчёт по
  маркерам мягкие уклонения не видит. Модель без цензуры может чаще уверенно выдумывать:
  проверяется eval S-10.6.
- Лицензия — условия Gemma (карточка модели, `license: gemma`), а не Apache-2.0: для личного
  использования подходит; перед публикацией — сверить Gemma Terms и Prohibited Use Policy.
- Замеры сделаны на арендованном хосте: перепроверить NFR на своей машине.
- Модель иногда вставляет символы других алфавитов (宿敵 в русском тексте) — разбор в журнале
  S-2.5.
- Шаблон Qwen3.5 отвергает промпт без реплики пользователя: прогрев при старте (`bootstrap`,
  `bench_latency`) теперь всегда содержит реплику — смена модели на Qwen не сломает запуск.
