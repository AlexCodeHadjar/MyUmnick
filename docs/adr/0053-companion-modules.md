# ADR-0053: Спутник — отдельный модуль из подпакетов (SOLID)

- Статус: принято
- Дата: 2026-11-17

## Контекст
Пользователь попросил выделить спутника как сложный модуль, разбить на мелкие модули и переписать по
правилам и принципам SOLID.

Было:
- 30 файлов в одной папке;
- `Companion.svelte` около 950 строк: вид, события оболочки, присутствие, жесты, органы чувств,
  исполнение решений, облачко, радио;
- `brain.ts` около 650 строк: движение, физика, выбор позы и типы вместе.

## Решение
Подпакеты по ответственности, импорт между ними — через `index.ts` (R-06). Описание —
`ui/src/features/companion/README.md`:
- `space`, `body`, `look`, `senses`, `phrases`, `behavior`, `mind` — модели и чистые функции;
- `controller/` — классы с одной ответственностью:

  | Класс | Ответственность |
  |---|---|
  | `Presence` | присутствие на экране |
  | `Scout` | органы чувств в мире |
  | `Gestures` | мышь |
  | `Speech` | облачко |
  | `Conductor` | исполнение действий «Разума» |
  | `CompanionController` | сборка |
- **инверсия зависимостей:** `Ports` — интерфейс оболочки. Классы получают его через конструктор и не
  знают о Tauri;
- **открыт для расширения:** новое действие — запись в `mind/activities.ts` и ветка в `Conductor`;
  новый источник наблюдений — метод `Scout`;
- **`body/pose.ts`:** выбор позы — чистая функция, тело только собирает своё состояние;
- **`Companion.svelte`:** только вид. Ошибка одного кадра больше не останавливает цикл кадров.

Поведение не меняется. Публичный API пакета (`index.ts`) прежний.

## Последствия
- Каждую часть можно тестировать отдельно: `controller/parts.test.ts`, `body/pose.test.ts`.
- `brain.ts` по-прежнему крупный (≈600 строк: движение и фазы). Следующий шаг — вынести физику падения
  и маршруты.
