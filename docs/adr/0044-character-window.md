# ADR-0044: Окно персонажа — картинка пользователя по умолчанию, сфера — по выбору
- Статус: принято
- Дата: 2026-11-16

## Контекст
Пользователь попросил выключить сферу (ADR-0038) и показывать в окошке своего персонажа — картинку, которую
можно сменить, перетащив файл в окошко. Сфера остаётся вариантом (ответ пользователя, `STAGE_23.md` 9.1).

## Решение
- **Вид показа** (`avatar/view.ts`): `portrait` (по умолчанию) или `orb`, выбор — в меню по правой кнопке на
  окошке, хранится в localStorage `vtuber.avatar.view`. Смена вида пересоздаёт сцену (`{#key}`).
- **`PortraitRenderer`** — реализация `AvatarRenderer` на одном `<img>` и CSS-трансформациях: дыхание (масштаб
  1.000…1.012, 3,5 с), покачивание ±0,6°, подскок по громкости речи, свечение по цвету эмоции (палитра сферы),
  вспышка на зов «Умник», наклон к курсору, «• • •» при долгом ожидании. Canvas и WebGL не нужны: браузер сам
  декодирует картинку, анимированные GIF/WebP/APNG работают без нашего кода.
- **Хранение картинки — IndexedDB окна** (`vtuber-character`), а не файл через команду оболочки: не нужны ни
  новые команды Rust, ни asset-протокол Tauri, работает и во вкладке браузера; спутник (S-23.5+) того же
  происхождения увидит ту же картинку. Проверка: PNG, JPEG, WebP, GIF, APNG; до 20 МБ; битый файл — силуэт.
- **Перетаскивание:** у окна Tauri выключен `dragDropEnabled` — иначе оболочка перехватывает файлы, и HTML5 `drop`
  их не получает. Перетаскивание файлов больше нигде в окне не используется.
- **Стандартный персонаж** — наш SVG-силуэт по пояс (`portrait/silhouette.svg`).
- Меню: «Сменить картинку…», «Вписать целиком / Заполнить окошко» (localStorage `vtuber.character.fit`),
  «Вернуть стандартную», «Показывать сферу / персонажа».

## Последствия
- Новых зависимостей и прав окна нет.
- Картинка живёт в профиле WebView2: переустановка с очисткой данных окна её сотрёт (её можно перетащить снова).
