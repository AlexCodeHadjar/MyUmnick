# ADR-0055. Визуальные реакции на действия Windows

Слой спутника получает вид события и размер для покачивания коробки. Поток раз в две секунды проверяет видимость слоя. После скрытия начальные снимки собираются заново.

Копирование определяется по смене поколения буфера и наличию текстового формата. Скриншот — появление PNG в стандартной папке снимков. Размер растущего нового файла в «Загрузках» определяет вес коробки. Большие каталоги пропускаются. Содержимое файлов и буфера не запрашивается. Клавиатурных хуков нет.

Штамп запускает Ctrl+V при текстовом формате в буфере. Для ветра требуется Win+D и активный рабочий стол после сочетания. Для взмаха проверяется, существует ли ещё окно, которое было активным. Сворачивание сохраняет окно. Содержимое вставки спутнику не передаётся.

Во время ввода, полноэкранного просмотра, жеста или спокойного режима реакция пропускается. Шанс и пауза определяются настройками каждого события.
