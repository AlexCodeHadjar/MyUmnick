# ADR-0032: Издания — слой конфига и свои данные, а не форк программы
- Статус: принято
- Дата: 2026-11-09

## Контекст
Этап 20: программа выходит в двух изданиях — русском (как сейчас) и английском без цензуры. От языка
зависят персона, голос, слух, память, промпты и модель (`docs/stages/STAGE_20.md`, раздел 1). Ядро грузит
голос, Whisper и прогревает LLM под конкретный язык, поэтому издание должно быть известно до старта.
Русское издание не должно измениться; у пользователя уже есть `config/user.toml` с русской персоной и
голосом, а у мастера — `config/setup.toml`.

## Рассмотренные варианты
1. **Две программы (форк или ветка)** — просто сначала; дальше две копии кода расходятся, каждую оптимизацию
   скорости приходится делать дважды.
2. **Переключение языка внутри работающего ядра** — без перезапуска, но смена голоса, Whisper, памяти и модели
   — это тот же перезапуск, только хрупкий, и в горячем пути появляются проверки языка.
3. **Издание — слой конфигурации + языковой пакет + свои данные, выбирается до старта ядра.**

## Решение
Вариант 3.
- Секция `[edition]` (`id`, `language`, `content_profile`, `stream_safe`) — `bootstrap/edition.py`;
  значения `EditionId`, `ContentProfile` — в домене.
- Выбор: `python -m vtuber [chat|serve] --edition <id>`, иначе `VTUBER_EDITION__ID`, иначе `ru`.
- Порядок слоёв (`kernel.ConfigFiles`): `default.toml` < `editions/<id>.toml` < выбор мастера < `user.toml` <
  `user.<id>.toml` < `VTUBER_*`. Выбор мастера у `ru` — прежний `setup.toml`, у остальных — `setup.<id>.toml`.
- Языковые ключи общего `user.toml` (`LANGUAGE_BOUND_KEYS`: персона, голос, фразы-заглушки, язык и имена слуха,
  пути памяти, модель llama-server, `chars_per_token`, файл мастера) действуют только в `ru`; в других изданиях
  отбрасываются с предупреждением `config.user_keys_ignored` в логе. Личные правки издания — `user.<id>.toml`.
- `[edition].id` после загрузки сверяется с выбранным изданием: файл или переменная не подменят издание молча.
- Данные: `ru` — прежние пути (`data/memory.sqlite`, `data/vault`), ничего не переносится; `en` — `data/en/`.
- Умолчания `default.toml` остаются русскими: `editions/ru.toml` задаёт только `[edition]`.

## Последствия
- Русское издание без `--edition` работает как раньше; все инструменты (`tools/*`) читают `ru` без изменений.
- Новое издание — файл `config/editions/<id>.toml` и значение в `EditionId`; языковые тексты ядра — языковой
  пакет (S-20.2).
- Пока нет английских персоны, голоса и модели (S-20.3, S-20.5, S-20.9), `--edition en` говорит русскими
  умолчаниями, но с английским Whisper и своей памятью.
- Сборка ядра уже копирует `config/` целиком, значит и `config/editions/`; личные `user.<id>.toml` из поставки
  нужно убирать так же, как `user.toml` (S-13.3; сборка — только по команде пользователя).
