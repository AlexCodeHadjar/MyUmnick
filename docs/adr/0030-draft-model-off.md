# ADR-0030: Черновик MTP пока выключен
- Статус: принято
- Дата: 2026-11-03

## Контекст
S-9.3: включить черновую модель при приросте ≥ 15 %. У основной модели есть черновик MTP (253 МБ), режим `draft-mtp`, `n-max 2`.

## Замер (RTX 5070 Ti, `docs/perf/report-2026-11-03.md`)
| | Без черновика | С черновиком |
|---|---|---|
| TPS p50 | 85 | 132 (+56 %) |
| TTFT p50 / p95 | 89 / 207 мс | 90 / 204 мс |
| TTFA p50 / p95 / макс | 318 / 624 / 809 мс | 310 / 520 / 568 мс |
| VRAM | 8645 МБ | 8949 МБ |
| Качество, 150 кейсов | 147–148 | 145 |
| Теги эмоций: есть / уместны | 97 % / 93 % | 90 % / 87 % |
| Жесты: уместны | 80 % | 73 % |

Текст ответов с черновиком другой, хотя по замыслу не должен меняться. Выборки эмоций и жестов малы, один прогон, температура 0,7: падение может быть случайным.

## Решение
Порог прироста пройден, но черновик не включаем: бюджет выполнен и без него, первый звук почти не меняется, а просадка качества возможна.
Контекст оставляем 16384: 8192 экономит 132 МБ и ничего не ускоряет. Подбор кванта уже сделан в ADR-0004.

## Последствия
- Без изменений в конфиге; файл черновика приложению не нужен.
- Включается через `[llama_server].extra_args`, если новый голос потребует запаса по TTFA: максимум 809 мс выше цели на 9 мс, а черновик дал 568 мс.
- Перед включением повторить eval несколько раз: нынешняя выборка спора не решает.
