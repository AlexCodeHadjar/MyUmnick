# ADR-0036: Интернет по смыслу реплики — погода, новости, свежие факты
- Статус: принято (дополняет ADR-0022)
- Дата: 2026-11-10

## Контекст
Пользователь хочет спрашивать обычными словами — «Какая сегодня погода в Москве?», «Какие новости про ИИ?» — и
получать настоящие данные, без фразы «найди в интернете». ADR-0022 разрешал поиск только по явной просьбе и только
через локальный SearXNG. Приоритет 1 — скорость: обычные реплики не должны ждать сеть.

## Рассмотренные варианты
1. **Модель сама вызывает инструменты** (`llama-server --jinja`, tool calling) — гибко, но лишний запрос к модели на
   ход, а у Gemma 4 в llama.cpp поддержка инструментов нестабильна; проверять — на аренде.
2. **Агент-браузер (Browser Use)** — секунды на шаг и несколько вызовов модели; для погоды и новостей избыточно.
3. **Правила по словам + узкие источники** — микросекунды на обычную реплику; выбран.

## Решение
- `intent.classify`: погода («погода», «температура», «дождь», weather…), новости («новости», «что нового»,
  news…), свежие факты («курс …», «сколько стоит», «кто выиграл», latest…), явная просьба — как раньше. Русский и
  английский; `[plugins.settings.web_search].auto = false` возвращает прежнее поведение (только явная просьба).
- **Погода — Open-Meteo** (`geocoding-api` + `forecast`, без ключа). Исключение из «только localhost» ADR-0022:
  наружу уходят название города и координаты, не текст реплики. Выключается `weather = false` (тогда погода ищется
  через SearXNG). Город не назван — `home_city`. Падеж («в Москве») — простые варианты именительного падежа.
- **Новости — SearXNG** (`categories=news`, `time_range=day`, язык издания) и текст первой статьи через
  **trafilatura** (Apache-2.0, без браузера; группа `web`, разбор — в потоке). Статья скачивается с самого сайта:
  это ещё один выход в интернет, `read_pages = 0` его отключает.
- Защита — как в ADR-0022: страницы — чужой текст, атаки отбрасываются, текст обрезается, источники видны в чате;
  зрители и приватный режим инструментов не получают (S-12.11, S-17.2). Плагин по-прежнему выключен по умолчанию.
- Срок инструмента — `2 × timeout_s + 1`: новости — поиск и чтение статьи подряд.

## Последствия
- Без включённого плагина приложение офлайн, как раньше (NFR-06).
- Ход с погодой или новостями ждёт сеть (обычно до секунды у Open-Meteo, несколько секунд у новостей) — TTFT такого
  хода вне обычного бюджета, осознанно. Обычные реплики не задерживаются.
- Правила промахиваются: «расскажи о погоде на Марсе» уйдёт в сервис погоды, а вопрос без ключевых слов не найдёт
  ничего. Точнее — вызов инструментов моделью (вариант 1), после проверки на аренде.
- Open-Meteo бесплатен только для некоммерческого использования.
