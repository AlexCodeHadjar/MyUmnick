# ADR-0056. Находки из недавних документов Windows

Окно спутника редко запрашивает одну находку через команду Tauri. Фоновая задача обращается к каталогу «Недавние»: читает метаданные ярлыка через Windows Script Host и получает его значок Windows. В слой отдаются только имя без пути и изображение значка. При запрете политикой Windows сцена пропускается.

Осмотр длится четыре секунды. В карман попадает только исход с сохранением. Показанные имя и значок хранятся локально, до 12 уникальных имён, без пути и даты документа. Карман можно очистить. Все сценические действия с документом рисует интерфейс.

Постройка растёт за каждые 15 минут присутствия и активности, хранит дату и длительность. По смене местного дня начинается новая постройка. Сброс доступен в меню спутника. Записка запоминается в окне до смахивания или закрытия приложения. Поле ввода, полный экран и жест удержания временно скрывают декоративные элементы. Включение спокойного режима прекращает новые находки и записки.
