# ADR-0040: Обращение по имени «Умник» — запрос без имени и ожидание запроса
- Статус: принято (на живом микрофоне не проверено)
- Дата: 2026-11-10

## Контекст
Пользователь попросил: сфера реагирует, когда её зовут; имя — «Умник»; после имени — текст запроса. Режим «по
имени» уже был (S-14.1, ADR-0026), но имя было «мика», уходило в запрос вместе с текстом, а одно имя без запроса
просто отбрасывалось.

## Решение
- `[stt.addressing]`: `mode = "by_name"` по умолчанию, `names = ["умник", "умничка"]` (у `en` — `umnik`, `oomnik`,
  `umnick`), новое `follow_up_s = 8.0`.
- `AddressedEvents`: имя и слова-обращения вырезаются (`without_call`), в ход уходит только запрос
  («Умник, какая погода?» → «какая погода?»); метка собеседника (S-14.3) остаётся. Одно имя («Умник!») открывает
  окно `follow_up_s`: следующая фраза — запрос, даже без имени.
- Персона называется «Умник» (`personas/default.toml`, `mika_long.toml`), в английском издании — «Umnik»; эталон
  русского промпта переснят: изменилось только имя.
- Реакция: в режиме «по имени» `input.barge_in` приходит ровно тогда, когда услышано имя. Стор считает обращения
  (`store.called`), сцена зовёт необязательный `AvatarRenderer.attend()`; сфера вспыхивает (свет, ореол, пульс)
  и затухает за пару секунд.

## Последствия
- Посторонняя речь не запускает ход (как и раньше в `by_name`); чтобы говорить без имени — `mode = "always"`.
- Качество распознавания имени Whisper'ом на живом микрофоне не проверено: если «Умник» пишется иначе, вариант
  добавляется в `names`.
