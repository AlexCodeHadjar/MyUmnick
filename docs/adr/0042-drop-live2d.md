# ADR-0042: Live2D убран из проекта
- Статус: принято (заменяет ADR-0011)
- Дата: 2026-11-16

## Контекст
С Этапа 22 справа показывалась сфера (ADR-0038), Live2D остался только «по имени» модели. Пользователь попросил
убрать модель и всё, что с ней связано: дальше персонаж — картинка в окне и спутник по экрану из кадров PNG
(Этап 23). Live2D к тому же нёс самое тяжёлое ограничение лицензий: приложение, загружающее модели, — Expandable
Application, нужно соглашение со всеми издателями (`docs/licenses.md`).

## Решение
- Удалены `ui/src/features/avatar/live2d/` (рендер, загрузчик Cubism Core, геометрия, настройки), `mapping.ts`,
  выбор модели в мастере (`onboarding/avatar.ts`, `parseAvatars`/`loadAvatars`), `VITE_AVATAR`.
- Зависимости `pixi.js` и `untitled-pixi-live2d-engine` сняты (`pnpm remove`, −14 пакетов).
- `ui/public/live2d/` и `ui/public/avatars/` (Cubism Core, модель Haru, `mapping.json`) удалены; правила `.gitignore`,
  ESLint и Prettier для них — тоже.
- Остаётся контракт `AvatarRenderer`: `load()` теперь без аргументов — вид сам знает, что грузить. Общий расчёт
  взгляда — `avatar/gaze.ts`. Вид показа выбирается в `avatar/view.ts` (localStorage `vtuber.avatar.view`); пока
  есть только сфера, окно персонажа добавит S-23.4 (ADR-0044).

## Последствия
- Лицензионного ограничения Live2D больше нет; строки о нём сняты из `docs/licenses.md`.
- Сохранённое имя модели (`vtuber.avatar` в localStorage) больше не читается: при старте — вид по умолчанию.
- Старые этапы (6, 13, 20) и журналы сессий не переписываются: там Live2D — история.
