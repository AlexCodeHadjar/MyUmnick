# Проверка аватара-спутника и его чек-листа — задание для GPT

_Версия проекта на момент составления: **0.2.1** (2026-11-18). Версия видна вверху главного окна и в заголовке
чек-листа: `v0.2.1 · <коммит>[*] · <время сборки>`; `*` значит, что в рабочей копии есть изменения не в git._

Ты проверяешь **персонажа, который гуляет по рабочему столу** («Сопровождение», спутник) и **окно персонажа**.
Твоя цель — пройти каждый пункт ниже, отметить результат и составить отчёт по форме из раздела 9.
**Код не исправляй**, пока пользователь не попросит: сначала отчёт.

Общий контекст проекта и правила — `docs/HANDOVER_CHATGPT.md` (раздел ⚠️ — твоя зона). Кадры персонажа —
`docs/character/FRAMES-6.md` и `FRAMES-6-REVIEW.md`. Код спутника — `ui/src/features/companion/` (карточка
`README.md`) и `ui/src-tauri/src/companion.rs`, `companion/desktop_events.rs`, `desktop.rs`.

## 1. Подготовка

1. Запуск: `cd ui; pnpm tauri dev` (или `scripts/launch.ps1`). Код подхватывается сразу: фронтенд — на лету,
   Rust — пересборкой и перезапуском окна.
2. Убедиться, что запущен свежий код: вверху главного окна версия **0.2.1** и время сборки не старше последней правки.
   Если версия старая — перезапустить `pnpm tauri dev`.
3. Включить спутника: меню окна персонажа → «Сопровождение» → **«Всегда»** (на время проверки). В режиме
   «Когда окно свёрнуто» спутник прячется, пока главное окно открыто, — это не ошибка.
4. Выключить «Спокойнее» (меню спутника, правый клик по персонажу).
5. Открыть **чек-лист** (раздел 2) и держать его открытым во время проверки.

Автопроверки перед ручной проверкой (все должны быть зелёными):

```powershell
cd ui; pnpm test; pnpm check; pnpm lint; pnpm format:check
```
```powershell
cd ui/src-tauri; cargo clippy -- -D warnings; cargo fmt --check; cargo test
```

Строки считает слой спутника (`look/checklist.ts`), показывает — панель `look/Checklist.svelte`.

| # | Проверка | Ожидается |
|---|---|---|
| 2.1 | Главное окно → у персонажа (окошко справа, значки внизу) кнопка **☑** | Кнопка есть; подсказка «Чек-лист: когда он что делает» |
| 2.2 | Нажать ☑ | Слева сверху панель «Когда он что делает»; в заголовке версия `v0.2.1 …`. Если спутник выключен — надпись «Жду данные от спутника…» |

| 2.4 | Панель обновляется | Значения меняются сами примерно 2 раза в секунду (например, «Стоит на месте» при перетаскивании) |
| 2.5 | Раздел **«Что он видит сейчас»** | Строки: на экране, режим, программа в фокусе (имя exe), полный экран, идёт видео, активен рабочий стол, вы печатаете, стоит на месте, смотрит фильм, «Спокойнее». Значения «да/нет» без цветной полосы |

| 2.7 | Раздел **«На ваши действия»** | 6 реакций: готов/не сейчас, шанс %, пауза «N с» после срабатывания |

## 4. Действия «Разума» (сами по себе)

Баллы и паузы — `ui/src/features/companion/mind/activities.ts` (ADR-0051 и дополнение 2026-11-18).

| Действие | Когда | Что видно | Проверка |
|---|---|---|---|
| Отдыхает (`idle`) | Всегда, 0,2 балла | Стоит, дышит, моргает | Есть почти всегда «сейчас», когда больше ничего не хочется |
| Сидит на музбоксе (`jukebox`) | Радио включено | Название станции видно на ящике, поза сохраняется на паузе | Включить радио во время просмотра, поставить на паузу, затем выключить |
| Смотрит фильм (`watch`) | Видео на весь экран / в плеере / на видеосайте со звуком | Идёт в угол, садится **с попкорном**, изредка тихо комментирует | См. раздел 6 |
| Выглядывает (`hush`) | Полный экран без видео (игра) | Выглядывает из-за правого края | Открыть игру/презентацию на весь экран |
| Идёт к окну (`follow`) | Режим «Следовать», сменили программу | Идёт к новому активному окну | Alt+Tab |
| **Гоняется за курсором (`trail`)** | Режим «Следовать», стоит без дела | ~8 с идёт за мышью (лезет по краю, свисает сверху), потом **не меньше минуты не гоняется** | Засечь время: погоня не дольше ~10 с, повтор не раньше 60 с; в «Стоять на месте» и «Спокойнее» — никогда |
| Говорит сам (`chat`) | Соскучился; не чаще раза в минуту | Облачко с фразой | — |
| Тычет в кнопки (`poke`) | Любопытно, есть окно, не «Спокойнее»; раз в 3 мин | Подлетает к кнопке, тычет пальцем, называет её | Ничего не нажимает на самом деле |
| Прыгает по значкам (`hop`) | Активен рабочий стол | Прыгает со значка на значок | Win+D, подождать |
| Гуляет (`wander`) | Засиделся, режим не «Стоять» | Прогулка по опоре | — |
| Играет (`play`) | Гладят, подбрасывают, водят мышью рядом | Радуется, танцует | — |

**Критерий «не слишком часто»:** за 5 минут простоя в режиме «Следовать» погоня за курсором занимает меньше
трети времени (это же проверяет тест `mind/mind.test.ts`).

## 5. Реакции на действия пользователя

Общее условие (строка над разделом в чек-листе): персонаж на экране и **стоит**, «Спокойнее» выкл., нет полного
экрана, не смотрит фильм, вы не печатаете (кроме вставки, копирования, закрытия окна и перехода на рабочий стол; эти действия разрешены и на ходу). У каждой реакции своя пауза. Код:
`behavior/desktopEvents.ts`, `controller/subscriptions.ts`, сигналы — `src-tauri/src/companion/desktop_events.rs`
(опрос раз в 2 с — реакция может прийти с задержкой до 2 с).

| # | Действие | Ожидается | Шанс / пауза | Как распознаётся и ограничения |
|---|---|---|---|---|
| 5.1 | **Ctrl+V** | Удар штампом (`stamp`), красный оттиск «Вставлено!» | 100 % / 2,5 с | Скопировать текст, подождать 3 с и вставить его в редактор. Ctrl+S штамп не запускает |
| 5.2 | **Win+D** | Персонажа сдувает ветром (`blown`) | 100 % / 2,5 с | Показать рабочий стол сочетанием Win+D. Закрытие последнего окна и обычный щелчок по рабочему столу ветер не запускают |
| 5.3 | Скопировать текст | Ловит бумажку и прижимает к груди (`hug_paper`) | 100 % / 2,5 с | Только факт копирования; содержимое буфера не читается. Картинка в буфере — не считается |
| 5.4 | Скриншот (Win+PrtScr) | Зажмуривается и закрывается руками (`flinch`), белая вспышка | 65 % / 45 с | Новый PNG в «Изображения → Снимки экрана». Win+Shift+S без сохранения файла — не распознаётся |
| 5.5 | Скачать файл | Тащит коробку на спине (`carry_box`), шатается сильнее у больших файлов | 65 % / 45 с | Новый **растущий** файл в «Загрузках» |
| 5.6 | Закрыть окно | Машет вслед (`wave`) | 100 % / 2,5 с | Открыть отдельное окно редактора, затем закрыть. Сворачивание и смена фокуса взмах не запускают |

Для проверки вставки повторить Ctrl+V после паузы в 3 секунды.

## 8. Внешний вид кадров

Для каждой сцены из разделов 5–7:

- [ ] Персонаж **одного роста** во всех позах, не «прыгает» в размере между кадрами одной сцены.
- [ ] Ноги на опоре (край окна, пол), не висят в воздухе и не проваливаются.
- [ ] Высокие кадры (поднятый штамп, рожки) не обрезаны сверху.
- [ ] Нет ореола, тёмного облака, белой рамки вокруг персонажа.
- [ ] Одноразовые сцены (штамп, бумажка, испуг, падение, находка, постройка, записки) идут **кадр за кадром один
      раз** и не зацикливаются; циклы (коробка, бег, ветер, хобби) — плавные.
- [ ] У слоя спутника **нет полосы заголовка** «AI VTuber — companion» сверху экрана.
- [ ] Известные слабые кадры (FRAMES-6-REVIEW.md): `knock` читается как «ура», у `inspect_1/3` злой прищур,
      карман в `stand_pocket*` почти не виден — отметить, мешает ли это на экране.

## 9. Форма отчёта

Сохранить как `docs/character/QA-REPORT-<дата>.md`:

```markdown
# Отчёт проверки спутника — <дата>, версия <из заголовка чек-листа>

## Итог
Пройдено N из M. Блокирующие проблемы: …

## Таблица
| Пункт | Результат | Что увидел | Чек-лист в этот момент |
|---|---|---|---|
| 5.2 Win+D | ✗ | остался сидеть в воздухе | Активен рабочий стол: да; Стоит: да; Сдувает ветром: не сейчас, пауза 12 с |

## Проблемы
1. <пункт> — что ожидалось, что произошло, шаги, частота (k из n), снимок экрана.
   Подозрение на место в коде (файл:строка), если есть.
```

Правила отчёта: для каждой неудачи — **значения из чек-листа в момент ошибки**; повторять неустойчивые пункты
не меньше 3 раз и писать частоту; не путать «не сработало» с «не выпал шанс» (смотреть шанс и паузу в чек-листе).
