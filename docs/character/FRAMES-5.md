# Реакции настольного спутника

## Тянется к курсору

Кадр `reach.webp` подготовлен по эталонной стойке. Задание для генерации: тот же персонаж в три четверти вправо, стоит на обеих ногах, взгляд направлен на приближающийся курсор, одна рука тянется вперёд. Курсор в кадр не включать. Сохранить кремовую маску, форму капюшона и пламени, мягкий верхний свет и прозрачный фон. В пакете WebP 526 × 768, качество 90, опора ступней (0,5; 0,97). Масштаб выровнен по маске существующей стойки. Длительность реакции 0,9 с.

## Сцены

| Действие | Кадры и эффект |
|---|---|
| Поглаживание | Смена направления курсора три раза за 1,3 с внутри фигуры включает готовую реакцию `pet` с сердечками. |
| Край окна | Сидящая фигура опускается за верхний край и вновь появляется за 4,2 с. Холст обрезается по линии опоры. |
| Стекло | За 2 с от поднятой руки расходятся три затухающих кольца. |
| Хобби | Книга, карандаш с листом и три подбрасываемые иконки рисуются поверх поз на протяжении 4,2 с. |
| Спотыкание | При начале ходьбы шанс 1,5 %. За 0,85 с фигурка теряет равновесие и возвращается к ходьбе. |
| Жук | Голубой жук движется перед фигурой; Мика делает несколько шагов вслед за ним. |
| Системные реакции | Коробка покачивается с амплитудой по размеру загрузки; штамп локализован; бумажка летит к груди; вспышка, взмах рукой и ветер используют готовые позы. |
| Находка | Системный значок с подписью поднимается и покачивается. За 4 с он возвращается, попадает в карман или летит в нарисованную корзину. |
| Долгие действия | Бумажные блоки в рабочей области появляются за накопленное время активности. Стикер остаётся до снятия. |

Предметы и эффекты рисуются средствами canvas/CSS. Новых звуков для этих сцен нет.
