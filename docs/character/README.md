# Персонаж

Встроенный персонаж лежит в `ui/public/characters/default/` (WebP, высота 768, ~0,9 МБ на все позы):
- его позы берёт спутник («Сопровождение»), если пользователь не загрузил свои папкой;
- поза `stand` — картинка окошка персонажа по умолчанию.

Список файлов — `index.json`.

**Анимация (2026-11-17):**
- `<поза>_1…N` — цикл позы, частота — `LOOP_FPS` в `pack.ts`;
- `<поза>_talk_1…N` — рот по громкости голоса;
- `<поза>_blink_1` — полуприкрытые глаза.

Кадры подгоняются тем же преобразованием, что их поза. Для цикла ходьбы опора — ступни каждого кадра: ноги
двигаются. Промпты — шаг 4 в [prompts.md](prompts.md).

## Откуда
Кадры сгенерированы пользователем 2026-11-16 по промптам из [prompts.md](prompts.md): PNG 1024×1536 с прозрачным
фоном. Это 11 поз и варианты `_blink` / `_talk` к `stand`, `sit_edge`, `laydown`. Эталонный лист
(`character-reference.png`) в пакет не входит.

## Как подогнаны (2026-11-17)
Генератор рисует позы в разном масштабе, а программа рисует каждую картинку одной высоты. Поэтому кадры
приведены к одному холсту:
1. **Масштаб к позе `stand`.** Это среднее двух замеров: высоты белой маски и ширины капюшона на уровне лица. Лёжа
   масштаб подобран на глаз: маска видна сбоку. Итог: `walk` 0,9; `lean_side` 1,05; `sit_edge` 0,92;
   `perch_corner` 0,945; `sit_corner` 0,83; `held` 0,95; `hang_side` 1,0; `float` 0,9; `laydown` 1,47; `sleep` 1,1.
2. **Точка опоры** — туда, где её ждёт `ANCHORS` в `ui/src/features/companion/pack.ts`. Высота — доля холста 1536,
   по горизонтали — середина:
   - ступни и низ тела: середина непрозрачного в нижних 90 px, на высоте 0,97 (`stand`, `walk`, `lean_side`),
     0,95 (`sit_corner`), 0,92 (`laydown`, `sleep`);
   - сиденье `sit_edge` и `perch_corner`: 1030 px исходника — там же руки на краю, на высоте 0,62;
   - `held`: кончик капюшона, на высоте 0,06. Кадр взят из повторной подгонки пользователя
     (2026-11-17): в ней кончик ровно по центру, а в первой версии он был смещён на 39 px;
   - `hang_side`: кулаки (верх), на высоте 0,04;
   - `float`: середина, на высоте 0,6.
3. **Варианты** `_blink` / `_talk` подгоняются тем же преобразованием, что их поза: они совпадают с ней до пикселя.
4. **Экспорт:** WebP, качество 90, высота 768. На экране персонаж ~300 px, поэтому вдвое меньше исходника хватает
   и на масштабе 200%.

Подгонка делалась одноразовым скриптом на Pillow (Pillow не зависимость проекта). Для новых кадров повторить шаги
выше или попросить ИИ-ассистента.
