# application/tools — справка хода от инструментов плагинов

## Ответственность
Опрашивает инструменты плагинов до запроса к LLM и собирает их ответы в `TurnHints`. Сами инструменты
живут в плагинах (`plugins/tools`). НЕ разбирает реплику и не выполняет ничего сам.

## Публичный API (`__init__.py`)
| Символ | Назначение |
|---|---|
| `ToolContext(providers, timeout_s)` | `hints(text)`: параллельный опрос, не успевшие отменяются |

## Зависимости
- application.memory (`TurnHints`), kernel (`ContextProvider`).

## Инварианты
- Медленный или упавший инструмент не задерживает ход дольше срока и не роняет его: только лог.
- Вызывается только для реплик ведущего (`ConversationService.handle`, `external=False`).
