# application/setup — мастер первого запуска

## Ответственность
Что нужно приложению и что посоветовать этой машине, установка выбранного с проверкой сумм, запись выбора
в конфиг. НЕ ходит в сеть и не опрашивает карту сам: это порты `FileFetcher`, `GpuProbe`. Каталог —
`config/catalog.toml`, включение — `[setup].enabled` (в поставке включён, при разработке нет).

## Публичный API (`__init__.py`)
| Символ | Назначение |
|---|---|
| `SetupCatalog`, `CatalogItem`, `CatalogFile`, `recommend(catalog, gpu)` | Каталог и совет этой машине |
| `Installer(root, fetcher, free_disk)` | `is_installed(item)`, `install(items, progress)`: докачка `.part`, сумма, атомарная замена |
| `SetupWizard(catalog, installer, probe, write_choice)` | `state()`, `start(choice, progress, finished)`, `cancel()` |

## Инварианты (`tests/unit/application/setup/`)
- Без вызова `start` не скачивается ничего; его UI делает только после согласия пользователя.
- Файл появляется под своим именем только после проверки суммы; неверная сумма — `.part` удаляется.
- Путь из каталога не выходит за пределы корня; места на диске не хватает — отказ до загрузки.
- Обязательный компонент снять нельзя, даже если он не советуется для этой карты: только предупреждение.
- Выбор пишется в `config/setup.toml` целиком; правки пользователя в `user.toml` важнее и не трогаются.

## Ограничения
- `is_installed` проверяет размер, а не сумму: подмена файла после установки не заметна.
