# application/speech — текст фразы → текст, который голос прочтёт правильно

## Ответственность
Готовит фразу к синтезу: числа и проценты словами, сокращения полностью, латиница по-русски,
без разметки и эмодзи. Чистые функции без состояния. НЕ режет поток на фразы
(`pipeline.SentenceChunker`), не синтезирует (TTSPort), не меняет текст для чата — только то,
что уйдёт в TTS.

## Публичный API (`__init__.py`)
| Символ | Назначение |
|---|---|
| `normalize_for_speech(text)` | Фраза для TTS: без цифр, латиницы, разметки, эмодзи, лишних пробелов |
| `integer_to_words(n, feminine=)` | Целое словами; > 999 999 999 999 — по цифрам |
| `decimal_to_words(whole, fraction)` | «3», «5» → «три целых пять десятых»; > 3 знаков — «запятая» и цифры |
| `digits_to_words(digits)` | По цифрам: «007» → «ноль ноль семь» |
| `plural(n, forms)` | Форма слова после числа: тысяча / тысячи / тысяч |
| `latin_word_to_russian(word)`, `transliterate_latin(text)`, `spell(word)` | Латиница: словарь, аббревиатуры по буквам, транслит |

## Инварианты
- Выход не содержит цифр, латиницы, знаков разметки, эмодзи и двойных пробелов — при любом
  входе (property-тест `test_output_has_no_digits_latin_markup_or_emoji`).
- Числа — количественные в именительном падеже, согласуются только собственные слова числа
  («две тысячи», «одна целая») и «процент» («1 процент», «3 процента», «1,5 процента»).
- `5-6` — диапазон (минус только в начале слова); `3.5`, `3,5` — дробь; `1 000 000` — одно число;
  `007` — по цифрам; стык буквы и цифры («100км», «GPT4») разделяется.
- Аббревиатура латиницей до 5 букв в верхнем регистре — по буквам («GPU» → «джи пи ю»).

## Производительность
- Горячий путь: да, на каждую фразу перед TTS. Несколько регулярок на фразу из ~10 слов —
  микросекунды; функции без состояния, без аллокаций сверх результата.

## Как расширять
- Сокращение — строка в `_ABBREVIATIONS` (`normalizer.py`), символ — в `_SYMBOLS`, слово
  латиницей с особым произношением — в `_KNOWN_WORDS` (`latin.py`); тест — в
  `tests/unit/application/speech/`.
- Падежи после предлогов («в 2024 году») и порядковые — не делаются: нужен морфологический
  разбор; кандидат — отдельная сессия, если голос будет звучать плохо.
