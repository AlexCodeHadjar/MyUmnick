# adapters/gpu — опрос видеокарты

## Ответственность
Реализация `GpuProbe`: сколько видеопамяти занято на самом деле. Не решает, что с этим делать: это
`ResourceManager`. Выбор — ADR-0018.

## Публичный API (`__init__.py`)
| Символ | Назначение |
|---|---|
| `NvidiaSmiProbe(cfg)` | `memory()` → `GpuMemory` или None (нет утилиты, не NVIDIA, вышел срок) |
| `NvidiaSmiConfig` | `timeout_s` |
| `parse_memory(output)` | Разбор вывода; первая видеокарта |

## Инварианты
- Никогда не бросает из-за отсутствия карты или утилиты: менеджер работает по лимитам конфига.
- Опрос — отдельный процесс без окна; цикл событий не блокируется.

## Связанные документы
ADR-0017, ADR-0018, T-11
