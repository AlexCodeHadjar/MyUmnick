# vtuber-singing

Персонаж исполняет готовую запись по команде ведущего. **Сам плагин голос не синтезирует:** запись вы готовите заранее любым
движком (ADR-0028). Без него диалог работает как раньше.

```bash
uv pip install -e plugins/singing
```

```toml
# config/user.toml
[plugins]
enabled = ["singing"]

[plugins.settings.singing]
songs_dir = "data/songs"
```

Положите в папку WAV (16 бит, моно или стерео), например `data/songs/колыбельная.wav`, и перезапустите приложение. В чате напишите
ровно `спой колыбельная`. «Стоп», Esc или новая реплика обрывают песню. Рот двигается по звуку, как при обычной речи.

## Что важно знать

- **Только материал, на который у вас есть права.** На стриме чужая песня — вопрос авторских прав.
- Клонирование голоса реального певца без его разрешения проект не поддерживает.
- Команду может дать только ведущий и только текстом в чате: зрители и голосовой ввод её не запускают.
- В истории остаётся короткая пометка, сам звук никуда не копируется.
