# vtuber-stream-chat

Витюбер отвечает зрителям из чата Twitch. Читает канал анонимно: аккаунт и ключи не нужны, писать в
чат плагин не умеет. Это единственная часть приложения, которая ходит в сеть, поэтому он выключен,
пока не включён явно (NFR-06).

```bash
uv pip install -e plugins/stream_chat
```

В `config/user.toml`:

```toml
[plugins]
enabled = ["stream_chat"]

[plugins.settings.stream_chat]
channel = "имя_канала"
min_interval_s = 20.0              # не чаще одного ответа за столько секунд

[plugins.settings.stream_chat.filter]
blocked_words = ["слово"]
ignored_authors = ["nightbot"]

[plugins.settings.stream_chat.queue]
mention_names = ["мика"]           # обращения выбираются первыми
```

## Как выбирается реплика

- Отбрасываются ссылки, команды `!…`, сообщения не по длине, запрещённые слова и авторы, повторы.
- При наплыве теряются самые старые, а сообщения старше `max_age_s` не озвучиваются.
- Первым идёт обращение по имени, затем вопрос, при равенстве — самое новое.
- Витюбер отвечает по одному сообщению и только когда договорил. Реплика ведущего перебивает ответ
  зрителю, но не наоборот.

## Что важно знать

- Текст зрителя идёт в промпт подписанным как чужой, а явные атаки до модели не доходят: ведущий видит их
  счётчик в строке статуса. Правила обходятся перефразированием, поэтому чат без присмотра вести не стоит.
- Реплике зрителя недоступны инструменты и факты о ведущем; факты и резюме из неё не пишутся. В истории
  диалога она остаётся с той же подписью: модель видит её в следующих ходах как чужой текст.
- YouTube пока не поддерживается: его API требует ключ и квоту.
