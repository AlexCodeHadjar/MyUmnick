# vtuber-code-assistant

Помощник-программист на отдельной модели. Основная модель переводит просьбу на английский, модель для кода отвечает, код появляется в
чате, а витюбер говорит вслух только короткую фразу. **Модель пока не выбрана:** выбор и замеры — S-12.5, нужна RTX 5070 Ti.

```bash
uv pip install -e plugins/code_assistant
```

```toml
# config/user.toml
[plugins]
enabled = ["code_assistant"]

[plugins.settings.code_assistant]
code_url = "http://127.0.0.1:8081"
code_model = "code"
vram_mb = 6000                     # заменить замером S-12.5

# Без этой секции сервер модели запускаете сами. С ней он поднимается на время задачи через менеджер ресурсов.
[plugins.settings.code_assistant.server]
autostart = true
executable = "llama/llama-server.exe"
model = "models/code/model.gguf"
log_file = "logs/code-server.log"
context_size = 8192
slots = 1
ready_timeout_s = 120.0
stop_timeout_s = 5.0
extra_args = []
```

## Как работает

- Запускается только на явную просьбу: «Напиши функцию сортировки», «Помоги с кодом», «Исправь этот код».
- Ответ не ждёт помощника: витюбер сразу говорит, что передала задачу.
- `отмени код` останавливает генерацию. Вторая задача, пока идёт первая, не запускается.
- Модель недоступна — витюбер говорит об этом, диалог продолжается.
- Зрители и приватный режим помощника не запускают. Код модели не запускается, только показывается.
