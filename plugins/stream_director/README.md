# vtuber-stream-director

Режиссёр стрима: выбирает сообщения зрителей, реагирует на рейды и подписки, держит паузы и переключает
сцены OBS. Заменяет плагин `stream_chat`: вместе их не включать, иначе ответы задвоятся. Плагин `obs`
(субтитры фраз, сцены по эмоциям) может работать рядом.

```bash
uv pip install -e plugins/stream_chat -e plugins/obs -e plugins/stream_director
```

В `config/user.toml`:

```toml
[plugins]
enabled = ["stream_director"]

[plugins.settings.stream_director]
channel = "имя_канала"
min_interval_s = 20.0            # не чаще одного ответа зрителю за столько секунд
host_hold_s = 30.0               # столько молчать о чате после реплики ведущего

[plugins.settings.stream_director.queue]
mention_names = ["мика"]

[plugins.settings.stream_director.obs]
password = "пароль из OBS"
live_scene = "Эфир"
paused_scene = "Перерыв"
question_input = "Вопрос"        # текстовый источник: на чьё сообщение отвечает витюбер
```

## Как ведущий берёт управление

Все команды пишутся в чат приложения точным текстом. До модели они не доходят.

| Действие | Что произойдёт |
|---|---|
| `/пауза` | Текущий ответ обрывается, новых ответов зрителям нет, сцена меняется на `paused_scene` |
| `/продолжай` | Пауза снята, сцена `live_scene` |
| Обычная реплика ведущего | Перебивает ответ зрителю; после неё чат молчит `host_hold_s` секунд |
| Кнопка «Стоп» | Обрывает текущий ответ; следующий придёт по лимиту частоты |

Пока идёт пауза, сообщения копятся в очереди, а старше `max_age_s` не озвучиваются.

## Ручной сценарий

1. Запустить OBS, `python -m vtuber serve` и UI, написать в чат канала.
2. Обращение по имени выбирается раньше остальных, а в источнике `question_input` виден автор.
3. `/пауза`: ответ обрывается, сцена меняется, новых ответов нет. `/продолжай`: всё возвращается.
4. Написать витюберу самому посреди ответа зрителю: зритель перебит, чат молчит заданное время.

Сами команды в истории чата видны как обычные реплики ведущего, но ответа на них не будет.
