# vtuber-obs

Субтитры текущей фразы и смена сцены по эмоции через OBS WebSocket 5. Соединение локальное.

```bash
uv pip install -e plugins/obs
```

В OBS: «Инструменты → Настройки сервера WebSocket», включить сервер, запомнить пароль. Добавить
источник «Текст» для субтитров.

В `config/user.toml`:

```toml
[plugins]
enabled = ["obs"]

[plugins.settings.obs]
password = "пароль из OBS"
subtitle_input = "Субтитры"      # имя текстового источника; пусто — без субтитров

[plugins.settings.obs.scenes]    # эмоция → сцена; остальные эмоции сцену не меняют
happy = "Весёлая"
sad = "Грустная"
```

Пароль можно не хранить в файле: `VTUBER_PLUGINS__SETTINGS__OBS__PASSWORD`.

## Ручной сценарий

1. Запустить OBS и `python -m vtuber serve` с включённым плагином: в логе `obs.connected`.
2. Написать длинную реплику: фразы сменяются в источнике вместе с голосом, в конце текст исчезает.
3. Нажать «Стоп» посреди ответа: субтитры сразу пропадают.
4. Получить ответ с нужной эмоцией: сцена меняется.
5. Закрыть OBS посреди ответа: диалог идёт дальше, после запуска OBS соединение восстанавливается.

Опечатка в имени сцены или источника видна в логе как `obs.request_failed`.
