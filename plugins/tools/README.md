# vtuber-tools

Время, таймер и заметки. Просьба распознаётся правилами до запроса к LLM, результат попадает в справку
этого же хода, поэтому модель генерирует один раз, а не два.

```bash
uv pip install -e plugins/tools
```

```toml
# config/user.toml
[plugins]
enabled = ["tools"]

[plugins.settings.tools]
notes_file = "data/notes.txt"
```

| Просьба | Пример |
|---|---|
| Время и дата | «Который час?», «Какое сегодня число?» |
| Таймер | «Поставь таймер на 5 минут», «Напомни через час позвонить маме», «Таймер на полчаса» |
| Записать заметку | «Запиши в заметки купить молоко», «Добавь заметку: позвонить маме» |
| Прочитать заметки | «Какие у меня заметки?» |

## Ограничения

- Понимаются только такие формулировки. Правила не разбирают смысл: непохожая просьба дойдёт до модели
  как обычная реплика, и та может ответить, что всё сделала, хотя таймер не поставлен.
- Таймеры живут до выхода из приложения. Сработавший таймер витюбер озвучивает только в режиме `serve`
  при подключённом UI, а в терминальном чате он не сработает.
- Время — по часам и поясу этого компьютера. `notes_file` считается от рабочего каталога.
- Инструменты слушают только ведущего: реплики зрителей до них не доходят.
