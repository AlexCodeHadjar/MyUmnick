# vtuber-web-search

Погода, новости и поиск в интернете по смыслу реплики, с показом источников (ADR-0022, ADR-0036).
**Единственный способ, которым витюбер читает интернет: пока плагин не включён, приложение работает полностью
офлайн** (NFR-06).

Поисковик — [SearXNG](https://docs.searxng.org/) отдельным процессом на этом компьютере. Он под AGPL-3.0, поэтому в
приложение не входит: запускаете его сами. В его настройках `settings.yml` нужно разрешить формат `json`.

```bash
uv sync --extra web          # trafilatura — текст статей
uv pip install -e plugins/web_search
```

```toml
# config/user.toml
[plugins]
enabled = ["web_search"]

[plugins.settings.web_search]
searxng_url = "http://127.0.0.1:8888"   # только этот компьютер
auto = true                  # искать по смыслу реплики; false — только «найди в интернете …»
weather = true               # погода из Open-Meteo; false — погода тоже через SearXNG
home_city = "Москва"         # город погоды, если он не назван
read_pages = 1               # сколько статей читать для новостей; 0 — только выдача
```

## Как работает

- «Какая сегодня погода в Москве?», «Будет ли завтра дождь?», «What's the weather in London?» — погода из
  [Open-Meteo](https://open-meteo.com/) (без ключа): уходят только город и координаты.
- «Какие новости про космос?», «Что нового в мире?», «What's the news about AI?» — свежие новости SearXNG за сутки
  и текст первой статьи (trafilatura).
- «Какой сегодня курс евро?», «Кто выиграл матч?», «Найди в интернете рецепт борща» — обычный поиск SearXNG.
- Остальные реплики в сеть не уходят: проверка — правила по словам, микросекунды.
- Реплики зрителей и разговор в приватном режиме поиск не запускают.
- Ссылки на источники показываются в чате под ответом.
- Не ответил за `timeout_s` — витюбер честно скажет, что поиск недоступен, а не будет выдумывать.
- Текст страниц идёт модели как чужой текст, а страницы с явными попытками командовать ею отбрасываются.

## Что важно знать

- Текст запроса уходит через SearXNG в поисковые системы, город — в Open-Meteo, статья скачивается с сайта:
  это выход в интернет с вашего компьютера.
- Open-Meteo бесплатен только для некоммерческого использования.
- Правила промахиваются: вопрос без слов «погода», «новости», «курс»… поиск не запустит — скажите «найди в интернете».
- Фильтр страниц — правила, их можно обойти. Проверяйте важное по ссылкам.
- Ответ задерживается на время поиска. На обычные реплики это не влияет.
