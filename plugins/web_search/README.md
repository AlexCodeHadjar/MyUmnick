# vtuber-web-search

Поиск в интернете по явной просьбе, с показом источников. **Единственный способ, которым витюбер читает
интернет: пока плагин не включён, приложение работает полностью офлайн** (NFR-06, ADR-0022).

Поисковик — [SearXNG](https://docs.searxng.org/) отдельным процессом на этом компьютере. Он под AGPL-3.0, поэтому в
приложение не входит: запускаете его сами. В его настройках `settings.yml` нужно разрешить формат `json`.

```bash
uv pip install -e plugins/web_search
```

```toml
# config/user.toml
[plugins]
enabled = ["web_search"]

[plugins.settings.web_search]
searxng_url = "http://127.0.0.1:8888"   # только этот компьютер
```

## Как работает

- Поиск идёт только на реплику вроде «Найди в интернете курс евро». Обычные реплики в сеть не уходят.
- Реплики зрителей и разговор в приватном режиме поиск не запускают.
- Ссылки на источники показываются в чате под ответом.
- Не ответил за `timeout_s` — витюбер честно скажет, что поиск недоступен, а не будет выдумывать.
- Текст страниц идёт модели как чужой текст, а страницы с явными попытками командовать ею отбрасываются.

## Что важно знать

- Текст запроса уходит через SearXNG в поисковые системы: это выход в интернет с вашего компьютера.
- Фильтр страниц — правила, их можно обойти. Проверяйте важное по ссылкам.
- Ответ задерживается на время поиска. На обычные реплики это не влияет.
