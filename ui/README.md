# ui — окно приложения: чат слева, сцена справа (Tauri 2 + Svelte 5)

## Ответственность
Показывает чат и сцену с моделью, говорит с ядром по WebSocket (адрес — `VITE_CORE_URL` в
`ui/.env`, протокол — `docs/protocol.md`). Логики диалога и LLM здесь нет: всё решает ядро.
Оболочка Rust (`src-tauri/`) только открывает окно; ядро как sidecar — S-13.1 (ADR-0009).

## Команды (из `ui/`)
- `pnpm install` — зависимости; `pnpm tauri dev` — окно с горячей перезагрузкой.
- `pnpm lint`, `pnpm check` (svelte-check), `pnpm format:check`, `pnpm test` (vitest),
  `pnpm build`.
- Ядро в разработке — отдельно: `uv run python -m vtuber serve` из корня.
- Live2D (ADR-0011): `public/live2d/live2dcubismcore.min.js` — из Cubism SDK for Web **5-r.4**
  (`Core/live2dcubismcore.min.js`; Core 6 из 5-r.5 движок не поддерживает); модель — в `public/avatars/<имя>/` целиком
  (`<имя>.model3.json`, `.moc3`, текстуры, моушены, выражения, физика).

## Инварианты
- tsconfig строгий (R-61); `any` и `as` — ошибки eslint (R-62); фичи не импортируют друг
  друга (R-63); типы сообщений — только из `protocol.gen.ts` (R-64).
- Всё, что пришло по сокету, проверяется в `frames.ts`; битый кадр — `protocolError`, связь
  живёт. Список типов сверяется с `OutboundMessage` через `satisfies`.
- Store меняется только своими методами. Сообщения чужого хода (хвост отменённого ответа)
  отбрасываются; разрыв связи посреди хода отменяет ход.
- Список «прилипает» к низу, пока пользователь внизу (допуск 24 px); ушёл читать выше —
  новые сообщения его не дёргают.
- Enter — отправить, Shift+Enter — перенос, Esc — «Стоп»; во время IME-набора не срабатывают.
- Код 4000 (ядро приняло другое окно) — без переподключения, иначе окна вытесняют друг друга.
- `chat.cancel` не ставится в очередь: разрыв сам отменяет ход на ядре (T-14).
- У каждого компонента есть `<script lang="ts">`, хоть и пустой: иначе svelte-check 4.7 не
  выдаёт типы модуля (ADR-0009).
- CSP окна пускает сеть только на `ws://127.0.0.1:*`.
- Аватар: Pixi, движок и Core грузятся динамически — основной бандл (63 КБ) их не ждёт, чат
  работает и без модели. Нет Core или файлов модели — сцена пишет, что и куда положить.
- Модель — `VITE_AVATAR` в `ui/.env` (каталог `public/avatars/<имя>/`); смена модели — без кода.
- Выражение: реакция (например, «думаю» до первого токена) важнее эмоции ответа. «Думаю»
  включается в кадре отправки — реплика в store попадает сразу (T-17).
- Рот (липсинк) — параметры группы `LipSync` из model3.json (иначе `ParamMouthOpenY`), индексы
  ищутся один раз при загрузке. Взгляд — `lookAt`, слежение движка за курсором выключено.
- Ширина чата — доля окна, не уже 320 px у каждой панели; хранится в localStorage
  (`vtuber.layout.chatRatio`), недоступное хранилище не ломает раскладку. Разделитель двигается
  и стрелками (WAI-ARIA window splitter).
- Статус-бар: потеря уже бывшей связи — «нет связи — переподключаюсь», состояние бэкендов без
  связи — «—» (последнее известное устарело).
- Ctrl+Shift+M — по `code`, работает в русской раскладке.
- Звук: один ход звучит за раз. Новый ход вытесняет звук прошлого (ядро синтезирует быстрее
  реального времени и закрывает ход раньше, чем голос договорит); «Стоп», новая реплика, Esc и
  разрыв связи глушат голос сразу, не дожидаясь `turn.cancelled`. Поздние кадры отменённого хода
  отбрасываются. Сброс — затухание 128 сэмплов (≈ 3 мс), после тишины — такое же нарастание:
  щелчков нет.
- Звук не обязателен: нет WebAudio — предупреждение в консоли, чат и аватар работают.
  AudioContext запускается первым нажатием клавиши или мыши (политика автозапуска).
- Рот — из того, что звучит (AnalyserNode после плеера), а не из пришедших кадров: RMS → порог
  0.02 → атака 30 мс / спад 90 мс (`DEFAULT_LIPSYNC`); в паузах рот закрыт.

## Производительность
- Токены в DOM — батчем раз в кадр (T-16, R-65): `CoreClient` копит входящие сообщения и
  смену связи в одной очереди и применяет на `requestAnimationFrame`; звук идёт мимо очереди.
  Свёрнутое окно не рисует кадры — очередь применится при показе.
- История виртуализирована (`features/chat/layout.ts`): в DOM — экран ±600 px, высоты строк
  меряет один общий ResizeObserver. 1000 сообщений — 17–22 строки в DOM.
- Замер в окне Tauri (S-5.3): Enter → первый символ 2–14 мс (бюджет — TTFT + 20 мс);
  прокрутка 1000 сообщений — медиана кадра 6,9 мс, p95 9 мс. Тот же замер UI собирает сам
  (`ui.first_char` в панели метрик; норма p50 — 270 мс = NFR-01 + 20 мс).
- PCM аудиокадра не копируется: `Int16Array` поверх буфера сокета; в поток аудио float-фрагмент
  передаётся (transfer), а не копируется.
- `ui.first_audio` — настоящий TTFA: Enter → первый сэмпл ответа ушёл в устройство (сообщает
  worklet). Норма p50 — 800 мс (NFR-02). Замер S-7.6 (окно Tauri, заглушка LLM ~50 ток/с,
  Silero 48 кГц): p50 160 мс, p95 178 мс; отмена «Стоп» — тишина через 32 мс, Esc после конца
  хода — 84 мс.

## Как расширять
- Новый тип сообщения ядра: перегенерировать `protocol.gen.ts` → компилятор потребует строку
  в `OUTBOUND_TYPES` (`frames.ts`) и ветку в `AppStore.apply`.
- Тесты — рядом с кодом (`*.test.ts`), сокет — через `socketFactory` (ADR-0010).
- **Новая модель Live2D** (без кода): каталог `public/avatars/<имя>/` с `<имя>.model3.json` и его
  файлами, `VITE_AVATAR=<имя>` в `.env.local`, рядом — `mapping.json` (необязателен):
  ```json
  {
    "version": 1,
    "expressions": { "Smile": "expressions/Smile.exp3.json" },
    "emotions": { "happy": "Smile" },
    "reactions": { "thinking": { "expression": "Smile", "motion": { "group": "Tap", "index": 0 } } },
    "frame": { "zoom": 1.5, "offsetX": 0, "offsetY": 0.3 }
  }
  ```
  `expressions` — имя → файл (дописываются в model3.json: у многих моделей файлы выражений
  есть, а в манифесте нет); `emotions` — эмоция протокола → выражение; `reactions` — `idle`,
  `listening`, `thinking` (выражение на время реакции, моушен — один раз); `frame` — масштаб и
  сдвиг центра в долях сцены поверх «вписать целиком». Ошибка в маппинге — текст с полем на
  сцене. Нет маппинга — модель как есть.
- Новая стадия в панели метрик появляется сама, как только ядро шлёт её `metrics.span`; норму
  добавить в `BUDGETS` (`features/metrics/stats.ts`).
- Карта модулей — раздел `ui/src` в `docs/ai/PROJECT_MAP.md` (`tools/ui_map.py`): описание
  экспорта — первая строка JSDoc над ним, компонента — первый `//` в `<script>`.
